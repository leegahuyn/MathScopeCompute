fixed-binder README. The checker separately transports four upper

For example, `Λ Xa exp(s)≤4exp(B)` is equivalent to `s≤B`, and
`log(X/Xa)≤B` is equivalent to `X≤Xa exp(B)` wherever `X>0`.

of the upper inequality. It also carries nonnegativity debts for the
original Y expressions. A feasible upper bound yields `Y<256/63<5`.

A `smooth_piecewise(x,l,r,before,inside,after)` first evaluates `x,l,r`.
The source chooses `before` when `x≤l`, `inside` when `x>l` and `x<r`,
and `after` otherwise. The lower proof uses `x>l` in the inside arm and
`x≥r` in the after arm. The latter also covers the source producer's
explicit endpoint specialization at `x=r`, without a cutoff-ordering
premise. The upper proof uses `x≤l` in the first arm or `x<r` in the
second. Conditions on the controlling operands stay outside all arm
contexts. These implications apply to selected real branches, including
derivatives represented by the same source arms.

variable `t` can be proved from both endpoint bounds. The argument uses

Endpoint expression obligations remain in the parent context. If the
