### B1 등식과 가장 먼저 필요한 원본 조건

기존 속도·압력 \(u_*,p_*\)에 실제 등록된 Repeat 속도 \(v\), 파동 압력 \(\pi\) 및 동일 평균 입력의 압력 갱신 \(\delta p\)를 더했다. 세 성분의 보존형 잔차는 \((u_*+v,p_*+\pi+\delta p)\)에서 처음부터 조립한 값과 기존 잔차에 모든 혼합·이차 증분을 더한 값이 같은 정확 다항식이다. 계산은 \(\nabla\cdot u\)를 남긴 채 진행했다. 이차 이류, 압력 cutoff 항 또는 방사 방향 벡터 라플라시안 결합을 빼면 정확 등식이 깨진다.

다음 연결은 \(X=X_a,X_b\)에서 실제 원본의 지원된 Repeat 성분과 필요한 미분이 입사하는 쪽에서 영으로 수렴한다는 명제다. 이 지점의 코드가 경곗값에서 0을 반환한다는 사실은 이미 확인했다. 경계 안쪽의 완전한 성분과 미분에 대한 상계가 있어야 양쪽을 일반 Cartesian 미분으로 연결할 수 있다. 함께 적용할 자료는 원고의 Proposition 9.9와 증거 브랜치의 goal-next/primary-forced-join/active-n3-c5-binding/repeat-shell-minimum/README.md다.

### B4 연장의 선택

Lemma 10.3에서 선택 가능한 시간 cutoff를 \(\chi_0(v)=\chi(v^2)\)로 고정했다. 계산한 외부 영역 상계로 안전한 정수 일정을 구성했다. 원고의 전역 최소 정수 일정에는 중심부를 포함한 전체 외력의 미분 노름이 필요하다. 압력의 무한 반경 적분과 공간 cutoff 미분을 유지했다. 원고 118–120쪽의 (10.4)–(10.12), 138쪽의 (A.32)와 대조했다.
