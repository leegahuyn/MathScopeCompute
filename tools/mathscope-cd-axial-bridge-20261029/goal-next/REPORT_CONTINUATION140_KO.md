- 실제 활성 3차 원본의 22,380,596개 AST 레코드와 런타임 정의 해시를 Python으로 대조했습니다. 기존 29개 원본 indexed 필드의 4,698개 signed 행이 모두 같은 물리 셸 `Xa < X < Xb`를 사용합니다. 원본 압력, Temporal 퍼텐셜, FiveMap를 포함한 여섯 적분 쌍에 대해 동일 밀도, 적분 변수, 고정 시작점과 전체 끝점을 확인했습니다. FiveMap 전체 적분의 끝점을 움직이는 평가점으로 바꾼 입력은 검사에서 거부됐습니다.
- 3차까지의 원본 응력 AST 123,869개를 독립 생성해 같은 GitHub 원본과 바이트 단위로 일치함을 확인했습니다. 각 차수의 축방향·각방향 응력은 원래 전진·후진 적분을 그대로 참조합니다. `#117047`의 바깥 분기는 0이고, 1차 축방향의 상단은 `Xplus`, 1차 각방향의 상단은 `Xb`입니다. 2·3차의 두 방향은 `Xplus`를 사용합니다.
- `centered_radial_primitive_same_on_two_envelopes`가 GitHub Lean에서 통과했습니다. 같은 밀도가 공통 내부 구간 양쪽에서 0이면 두 고정 적분 구간으로 계산한 중심화된 퍼텐셜이 같습니다. GitHub 로그는 표준 Lean 공리 세 개만 기록합니다. [GitHub Lean 실행](https://github.com/leegahuyn/MathScopeCompute/actions/runs/44707675038)
