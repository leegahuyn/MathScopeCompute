# N2 original eta parameter transport

The 44 new natural calls and 37 system 3/5 even-profile calls all pass the original coordinate `eta` #2. Original system 3 and 5 Picard registry definitions also use the identical eta formal. The `check_eta_frames.py` replay checks source graph and registry hashes, derives the complete conservative native ancestry of those 81 targets, and classifies every reached `actual_expression_partial` whose native body reaches a target:

- 2,986 applications use literal -1;
- 4,312 applications use 1,536 distinct original eta integral coordinates, each with its unique original integral endpoints [-1,1];
- six use slow physical eta #1451898;
- 97 retain eta or have no eta formal.

A finite graph must-dataflow passes a binder only across its own integral body edge, retains both sides of every lazy branch, intersects the available binders at each join, and checks all 4,312 integral-coordinate applications. It reports zero failures. Disabling all binder transfers makes all 4,312 fail: `--negative-no-binders` is the negative control. This is a conservative structural result, conditional on capture-free simultaneous formal substitution and correct derivative semantics; it is not a kernel proof of these semantics.

`check_slow_eta.py` checks the complete original slow inverse equation and actual physical eta operand, and audits 4 covariance, 4 global indexed and 39 auxiliary indexed native calls. At each call, formal Z,T operands are unchanged. At every reached unique-definition row, 243 global and 972 auxiliary, the source maps `(Z,T)` to `(Z*c^D,T*c)` with `D=1/2-h` and positive ratio c. Each c is an exact exponential divided by an exponential. Thus, on actual compatible source images and under uniqueness in the original bracket, `s` maps to `c*s`, and eta is unchanged. The row image and bracket must be established by its actual guards; no unconditional inverse existence is assumed. Embedded covariance definitions are source-cross-checked, not runtime-private seals.

For s>0 the original root is `s-Z^2*s^(2h)-T=0`, and actual eta is `Z/s^(1/2-h)`. Hence `eta^2=1-T/s`; the original `T>=0` source image entails `|eta|<=1`. The exact negative control `h=1/32,s=1,Z=2,T=-3` satisfies the same equation but eta=2. It even has a unique root in the declared positive bracket: endpoint signs follow `(8/7)^16>2` and `(5/4)^16>2`, and the derivative exceeds 1/2 throughout. This is an abstract source-equation countermodel, outside the actual T>=0 domain, establishing why that condition is needed.

The independently verified `whole-k-inner-axis` Picard/even evaluation is useful only in its stated `0<=Y<=4`, `|eta|<3/4` whole-K inner region. It does not itself establish the annular `4<Y<5` or all ambient chart cases. Complete domain transport must still verify every active row guard's image/bracket and fixed-chart derivative/frame semantics, and combine eta with the independent Y/radial transport. All original gate/release statuses remain unchanged.
