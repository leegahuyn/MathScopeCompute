# R1-08의 실제 게시 화면 확인 범위

원래 설계도 68쪽은 지원 기능의 후보 범위, 모듈 상태와 전체
`RELEASE HOLD`의 구분, 패치·테스트·rollback, 실제 게시 후 화면
확인의 네 조건을 요구한다. 마지막 조건의 게시 대상을 운영 페이지로
지정하지 않는다. 독립된 게시 환경에서 동일 후보의 실제 버전과 화면을
읽어 확인하면 해당 후보의 게시 검사를 충족할 수 있다.

현재 15개 M4 등록 자료를 원래 평가기에서 다시 검증했다.
남은 기준은 R1-08이며 M3의 N7-06과 N8-05도 OPEN이다.
전체 판정은 `HOLD`이고 `canFreeze=false`다. 원래 평가기는 검토한
R1-08 증거 digest를 아직 보유하지 않는다. 실제 게시 영수증과
독립 검토가 있어야 이 기준의 등록을 진행할 수 있다.
평가기의 `publicationConfirmed`는 해당 평가기 자체가 배포를
확인하지 않도록 설계된 상수다. 향후 게시 사실은 별도의 실제 게시
영수증에 기록하고, 전역 `canFreeze`는 원래 M3 완료와 16개 M4
수락을 모두 요구하는 평가 규칙을 따른다.

## 읽기 전용 확인

- 연결된 WebsitePublisher 계정에서 프로젝트 29770 한 개와 페이지
  다섯 개를 읽었다. 후보용 격리 프로젝트나 페이지는 그 목록에 없었다.
- 운영 `v0.3.1.html`은 버전 137, 버전 해시 `9171eb0c`였다.
  실제 HTTP 응답의 SHA-256
  `a945831236caa965dd96f986fb3f8311d6a236afed8235c0a69e135f51febe48`는
  기존 운영 읽기 기록과 일치했다. 이 응답은 운영 페이지의 현재 버전이다.
- GitHub 저장소의 접근 가능한 배포 목록과 해당 브랜치 배포 목록은
  모두 빈 배열이었다. GitHub Pages 설정 조회는 HTTP 404였다.
  이 범위에서 실제 게시된 격리 후보 URL을 확인하지 못했다.
- 격리 브라우저 검증에 사용된 후보 SHA-256은
  `0504482900dbeac2faf992be9a923bc51ab1de6bcec0b82ac058085444669735`이다.
  이 후보의 4개 패치를 다시 적용하고 역순으로 되돌려 보관 기준본과
  바이트 단위로 일치함을 확인했다. 후보와 현재 운영 HTTP 응답은
  서로 다른 바이트다.

## 닫을 수 있는 범위

게시할 정확한 후보와 별도의 호스팅 대상 또는 이미 게시된 동일 후보의
URL·버전이 주어지면, 해당 후보 화면에서 지원 범위와 HOLD 상태를
읽고 배포 식별자와 연결할 수 있다. 이때 게시 전 후보 해시와 게시
버전의 읽기 결과를 결속하고, 새 브라우저에서 실제 페이지를 확인한
화면을 기존 테스트와 rollback 자료에 연결한다. 제공자가 HTML을
변환하는 경우, 저장된 게시 버전의 소스와 HTTP 응답을 각각 식별한다.
검토자는 그 동일 후보의 게시 영수증을 원래 R1-08 검토 대상으로
사용할 수 있다.

원래 평가기의 개별 증거 파일 제한은 16 MiB다. 현재 HTML 후보
28,928,002바이트를 하나의 증거 파일로 제출하면
`CRITERION_ARTIFACT_INVALID`가 나온다. 독립 HTTP 원본 해시를
보존하고, 평가기에는 크기 제한을 충족하는 게시 영수증·화면·해시
자료를 결속하는 방법이 가능하다. 실제로 제한 내 패치 기록은 바이트
검사를 통과했고, 검토 digest가 없어 `CRITERION_REVIEW_REQUIRED`가
유지됐다.

실제 후보 게시 영수증이 생기면 검토 후 R1-08 범위만 닫을 수 있다.
운영 URL 변경, 전체 릴리스, 최종 67개 jet 수락은 별개의 판정이다.
이번 확인은 원래 운영 페이지와 소스 브랜치를 변경하지 않았다.

[운영 페이지](https://project29770.websitepublisher.ai/v0.3.1.html)

동일한 후보 HTML, 두 시점의 운영 응답, 브라우저 영수증을 사용해
검사를 재생할 수 있다.

    node audit_r108_remaining.mjs REPO OUT CANDIDATE_HTML CURRENT_HTML PRIOR_HTML BROWSER_RECEIPT
