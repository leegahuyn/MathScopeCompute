# 현재 운영본의 R1-08 읽기 전용 대조

2026-11-11에 운영 페이지의 인수 보드를 실제로 열고 R1-08을 선택했다.
데스크톱 1280×900과 모바일 390×844에서 R1-08은 OPEN이었다.
운영 보드는 2026-10-25 장부 스냅샷으로 M3 62/64, M4 0/16,
Y 33/523, 최종장 0/67과 전체 RELEASE HOLD를 표시했다.
[운영 페이지](https://project29770.websitepublisher.ai/v0.3.1.html)

운영본의 기존 R1 실행·재현 작업대를 확인했다. 격리 검증 후보에
있는 ProofJob 편집기 호스트는 이 공개본에서 0개였다. 따라서
공개본의 화면 증거와 격리 후보의 패치·테스트·rollback 증거는
서로 다른 버전에 속한다. 해당 후보의 실제 게시 후 화면 검사는 OPEN이다.

데스크톱에서 인수 보드 버튼 가운데를 누르면 겹친 원문·증거 버튼이
포인터를 받았다. 인수 보드 버튼에 초점을 옮겨 Enter를 눌렀을 때는
보드가 열렸고 R1-08을 선택할 수 있었다. 수집 중의 페이지 오류와
브라우저 콘솔 오류는 각각 0건이었다.

검사 전후 운영 버전은 137, 버전 해시는 `9171eb0c`로 일치했다.
화면 검사는 새 브라우저 세션에서 GET과 HEAD만 허용했다.
파일별 해시와 응답 해시는 `public-readback/public-identity.json`에
있다. 브라우저에서는 현재 운영 화면, 별도 HTTP 요청에서는 공개
HTML 바이트를 확보했다.
