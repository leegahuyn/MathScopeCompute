# Live N3 identity for the original C73 and C74 paths

## Verified result

All 40,621 selected typed source records and all listed nested
declarations agree at identical IDs. The live stream contains
22,155,584 nodes and 1,024,352,367 uncompressed bytes. The source
identity binds the C73 Wrz and C74 P0/Jz0 operands on this live run.
The full old-count prefix check returned false. The original graph
identity reported here is therefore limited to the specified slices
and declarations.

## Replay

This verifier reads the already downloaded graph of completed GitHub
run 44582875351. It checks the terminal run pin, embedded export
manifest, native registry digest and uncompressed graph digest. It
then compares the archived C73/C74 typed operands against that same
live graph, including the entire Wrz registry and the signed local
bodies, Temporal inverses, exact original Haar declaration and
fresh P0/Jz0. The native potential systems used by C75 are also
compared as source declarations.

The node stream is read once without a decompressed copy. Each
selected record is compared at its retained integer node ID with
its JSON type and original argument order. A separate check tests
whether the entire earlier node stream equals the corresponding
prefix of the live stream when only the header's count is adjusted.

The result connects the source operands to the live export.
Analytic inequalities keep their own hypotheses. In particular
this comparison does not establish weighted bases, final spatial
endpoint inequalities, later Signed/FiveMap corrections, or final
jet bounds. The live export itself is scoped to first-correction
spatial ingress.

Run the verifier with the preserved workspace and a new output file.

    python verify_live_prefix.py WORKSPACE NEW_RECEIPT.json

Supply --host PATH if the complete hosted source directory was
extracted elsewhere. Its sibling first-correction-spatial-export.json
is checked against the embedded manifest as well.
