# First active correction spatial source export

This companion runs next to the same original N3 first-correction build.
It requires the live private post-Five source owner and checks its six
stage records against the archived successful run 44528954587. Its
separate archive receipt cannot stand in for the live owner.

The export requests 24 uncut velocity, potential, and first spatial
derivative roots for the energy proof, together with 33 original
spatial jet labels for the potential and direct axisymmetric scalar.
It retains the reference-band coordinate scaling, all 162 original
label maps, both conjugate signs, and the Forced, Signed, Temporal
and FiveMap inputs. The three gauge-to-velocity curl differences are
exported as separate proof obligations. Their values are OPEN.

**VERIFIED preflight.** The archived original N1 control streams and
hashes all 4,456,994 original nodes, with six own-to-reference gauge
definitions and all 162 row maps. The original differential kernels
pass the radial chain, rotation, curl sign, and 33-label controls.
A detached copy of the archived source receipt is rejected by the
original private owner assertion. The controls do not execute the
new N3 path or supply uniform numerical bounds.

The isolated first-cycle runner defaults to `full-source`, which
saves the normalized roots, extended native registry, and streamed
source. `MATHSCOPE_FIRST_CORRECTION_SPATIAL_MODE=operands` saves the
24-root metadata only. `off` runs the existing split verifier alone.
The direct split and spatial export have separate outcome records.
If either fails, its failure remains visible in the workflow and logs.
All modes use the existing isolated branch and readonly checkout of
the original code.

Run the local controls using the original pinned `NAVIER_RUNTIME`,
source graph archive, prior first-cycle receipt, and guard overlay.

~~~text
python -B check_archived_reference_scaling.py GOAL_NEXT ARCHIVED_N1_GRAPH NEW_CONTROL.json
node check_spatial_operators.mjs NAVIER_RUNTIME NEW_CONTROL.json
node check_detached_stage1_owner.mjs NAVIER_RUNTIME PINNED_FIRST_CYCLE.json ORIGINAL_GUARD_OVERLAY
~~~
