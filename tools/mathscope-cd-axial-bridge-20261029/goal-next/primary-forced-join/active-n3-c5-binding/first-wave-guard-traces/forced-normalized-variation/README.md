## CONDITIONAL

\(\alpha=(r,z,l)\), \(s=r+z\)라 하자. 실제 강제항의
\(P^m\)을 분리한 계수가 해당 방사 가중치와
\(D^\alpha\)마다 \(F_m S^{b_m+2s}\)로 제어된다고 둔다.
이 전제에서 기저와 투영의 각 \(R,Z\) 미분은 \(S\)를 한 차수
쓰며 \(L\) 미분은 모두 강제항으로 전달된다.
변분 미분에 원본 적분 방정식을 반복 적용하면, 행렬 도함수 \(k\)개가
강제항 시간 \(t_0\) 이후의 순서가 있는 구간에 놓인다.
원래 전파자 상수 \(C_0=\exp(3B_{\rm norm}^{256}L_{\max})\)는
항마다 \(k+1\)번 곱한다. 미분이 없는 행렬은 이 전파자에
포함된다.
강제항의 원소별 노름은 실수부와 허수부 각각의 절댓값 중
최댓값이다. 복소수 모듈러스가 필요한 경우 \(\sqrt2\)를 곱한다.

행렬이 \(\beta\ne0\)차 미분될 때 지수 비용은 \(S^{|\beta|}\)다.
미분이 강제항에서 행렬로 이동하면 강제항에서 \(S^{2|\beta|}\)를
덜 쓰며, 적분 시간 하나의 비용이 \(S\)다. 따라서 행렬의 개수는
\(k\le s\)이고, 남는 순서 적분 부피는
\((v-t_0)^k/k!\)이다. \(L\)만 한 번 미분한 행에는 순서 항이
하나이고, \(R\)을 네 번 미분하는 행에는 16개다. 유리수
코드는 \(-B_\ell\Pi\), 마지막 \(B\) 및 모든 Leibniz 계수를
정확 유리수 다항식으로 저장한다.

모드 1의 정규화된 강제항에는 펄스 질량 인자가 들어가지 않는다.
가장 안쪽의 시간 적분은 \(L_{\max}S\)로 제어한다.
모드 2에서는 원본 강제항의 \(P^2\) 중 하나가 남는다.
실제 \(P(t)\le\exp[-g_L(t-L_s/2)^2/L_s]\)와
\(g_L=R_{\rm env}^{-41}/8\)를 적용하면 가장 안쪽의 적분은
\(3\sqrt{L_{\max}/g_L}\sqrt S\) 이하이다. 따라서 두 모드의
정규화 해와 물리장 \(U/P\)의 \(S\) 지수는 각각
\(b_1+2s+1\) 및 \(b_2+2s+1/2\)다.
원본 이동 경로가 고정하는 방사 가중치의 극점은 이 단계에서
증가하지 않는다.
이번 미분 조합은 \(s\le4\)다. 강제항의 밴드 기저 차수가
\(0\le b_m\le55\)라면 정규화 해의 다항 차수는 두 모드
모두 64 이하이다. 이 조건에서 C89의 실제 라벨 부등식으로
원본 \(\epsilon\) 지수의 \(2^{-20}\) 이내에서 위 손실을 흡수할 수
있다. 강제항 기저 차수의 실제 정량적 상계는 열린 입력이다.

물리 모드 2에서 \(P(v)^{1/2}\)를 외부에 유지하고 나머지
\(P(v)^{1/2}\)를 시간차의 제어에 사용해 다음의 별도 상계를 얻는다.

\[
P(v)\int_0^v P(t)\frac{(v-t)^k}{k!}\,dt
\ \le\ \sqrt{P(v)}\frac{3}{\sqrt{k!}}
       \left(\frac{2L_s}{g_L}\right)^{(k+1)/2}.
\]

이는 두 중심 거리 \(a,b\)에 대한
\((a-b)^2\le2(a^2+b^2)\)와 양의 지수급수의 \(k\)차항을
사용한다. 이에 따라 \(k\)개 행렬이 삽입된 물리 모드 2의
지수는 \(b_2+2s+(1-k)/2\)다. 같은 구간에서 시간 적분의
질량 전달과 \(\sqrt{L_s}\) 상계는 Lean으로 검증했다.
계수표에 \(1/k!\)가 이미 있으므로 그 표를 사용할 때는 새
시간 인자의 계수로 \(3\sqrt{k!}\)를 넣는다.
이 물리장 외피는 정규화 해에 필요한 전체 \(P(v)\)를 보존하는
외피와 함께 제공한다.
