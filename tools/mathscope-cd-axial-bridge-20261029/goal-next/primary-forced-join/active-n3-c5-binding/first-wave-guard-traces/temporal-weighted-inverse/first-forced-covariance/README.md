# C87 첫 Forced 공분산의 바깥 방사 가중치

**VERIFIED.** GitHub 원본 실행 44582875351의 22,155,584개 레코드를 인증하고 C85 계산을 다시 실행했다. 실제 양의 두 모드의 원본 RHS 스칼라 120개를 유리수로 전개했다. 특히 모드 2의 각 이차 단항식에는 Primary 속도 두 개의 원본 미분 차수 합이 0 또는 1이다. 두 인자의 차수 상한을 각각 1로 더하면 이 사실을 잃는다. 모드 1에서는 선형 Primary 속도 2차, Primary 압력 1차, 주 펄스 꼬리 0차, 배경을 포함한 평균–속도 곱의 합 1차까지 나온다.

**VERIFIED.** 원본 직접 Haar 항과 원본 축방향 압력 항에서 방사 \(0,1,2\)차에 필요한 공분산 미분을 추렸다. 고정 차트 열 개, \(a_1,f_1,f_2\)와 세 속도 성분에서 총 750개 복소 계수 역할이다. 원본 curl을 전개한 결과 변분 방향은 \(R,Z,L\)의 아래로 닫힌 23개 다중지수이며, 최대 합계 차수는 4다. 스무 펄스 시스템의 투영 RHS에 1,380개 복소 성분 요청이 대응한다. 압력의 짧은 적분은 방사 1차부터 끝점값으로 바뀐다. 따라서 C85의 모든 0차 입력에 방사 미분을 무조건 두 번 추가하는 계산보다 필요한 최대 차수가 하나 작다.

등록된 네이티브 미분 한도는 위 요청을 수용한다. 이 계산은 새로운 고차 수치를 적분하거나 원본 그래프에 물질화하지 않았다.

## 실제 원본 항의 조건부 상계

\(d=\log(X_b/X)\in(0,1/4]\)에서 원본 \(g(d)=e^{-2/d^2}d^{-3/2}\)의
\(j\)차 미분은 \(g(d)d^{-3j}P_j(d^2)\)이고 다음 유리수 다항식 재귀를 만족한다.

\[
P_0=1,\qquad
P_{j+1}(z)=(4-(3/2+3j)z)P_j(z)+2z^2 P_j'(z).
\]

두 Gaussian을 비교할 때 바깥 한 쪽 Gaussian과 실제 \(\sqrt{\zeta}\)의
비는 \(100352/100351\)로 제어된다. 같은 활성 차트의 원본 양의 진폭이
\(g\sqrt{W}\)에 결속되고 나머지 정규화 계수가 요구 차수까지 유계라는
조건을 쓴다. 특히 정규화 Primary 진폭에는 7차까지 필요하다.
원본 Primary 압력은 \(i(n^T K-n'^T)t/(k|n|^2)\)의 컷오프 진폭에 선형이고, 주 펄스 꼬리도 미분되지 않은 원본 진폭에 선형이다.

\(j\)차 방향 미분의 상계를 \(C\zeta^\nu d^{-p-3j}\)로 쓸 때
원본 복소 계수의 \((\nu,p)\) 값은 다음과 같다.

| 복소 계수 | Gaussian 지수 \(\nu\) | 기본 극점 \(p\) |
| --- | ---: | ---: |
| Primary 속도 \(a_1\) | \(1/2\) | \(9/2\) |
| 투영 모드 1 RHS | \(1/2\) | \(21/2\) |
| 투영 모드 2 RHS | \(1\) | \(12\) |
| Forced 속도 \(f_1\) | \(1/2\) | \(27/2\) |
| Forced 속도 \(f_2\) | \(1\) | \(15\) |

원본 \(H_w\)는 같은 차트에서 \(R,Z,L\) 방향과 교환하며 짧은
펄스에서 가중치를 고정한다. 비교에 필요한 원본 행렬 도함수,
투영 행렬과 기하 인자를 유계로 둔다. \(\Phi\)의 같은 순서 쌍 전파 상계
\(C\), 행렬 도함수 상계 \(B\), 입력 상계 \(F\), 길이 \(L_s\) 아래
4차까지 영초기값 미분의 공통 상수는

\[
CFL_s\sum_{j=0}^4\frac{(15BCL_s)^j}{(j+1)!}.
\]

이는 변분식의 엄격한 차수 하강과 삼각 적분 부피를 사용한다.
원본 출구에 \(w=v(Y)\)를 치환해도 세 방향은 고정되며, 마지막
curl의 1차가 \(f_m\)의 극점에 3을 더한다.

60개 원본 공분산 본체와 정규화 각 평균의 실제 곱을 사용했다.
\(a_1\overline{f_1}\), \(f_1\overline{a_1}\), \(f_1\overline{f_1}\),
\(f_2\overline{f_2}\)에 \((\nu,p)=(1,18),(1,18),(1,27),(2,30)\)가
나온다. 이미 포함된 Primary 자체 곱은 \((1,9)\)다.
양의 지수급수의 2차항에서 \(\zeta d^{-3}\le d/8\le1\)이므로
전체 공분산은 \(j\)차에서 \(\zeta d^{-(27+3j)}\)를 유지한다.
고정 라벨 \(162\)개를 포함한 조건부 계수
\[
C_j=162\cdot16\cdot2^{2j+1}
   (P_{\rm cap}^2+2P_{\rm cap}F_{1,\rm cap}+F_{1,\rm cap}^2+F_{2,\rm cap}^2)
\]
는 라벨 정규화 \(16\), \(R,Z\) 느린 미분마다 최대 2, 각 평균과
곱미분의 \(2^{j+1}\)을 반영한다. 원본 같은 \(X,d,\zeta\)와 고정 라벨
affine 치환을 유지한다.

원본 압력이 쓰는 두 적분은 원래의 이동과 고정 경계를 유지한다.
Haar 변환을 먼저 적용하면 토러스 이동이 사라지고, 바깥쪽에서
\(\chi=1\), \(\chi_Z=\rho=\rho_Z=0\)인 실제 짧은 구간이 남는다.
사용한 보조 함수는
\[
H(r)=\frac{\overline W_{rr,Z}(r)-\overline W_{\theta\theta,Z}(r)}r
       +\varepsilon\overline W_{rz,ZZ}(r).
\]
공분산이 주는 \(\overline{p_Z}\)는
\(-\overline W_{rr,Z}(R)+\int_R^\beta H(r)dr\)이며 1차에는
\(-\overline W_{rr,RZ}-H(R)\), 2차에는
\(-\overline W_{rr,RRZ}-H_R(R)\)를 사용한다.
0차 적분에는 로그 거리의 Jacobian \(r/2\)와 C86의 \(d^3/4\) 이득을
동시에 적용한다.

| 공분산 기여와 공통 가중치 | 0차 방사 | 1차 방사 | 2차 방사 | 3차 방사 |
| --- | ---: | ---: | ---: | ---: |
| 원본 Haar \(E\), \(\zeta\) | 30 | 33 | 36 | |
| Signed \(\Sigma\), \(\zeta\) | 27 | 30 | 33 | 36 |
| Signed 포텐셜, \(\sqrt{\zeta}\) | \(51/2\) | \(57/2\) | \(63/2\) | \(69/2\) |

위 숫자는 \(d^{-p}\)의 \(p\)이다. Signed 몫까지 적용할 때 같은 실제
차트의 양의 진폭과 나머지 정규화 계수의 방사 3차 상계가 필요하다.
위 조건 하의 공분산 기여는 방사 0–3차에서 임의의 양의 멱으로 0에
수렴한다.

## 남은 정확한 입력

같은 활성 Primary 외부 계수의 7차 결속, 원본 초기 평균 C5,
전파 및 행렬·기하 상계와 모든 라벨의 실제 수치 계수가 필요하다.
원본 매끄러운 영연장, 정상적인 적분 교환과 지지 조건도 유지한다.
여기서는 직접 공분산과 압력의 공분산 성분을 계산했다.
초기 평균의 독립 항과 축 압력의 배경·점성 항이 남으므로 전체
Haar \(E\)와 혼합 접합, 최종 jets 또는 릴리스 판정은 따로 검증해야 한다.
N7-06·N8-05는 OPEN, 최종 jets 0/67 및 RELEASE HOLD다.
