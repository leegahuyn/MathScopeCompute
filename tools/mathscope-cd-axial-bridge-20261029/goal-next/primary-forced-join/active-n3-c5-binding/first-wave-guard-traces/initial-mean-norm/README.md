## VERIFIED

활성 원본의 세 초기 평균 본문을 모두 읽었다. 첫 Forced가
참조하는 세 정의는 각각 다음의 정확한 합이다.

고정 차트 전체에 등장하는 위 세 정의의 15개 원본 호출을
실제 \((R/\sqrt{\rho},Z/\rho^D,T/\rho,\ell_{\rm ref},Y_0,Y_1)\)에
결속했다. 바깥 물리 배율은 \(\rho^{-A}\)다.
\(\rho=Q_{\rm ref}/Q_{\rm own}\)과 \(2D+2h=1\)이므로
같은 실제 점에서 \(X,\eta,q\)가 보존된다. 이는 원래 양의
단조 차트에 속하는 점에 적용된다.

실제 공통 시간 계수는 \(c_{i,0}=T_g^{i(\ell-2)}Q^{1+h}\)이다.
\(S=\ell^2\), \(\ell\ge8\), \(0<h<1/64\)에서
\(1/(8T_g S)<c_{i,0}\le1/S\)다. 공통 반지름 이동
\(\phi(R)=c_{i,0}^{\rho_g}\epsilon^{-1/100000}R^{d_r}\)와
\(a=\phi_R\)도 실제 원본 노드에 결속했다.
계수의 라벨 이동 부등식은 GitHub Lean에서 컴파일했다.
[GitHub 실행](https://github.com/leegahuyn/MathScopeCompute/actions/runs/44634334317).

원본 \(b/\epsilon\)에는 각 양의 차수의
\(-2\eta\,M_n(c_nq)\chi'(c_nq)/L\) 항이 있다. 세 차수 모두에서
그 항을 생략하면 실제 식이 달라진다. 원본 수치 엔진과
74,575개 산술 노드로 평범한 cutoff 및 추가 미분 항을 포함한
5차 범위를 계산했다. 원래 물리 slab에서 \(b/\epsilon\)의
상계는 기존 문턱 \(\exp(H/2^{128})/(64X_b^2)\)보다 작다.
원래 계수 상계와 슬로 차트의 해석 전제를 유지한다.

[Primary 소스](primary/README.md)의 100개 본문에 원래
\(S^3\) 격자 미분 비용을 적용했다. Primary 속도의 느린 7차,
횡방향 8차를 유지했고, 실제 강제항에서 정규화 펄스 미분은
모드 1의 \(+\partial_v\widehat U\)만 남는다.

## CONDITIONAL

고정 라벨의 원래 소섭동 조건, 원본 정칙 경계 및 같은 chart 안의
전체 짧은 반지름 경로를 가정한다. 원본 Primary 복소 계수
\(U_*\)는 실수부·허수부 성분 각각의 상계를 나타낸다.
\(k^{-1}\le\sqrt\epsilon\)과 기존 C89의 밴드 부등식
\(S^3\le\epsilon^{-2^{-20}}\)을 사용하면, 필요한 모든 Primary
공분산 요청에서
\(W_*\,\epsilon S^{1/2+3s}\zeta d^{-(9+3s)}\)를 사용한다.
\(W_*\)는 같은 원래 차트의 \(U_*^2\), 고정 162개 부호 행,
이웃 라벨의 아핀 계수 및 \(L\)에 대한 실제 고정 배율을
곱한 명시적 상수다.

43개 \(R,Z,L\) 조합을 각 초기 평균 성분에 적용했다. 원래
Fourier 역, 축 방향 압력, \(T_0/T_1\)의 순서 있는 반지름
이동, \(\chi_R=0\)의 바깥 조건, 더해진 \(L^2\) 요구를
모두 유지했다. 값이 필요한 공분산 요청은 600개다.
압력과 흐름함수에 들어가는 짧은 적분은 153개 역할을 갖는다.
원래 대조 범위의 바깥에서는 FiveMap이 남으므로 이 외피를
임의로 적용할 수 없다.

각 행에 \(W_*\zeta d^{-(12+3s)}\)를 곱한다. 기하 상수는
원본 \(R\) 범위에서 \(98304(2+2R_{\rm env})^7\)로 선택할 수
있다. \(s\le5\)에 남는 Gaussian과 방사 극점은
\(14!/4^{14}\)로 유계다. \(b,RF,G\)의 배경 상계를 더하면
이 바깥 collar에서 초기 평균에 적용할 실제 계수식을 얻는다.

원본 C90의 강제항 계수표를 \(S^{3s}\) 기울기로 다시 합산했다.
나머지 강제항 계수가 같은 기울기이며 양의 기저 밴드 멱을
추가하지 않을 때, 모드 1·2의 정규화 해는 4차까지 각각
\(S^{107/4}\), \(S^{16}\)으로 제어된다. 나머지 계수의 실제
밴드 멱이 있으면 해당 멱을 더해야 한다. 분리해 저장한 원본
\(\epsilon\) 인자와 음의 방사 극점도 보존한다.
