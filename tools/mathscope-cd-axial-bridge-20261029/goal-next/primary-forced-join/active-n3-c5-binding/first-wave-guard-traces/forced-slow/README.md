# 원본 첫 Forced의 네 느린 경계

## VERIFIED

원본 N3 실행 44582875351의 22,155,584개 노드에서 band, R, Z, T의
정규화된 cutoff를 결속했다. 각 cutoff는 중앙 범프를 세 이동 범프 제곱의
합의 제곱근으로 나눈다. 양쪽 경계 $d=\pm3/4$에서 이웃 범프 하나가
1이고 나머지 둘은 0이므로 분모는 정확히 1이다. 중앙 범프는 원본
$\sigma(3/2-2|d|)$의 경계 인자가 0이며, 표준 $C^\infty$ step의
평탄성으로 모든 유한 차수의 도함수가 0이다.

각 인자를 실제 잠재장 6개와 초기 속도·압력·주 잔차 100개로 추적했다.
실제 20개 모드의 원시·지지 강제항 각 120개와 첫 조화의 제거 항 60개를
확인했다. 두 번째 조화에는 제거 항이 없다. 원본 $H_w$가 두 자유
좌표만 바꾸고 일곱 느린 인자를 그대로 넘긴다. 투영 강제항 120개가
실제로 이 지지 강제항으로 생성된다. 투영 분모와 행렬의 원래 인자를
유지했다. 실제 20개의 순서 적분 재귀는 동일한 닫힌 펄스에서 시작하며
초기값은 0이다.

## CONDITIONAL

다른 guard가 엄격한 한 고정 차트에서 선택한 느린 입구 또는 출구를
횡단한다고 가정한다. 펄스의 모든 점에서 원래 cofactor, 투영 역수와
펄스 행렬이 경계까지 필요한 차수로 매끄럽고 실제 해의 미분이 유한
변분계와 일치하면, 선택한 얼굴에서 원본 강제항의 유한 도함수는 0이다.
강제항 내부의 최대 속도·압력·주 잔차 미분 차수는 각각 2, 1, 0이다.
강제항의 추가 $r$차 도함수에는 각각 $r+2$, $r+1$, $r$차까지 필요하다.
기저 포텐셜에서 초기 속도를 만들 때 추가 1차를 사용한다. 해당 유한
변분계를 블록 행렬로 묶으면 Lean의 영강제 순서 적분 정리를 적용할 수
있다. 결과를 사용할 때 외부 cutoff 곱미분은 따로 유지한다.

## OPEN

정확한 대조 예로 $s>0$, $0\leq w\leq1$에서
$t'=s^{-2}t+e^{-1/s^2}$, $t(0)=0$이면
$t(1)=s^2(1-e^{-1/s^2})$이다. 강제항은 평탄하고 끝점의 2차 미분은
$2$에 접근한다. 실제 원본의 네 느린 경계에 필요한 균일 변분계 제어,
