# 바깥 collar에서 첫 Forced에 들어가는 계수의 로그 상계

고정 원본 라벨의 허용 범위에서 C88의 양의 공분산 행렬과 C89의 펄스 프레임, C91의 Primary와 초기 평균 상계를 하나의 정확한 정수 계산으로 연결했다. 느린 원본 프레임의 0–8차와 Primary 속도의 느린 0–7차, 횡방향 0–8차를 유지했다. 최종 첫 Forced 변분의 23개 혼합 방향에서 모드 1·2 두 외피를 각각 계산했다.

## 조건과 상계

\(B=B_{\rm norm}\), \(W=\exp(3B^{256}L_{\max})\), \(M=\exp(H/2^{128})\), \(H=h(\ell_{\min}+15)\log 2\)로 둔다. \(W\)는 전파자 외피이고 C88의 공분산 역으로 정의되는 두 양의 제곱근 가중치는 별도다. 원본 C89의 허용 슬로 chart와 \(q_{\rm Big}/64\le q<q_{\rm Big}/16\) 슬래브, \(0<d=\log(X_b/X)\le1/4\), 고정 라벨에서의 원본 양의 분모와 공분산 cone, 모든 참조·변분·짧은 반지름 경로가 해당 정의역에 속함을 사용한다. 원본 \(F,G,b\) 미분 상계와 C88의 정칙 표적·축방향 모멘트 전제를 유지한다.

- \(B\ge2^{128}\), \(R_{\rm env}^{4096}\le B\), \(L_{\max}\le1\) 및 \(B^{511}<2H\)는 원본 라벨과 펄스 경계의 부등식이다. 원본 \(F,G\) 상계가 \(M\) 이하인 슬래브에서 C89 행렬의 공통 입력은 \(2B^5M\le B^6M\)로 잡는다.
- C88의 \(g_L=R_{\rm env}^{-41}/8\)과 채택한 \(I_\chi\in[r_0/2,2r_0]\), \(1<D_{\rm geom}<4\), \(r_0=2^{-34}\), \(T_g<6\)을 쓴다. 원본 \(\lambda_{\rm upper}\le R_{\rm env}^{83}\), \(u\ge2\)이고 Gaussian 중앙 질량 계수는 \(2^{-10}B^{-1}W^{-2}\) 이상이다. 따라서 \(m_L\ge2^{-64}B^{-1}W^{-2}\), \(K_G\le32B\), \(m_U\le2^7BW^2\)다. 양의 행렬식 하한에서 \(D_0^{-1}\le2^{128}B^3W^4\)를 얻는다.
- 방향 여유 \(\kappa\)의 원본 값은 \(R_{\rm env}^{-10}\)이다. C88의 양의 가중치 범위에 대입하면 제곱근의 0차 상계는 \(2^{33}BW\)이고 양의 차수 재귀의 역분모는 \(2^{16}BW\) 이하이다. 원본 규모 정의에서 \(\log C_{\rm selected}\ge Q_{\rm parameter}^{200}\), \(R_{\rm env}>C_{\rm selected}\), \(\Lambda_{\rm profile}=Q_{\rm parameter}^{64}\)이므로 \(R_{\rm env}\max(2,\Lambda_{\rm profile},R_{\rm env})^{119}\le B\)다. 여기서 \(\Lambda_{\rm profile}\)은 \(\Lambda_{\rm lift}=4-\sqrt2\)와 구별한다.
- 원본 고정 라벨의 밴드 cutoff에 기존 9차의 \(2^{4096}R_{\rm env}^{26}\)을 사용한다. 세 메시, 횡방향 및 시간 cutoff는 C91의 실제 미분 계수를 사용했다. 고정 팔레트 수준 0–4와 횡방향 9차까지는 \(\Lambda_{\rm lift}^{36}<2^{60}\)이고 활성 구간에서 \(1/L_s\le2^{33}/S\)다. 시간 미분 한 번은 이 인자를 유지한다. C71 차트에서 8차 이하 \(\log s\) 미분은 \(4\,j!\,256^j\) 이하이며 \(R^{-1}\le2R_{\rm env}\)이다. \(d=\log(2X_b)+\log s-2\log R\)의 미분을 \(2^{100}B^8\)로 잡고 C91 Gaussian 다항과 8차까지의 Bell 가중치를 합하면 \(2^{900}B^{64}\)로 제어된다. 원래 \(d\)의 음의 멱과 Gaussian은 유지한다.
- Primary에서 \(n\times\widehat A/(k\,n\cdot n)\)과 한 번의 \(v\) 미분에 필요한 \(q_n^{-1}\)의 미분을 실제 식으로 적용했다. 압력의 \(n^\mathsf{T}K-n_v^\mathsf{T}\), 꼬리의 \(1/L_s\), 반지름·빠른 위상 인자를 유지한다. 초기 평균의 세 Temporal 성분에는 C91의 실제 공분산 이전 배수 및 그 성분별 유리 계수를 곱했다. \(G_{\rm geom}=98304(2+2R_{\rm env})^7\le2^{24}B^7\)와 \(14!/4^{14}<2^{40}\)을 사용한다.
- 두 모드의 첫 변분에서 필요한 \(B_\ell,\Pi,B\)와 모든 순서 가중치는 C90의 유리수 다항 그대로 사용했다. 모드 1의 적분 계수 \(L_{\max}\le1\), 모드 2의 \(3\sqrt{L_{\max}/g_L}\le16B\)를 적용하고 서로 다른 \(S\) 멱을 유지한다.

\(cB^bW^wM^m\)에서 \(c\)를 정확한 정수로 올림하고 곱의 차수는 더한다. 합은 정수 계수를 더하고 각 지수의 최댓값을 유지한다. \((\log2,\log B,\log W,\log M)\)의 최대 계수 벡터는 \((69106,10145,437,1594)\)다. \(\log2\)를 두 번 사용하여 Lean에 들어가는 다섯 가중치를 \((65536,3570,10145,437,1594)\)로 나눈다. 각 로그는 \(H/2^{128}\) 이하이다. \(\log B\le B\)에는 같은 원본 문턱을 적용하고, \(\log W\)와 결합 부등식은 GitHub에서 컴파일한 두 정리를 적용한다. 이 범위에서 **Primary·초기 평균의 곱과 변분 계수**에 대한 로그 상계는 \(H/2^{109}\)다.

원본 강제항 자체의 기하 배수와 모드별 양의 \(\epsilon\) 최소 멱은 별도 geometry 재현에 있다. 위 결과에는 명시적으로 남는 \(S\), \(d\), \(k\), \(\epsilon\)의 결합, 압력과 Initial Mean의 전 구간 접합, 전체 보정 후 에너지와 수렴 인증이 필요하다. 안쪽 및 중간 영역은 OPEN이다. N7-06, N8-05와 최종 jet 67개의 수락 상태는 OPEN이다.
