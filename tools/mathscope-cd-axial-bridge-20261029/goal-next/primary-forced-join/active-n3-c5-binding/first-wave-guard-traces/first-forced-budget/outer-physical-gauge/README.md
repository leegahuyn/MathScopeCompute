# 첫 Forced의 바깥 물리 잠재장과 단계 1 에너지 기여분

## VERIFIED

실제 원본 첫 Forced 잠재장 120개, 참조 행 162개와 Cartesian 공간 미분근 30개를 두 번 재생했다. 두 결과가 바이트 단위로 일치했다. 위상, 펄스 cutoff와 \(n\times t_m/(mk|n|^2)\)를 원본에서 지켰다. \(Y\) 두 번의 미분이 있는 항 45개의 원본 계수는 \(a_{\rm ref}^2\)와 물리 방향의 삼각함수, 원래 보조 좌표 방향의 \((1,2v_{r,1},v_{r,1}^2)\)를 포함한다. 실제 토러스 미분은 \((R,Z,L)\)의 \((0,0,2)\)를 추가로 요구한다.

새 \(L^2\) Forced 요청의 모드 1은 초기 평균 \(L^3\)을 사용한다. 원본 C91 재귀를 그 차수까지 적용해 공분산 요청 600개에 네 개를 추가했다. 새 요청은 느린 1차, \(L\) 6차 이하로 기존 Primary 외피 안에 있다. 이동 primitive 역할 153개는 동일하며, 고정 Fourier 요청 역할은 169개에서 171개가 된다. 모드 2는 두 Primary만 필요하다. 두 모드의 새 순수 \(L^2\) 변분은 C94의 계수 예산과 \(\varepsilon^{99999/100000}\) 지수를 유지한다.

원래 \(D_r=\partial_R+a_{\rm ref}L\), \(D_z=\varepsilon\partial_Z\), \(D_\theta=R^{-1}\partial_\theta\)를 적용하고 \(L(v)=L(\phi)=0\)을 사용했다. 펄스 \(P(v)\)와 cutoff는 이 세 공간 방향에서 일정하다. 실제 \(R^{-1}\) 미분, Cartesian 방향의 삼각함수 미분과 벡터 회전을 전개했다. 한 미분이 위상과 방사 빠른 연산을 각각 한 번씩 소비하는 항은 없으며, 두 비용을 합친 최악 지수는 \(-1/2\)씩이다.

## CONDITIONAL

원본 \(q_{\rm Big}/64\le q<q_{\rm Big}/16\), \(0<d=\log(X_b/X)\le1/4\), 고정 라벨과 정수 복사본에서 원래 프레임·공분산, 원본 짧은 적분의 범위와 같은 차트의 정칙성을 사용한다. \(q=Qs\), \(s\in[1/2,2]\)를 원본 라벨마다 적용한다. \(Q^{1/2-A}\)에 물리 미분 \(Q^{-r/2}\)를 곱하고 기존 \(q^{1/2-A+h/10-rs_x}\)로 나눴다. 여기서 \(s_x=1/2+h/2\)다. \(1/(mk)\le\sqrt\varepsilon\)와 공간 미분 한 번의 \(\varepsilon^{-1/2}\)를 포함하면 모든 \(r=0,1,2\)에서 최종 지수는

\[
(1-1/100000)+1/2-1/10-1/100000=69999/50000
\]

이다. 따라서 원래 라벨을 합친 이 잠재장 기여분의 공통 \(K_1\) 외피는 \(e^{-H/2}\) 이하이다. \(X_b\le R_{\rm env}^2\), \(\log B_{\rm norm}\le H/2^{128}\), \(\log 2\le H/2^{128}\)를 적용하면 \(e^{-H/2}<2^{-36}X_b^{-2}e^{H/10}\)이다. 이는 기존 단계 1 잠재장 배정치 \(2^{-33}X_b^{-2}e^{H/10}\)의 \(1/8\)보다 작다. 실제 물리 정규화와 엄격 로그 비교는 GitHub에서 컴파일했다.
