# 안쪽 첫 Forced의 전방 압력 적분과 에너지

## VERIFIED

원본 안쪽 정칙 표적의 두 성분 \(\#119712,\#119713\)을 실제 생성기에 결속했다. 원본 내부 활성화의 정칙 인자는 이 두 본문 안에 이미 있다. \(u=\log(X/X_a)/t_1\)로 쓰면 분리하는 지수는 정확히 \(\exp(-1/u^2)\)다. 수치 상계에서 \(0<u\le1/4\)를 쓴다. \(t_1=C_{\rm Selected}^{-120}\), \(X_a=4/\Lambda\)와 원래 \(R_{\rm env}\) 계층을 그대로 사용한다. 원래 양의 방향 cone 조건에서 정칙 표적의 투영 하한은 \(R_{\rm env}^{-55}\), 물리 8차까지 상계는 \(2^{4096}B_{\rm norm}\)이다.

실제 압력 \(\#17754234\)에서 바깥 적분을 고르는 cutoff는 안쪽에서 0이다. 따라서 두 전방 적분 \(\#17753667,\#17754191\)의 같은 원본 보조 좌표 이동을 유지한다. 고정 \(Z,T\)에서 \(s\)와 \(q\)는 방사 이동과 독립이다. \(r\le R\)이면 \(X(r)\le X(R)\)이고 \(\chi\)의 인자는 원래 zero 구간에 있다. 물리 지지 밖의 낮은 반지름은 원본 영연장을 쓰며 \(\partial_R T_0 f=f-aL T_0f\)를 유지한다. 실제 전방 cutoff와 반대쪽 Gaussian의 기하 부등식을 Lean으로 확인했다. [GitHub 실행](https://github.com/leegahuyn/MathScopeCompute/actions/runs/44642679434).

두 방사면의 실제 Gaussian은 \(\zeta(x)=\exp(-1/x^2-4/(w-t_1 x)^2)\)이고 \(w=\log(X_b/X_a)>2\)다. \(0<x\le u\le1/4\)에서 \(z=x^{-2}-u^{-2}\)로 바꾸면

\[
 \int_0^u e^{-1/x^2}x^{-p}\,dx
 =\tfrac12e^{-1/u^2}u^{3-p}
 \int_0^\infty e^{-z}(1+u^2z)^{(p-3)/2}\,dz .
\]

\(n=\max(0,\lceil(p-3)/2\rceil)\)을 사용해 오른쪽 적분을 \((n+1)n!\)로 제어한다. 끝점에서 반대 Gaussian의 복원비는 \(e^2<9<16\)으로 제어된다. 실제 이동 적분의 \(dr=(t_1r/2)\,dx\)는 원본 반지름 상수에 포함된다. 따라서 정규화 적분은 \(\zeta(u)u^{3-p}\)에 유한 계수를 곱한 값으로 제어된다.

실제 초기 평균 재귀의 각 원래 항을 대조했다. \(L^3\)를 포함한 결과, 전방 적분 입력 극점은 \(12,15,18,21,24,27,30\)이고 한 계수항에 전방 적분은 두 개까지다. 두 끝을 보존하는 공통 계수는 \(n=14\)에서 \(10461394944000\)이다. 공분산 입력 604개, 이동 적분 153개, Fourier 역할 171개를 원래 형태로 유지했다.

## CONDITIONAL

안쪽의 원래 고정 차트·양의 방향과 공분산·펄스 전파자, 실제 참조 경로 및 방사 영연장을 가정한다. C92의 동일 유리수 계수 재귀에 안쪽 정칙 표적, 압력 전방계수와 \(u\) 미분비를 대입했다. 원본 두 모드의 폐합된 물리 방향과 C95의 0–2차 Cartesian 잠재장을 사용했다. \(g_i=e^{-1/(2u^2)}u^{-3/2}\)는 정칙 인자를 분리한 후 쓸 수 있는 **상계용** 가중치다. 그대로 남는 \(u\) 극점은 \(\zeta^{1/4}\)에서 \(4^n n!\)을 사용해 흡수했다. 양의 \(\varepsilon\) 지수와 밴드·좌표·적분의 비용을 한 번에 합산한다.

같은 실제 \(q_{\rm Big}/64\le q<q_{\rm Big}/16\)에서, 이 물리 잠재장의 단계 1 정규화 지수는 \(\varepsilon^{69999/50000}\)이다. 기존 cutoff를 적용한 첫 Forced의 안쪽 적분은 \(J_{\rm inner}^2/S_R<2^{-32}\)이다. C95 바깥쪽은 별도 구간이고 두 부분이 겹치지 않으므로, 원래 적분의 기여를 합하면 \(J_{\rm inner\cup outer}^2/S_R<2^{-31}\)이다. 원본 속도와 cutoff의 미분을 먼저 계산한 뒤 각 영역의 적분을 합친다.
