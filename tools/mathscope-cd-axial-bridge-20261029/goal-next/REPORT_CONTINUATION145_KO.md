**검증 브랜치의 원본 Y 범위는 142/523입니다. 운영 장부의 Y는 33/523입니다.** M3 62/64, 운영 M4 0/16, 최종 jets 0/67 및 RELEASE HOLD를 유지합니다.

## VERIFIED

- 원래 523개 행의 판정 기준인 실제 방사 인자의 `0≤Y≤5`를 적용했습니다. 원본 첫 FiveMap의 4,420,257개 AST 레코드와 등록 정의를 대조했습니다. 원래 Node 실행기와 독립 Python 경로 검사가 109개 추가 행에서 일치했습니다.
- 추가 109개는 18개 고정 적분군에 속합니다. Python은 물리 루트 11개와 원본 정의 진입점 1,745개에서 각 행으로 가는 모든 경로를 검사했습니다. 각 행에는 원본 적분의 올바른 바인더와 경계가 적용됩니다. `#10219`에 바인더 없는 경로를 추가한 대조군은 거부됐습니다. 33개 기존 행, 109개 추가 행, 381개 미해결 행의 정확한 원본 ID와 인자를 보관했습니다.

## CONDITIONAL
