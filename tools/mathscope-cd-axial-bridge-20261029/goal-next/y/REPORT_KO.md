## 동일 원본 창과 직접 역함수

원본 스트림의 `#617433`은 `ℓ₀ = 6 + C`, `#617465`는 `log b₁`, `#617514`는 `log b₂`이다. 두 `maximum`에는 각각 `(10 + C) log 2`와 `log b₁ + log 16`이 들어 있다. 따라서 원본 N=1 창의 하한 `#622785`와 상한 `#622790`은 다음 식을 만족한다.

```text
L = max(ℓ₀, floor(log₂ b₁)) = floor(log₂ b₁) ≥ ℓ₀ + 4
U = floor(log₂ b₂) − 1 ≥ L + 3
```

같은 창에서 `ℓ = L + 2`, `Q = 2^(−ℓ)`를 선택한다. 원본 정수 식으로 지정한 라벨이다. 모든 `1/2 ≤ s ≤ 2`에서 `q = Qs ≤ 2^(−ℓ₀−5) < qGlobalStar`이고 `b₂q ≥ 2`다. 마지막 부등식은 `b₂ ≥ 16b₁ ≥ 2^(L+4)` 및 `q ≥ 2^(−L−3)`에서 나온다.

`source_image`는 `s ∈ [1/2, 2]`, `|η| ≤ 1`, `X ≥ 0`에서 원본 `#622791`, `#622802`, `#622803`, `#622804`에 아래 정확한 식을 넣는다.

```text
R = sqrt(2sX), Z = s^D η, T = s(1 − η²), D = 1/2 − h.
(r, z, τ) = (sqrt(Q) R, Q^D Z, QT).
```

이는 소스의 실제 물리 좌표 변환과 일치한다. 원본 `h = exp(−8002(exp(1048576) + 10))`에서 `0 < h < 2^(−4096)`이고 `2D + 2h = 1`이다. `#622820`의 native system 2는 `#622819`의 `F(u) = u − Z²u^(2h) − T`를 이 Z, T에서 평가한다. 대입하면 `F(s) = 0`이다. `Z² ≤ 2^(1−2h) < 2`이고 브래킷 안의 모든 `u ∈ [1/2, 2]`에 대해 `u^(2h−1) ≤ 2^(1−2h) < 2`이므로 다음 하한이 성립한다.

```text
1/2 < 1 − 8h ≤ F′(u) = 1 − 2h Z²u^(2h−1) ≤ 1.
```

따라서 두 끝점 부호를 만족하고 해는 유일하며 양수다. 이 도함수 하한은 이미지에서 얻은 Z의 상계에 의존한다.

이미 원본 ℓ을 선택한 경우 `physical_ingress`의 `selected_ell`은 그 라벨을 직접 검사한다. 선택값이 없는 경우 같은 N=1 창 안에서 q의 전 구간을 포함하는 가장 작은 정수 ℓ을 고른다. 정확한 실수에서는 같은 창 안에 후보가 존재하는 범위가 `[2^(−U−1), 2^(1−L)]`이고 여기에 `q < qGlobalStar`를 요구한다. 유리수 구현은 소스의 실제 정수 창 값이 외부에서 결속되었을 때 적용한다. 유리수 구간으로 판정할 수 없는 경계 입력은 거절한다. 상징적 `source_image`에는 원본 라벨 `#622785 + 2`가 직접 들어 있다.

## 활성 상대 라벨과 원본 대표점

`#625157`은 `−log₂ q`다. 상대 후보는 `floor(−log₂ q + 1/2)`와 그 양옆의 두 정수다. 행 본문을 평가하기 전에 바깥 가드가 `|−log₂ q − ℓ′| < 3/4`를 검사한다. 따라서 `s′ = q/Q′ ∈ (2^(−3/4), 2^(3/4)) ⊂ (1/2, 2)`이다. 기준 라벨이 `ℓ = L + 2`인 위 범위에서는 활성 `ℓ′ ∈ [L+1, L+3]`이므로 같은 원본 N=1 창에 속한다. 원본 비율 `k = Q/Q′`은 `R′ = k^(1/2)R, Z′ = k^D Z, T′ = kT`를 만든다. 따라서 `Z′ = (s′)^Dη, T′ = s′(1 − η²)`이고 `R′²/(2s′) = R²/(2s)`이다.

세 원본 indexed materializer는 행의 실제 인자와 본문을 `expressionValue` 노드로 만들고 이를 `choose(x, l, r, 0, body, 0)`의 안쪽 분기에 넣는다. 마지막에 추가하는 상대 밴드 가드가 가장 바깥에 있다. 원본 `smooth_piecewise`는 조건과 경계를 평가한 다음 한 분기만 평가한다. `x = l`이면 앞 분기, `x = r`이면 뒤 분기이므로 두 정확한 경계 모두 0이다. 행의 실제 인자도 본문 쪽 native 호출의 피연산자여서 비활성 행에서는 평가하지 않는다. 이 순서는 materialized 실수 소스의 평가 순서다. 기존 primitive 진단 평가기는 raw M3 native 연산 전체를 실행하는 수치 평가기가 아니다.

활성 행의 세 메쉬 가드는 실제 후보 좌표에 `ℓ′^6`을 곱한 뒤 `#623855..#623857`의 라벨을 빼서 검사한다. 각 좌표의 열린 반폭은 `3/(4ℓ′^6)`이다. 셸 가드는 실제 후보 `X = R′²/(2s′)`에 대해 `X_a < X < X_b`를 요구한다. 원본 support-order 증명에서 `0 < X_a < X_b`다. `#623935 = system2(#623921, #623934)`의 브래킷은 이 실제 활성 상자에서 다음처럼 닫힌다. 아래 R, Z, T, s는 해당 후보 좌표를 뜻한다.

1. 반경, 축방향, 시간 상자를 각각 `(R_l, R_u)`, `(Z_l, Z_u)`, `(T_l, T_u)`라 한다. 실제 활성점은 `R > 0, X_a < R²/(2s) < X_b, 1/2 < s < 2`를 만족한다. 이에 따라 원본 `#623875`의 `s_l = max(1/2, max(0, R_l)²/(2X_b))`와 `#623882`의 `s_u = min(2, R_u²/(2X_a))` 사이에 엄격히 있다. `#623883`의 양수 연장 `max(s_l, s_u)`는 여기서 `s_u`다. 시간에 대해서는 `T_l⁺ = max(0, T_l) ≤ T < T_u`이다.
2. `f_Z(u) = u − Z²u^(2h)`는 실제 활성 Z에서 브래킷 전체에 걸쳐 위 도함수 하한을 만족한다. `f_Z(s_l) < T < f_Z(s_u)`이므로 `Z² > (s_l − T_u)/s_l^(2h)` 및 `Z² < (s_u − T_l⁺)/s_u^(2h)`이다. `T = 0`에서도 두 부등식은 엄격하다. 원본 `#623891`과 `#623898`이 이 투영 경계다.
3. `#623921`은 두 부호별 축 구간과 `[Z_l, Z_u]`의 교집합을 사용한다. 음의 구간 너비가 양수면 그 중점, 그 밖에는 양의 구간 중점을 고른다. 실제 활성점이 두 제곱 부등식을 엄격히 만족하므로 적어도 하나의 교집합 너비가 양수다. 활성 `Z = 0`에서는 아래 제곱 경계가 음수이며, 열린 축 구간이 0 근방에서 양의 너비를 보장한다. 선택한 중점 `Z_rep`은 두 제곱 부등식을 모두 엄격히 만족한다.
4. `Z_rep² < (s_u − T_l⁺)/s_u^(2h) ≤ s_u^(1−2h) ≤ 2^(1−2h)`이므로 `f_Zrep` 역시 브래킷 전체에서 증가한다. 투영 부등식은 `f_Zrep(s_l) < T_u`와 `T_l⁺ < f_Zrep(s_u)`를 준다. `#623934`의 실제 중점은 두 시간 구간 교집합 내부에 있다. 따라서 `f_Zrep(1/2) < T_rep < f_Zrep(2)`, `s_l < s_rep < s_u`, `T_rep > 0`이다. `#623955`에서 `η_rep = Z_rep/s_rep^D`이므로 `η_rep² = 1 − T_rep/s_rep < 1`이다.

실제 원본 활성 상자의 한 점은 `ℓ = L + 2, s = 1, η = 0, X = (X_a + X_b)/2`로 주어진다. 중심 라벨 `ℓ′ = ℓ`에서 `g_T = ℓ^6, g_Z = 0, g_R = floor(ℓ^6 sqrt(2X) + 1/2)`로 고른다. 반경 메쉬 오차는 `1/2` 이하라서 `3/4`보다 작다. 이 점의 `#623935`는 위 중점 증명을 적용할 수 있다. 원본의 초대형 스케일에 근삿값을 대입하지 않았다.
