# MathScope C142 참조 전환과 Fourier 비교

**공식 판정 M3 62/64 (96.875%), M4 0/16, Y 33/523, 최종 jets 0/67. RELEASE HOLD.**

## VERIFIED

- 원본 단조 역함수에서 `Z=±1,T=0`의 정확한 루트 `s=1`과 양쪽 η 끝점을 재현했습니다. `(Z,T)=(5/4,-9/16)`도 엄격한 브래킷 안에서 같은 양의 루트와 검증 가능한 양의 도함수를 갖지만 `η=5/4`라서 원본 물리 영역 밖입니다. 이 재현은 양의 루트와 브래킷만으로 물리 영역을 판정하는 방법의 반례입니다.
- 참조 전환에서 원래 정수 토러스 변환 `Jg`를 적용하는 경우 현재 두 `K=1` 정사각형에 공통으로 전송되는 영이 아닌 모드가 없습니다. 정수·이차체 연산으로 289개 덮개 문자 합, 576개 Fourier 항 등식과 64개 절단 쌍을 검증했습니다. 런타임의 진단 한도 안에서는 `(K_a,K_b)=(6,1),(7,1),(8,1)`에서 비교 대상을 상응 모드로 제한하면 b 쪽 반경 1의 정사각형 전체를 유지할 수 있습니다.

## CONDITIONAL

- 원본 중심화 소스가 두 물리 차트에서 토러스 덮개로 결속되면, 덮개 영상 밖의 Fourier 계수는 0입니다. 대응하는 유한 역함수는 정확히 같은 물리 모드를 비교하며, 원래 시간 계수로 나누면 속도의 스케일이 보존됩니다. 실제 최종장 계수의 수치값 및 Fourier 꼬리 상계가 계속 필요합니다.
