# MathScope C139 검증 결과

**M3 62/64 · M4 0/16 · Y 33/523 · 최종 jets 0/67 · RELEASE HOLD.** 이 수치는 원래 승인 장부의 판정이며, N7-06과 N8-05의 승인 및 최종 전체장 독립 비교 0/4는 그대로입니다.

## VERIFIED

- 같은 참조 차트에서 최근접 밴드와 격자가 전환될 때, 절대 라벨과 guard, 색상과 토러스 중심이 보존되는 원본 규칙을 확인했습니다. 양·음의 큰 정수 제어를 포함해 정확 분수로 1,536개 경우를 재생했습니다. 빠지는 행과 들어오는 행의 cutoff는 전환 근방에서 0입니다.
- 참조와 무관한 물리 스케일 방정식의 양의 해가 존재하고 유일하다는 정리와 고정 참조의 인접 격자 합이 같다는 보조정리를 GitHub에서 컴파일했습니다. 앞선 두 전체 검사는 같은 라벨 타입 오류로 실패했고, 정수 타입을 명시한 실행에서 두 정리가 통과했습니다. [GitHub Lean 성공 실행](https://github.com/leegahuyn/MathScopeCompute/actions/runs/44706088351)
- 실제 Repeat 내보내기의 원본 레코드 22,380,596개를 독립 Python 재생으로 두 번 검사했습니다. 뿌리 1,444개의 경로에서 자연급수 호출 567개를 재현했고, 핵심 원본 검사는 formal→actual 인자 전달 1,694개를 확인했습니다. [원본 전체 내보내기](https://github.com/leegahuyn/MathScopeCompute/actions/runs/44682703381)
- M4 격리 후보의 인증된 저장본에 대해, 보관한 배포 입력에서 제공자 저장 아카이브를 바이트 단위로 재생했습니다. 현재 호스팅 화면의 두 예제를 다시 실행해 보관된 입력·결과·Worker 해시와 일치함을 확인했습니다. 제공자 삽입 부분이 달라진 HTTP 응답에서도 원본 후보 본문은 동일했습니다.

## CONDITIONAL

- 한 참조 차트 안에서는 공통 절대 행의 원본 본문과 미분이 실현될 때 전환 양쪽의 같은 국소함수가 얻어집니다. 인접 참조 라벨 교체에 대해서는 원래 물리 스케일, 정수 토러스 사상, 펄스 경로, 유속·압력 가중치와 Fourier 역연산의 정확한 극한에서의 전달 법칙을 결속했습니다. 같은 크기의 유한 Fourier 상자는 이동과 교환되지 않습니다. 원본 정수 행렬에서 모드 (1,0)은 (3,1)이 되므로 크기 1의 유한 상자에서 빠집니다.
- 참조 라벨 교체가 원본 계수 창의 변경도 일으키면, 공통 열린 구간에서 추가되는 차수의 원본 cutoff는 모두 평탄한 0입니다. 여기에는 반경 항의 cutoff 미분도 포함됩니다. 이 결과는 같은 원본 계수 계열의 배경과 공분산 목표항에 적용됩니다.
- 원본 차트의 양의 해가 정의되고 원래 반복 구간의 하한 부호를 유지하면, 내보내기의 자연급수 호출 567개 모두에서 필요한 범위를 검증했습니다. 양의 해 구간 조건을 제거하면 네 호출이 열리고, 원본 반복의 왼쪽 하한 부호를 제거하면 158개가 열립니다. 무한 차수 일반화와 실제 수치 등식은 별도입니다.
- 실제 원본의 고정 라벨 반경 (C^1) 결론은 C137–138의 조건에서 유지됩니다. 인접 참조 차트의 전체 평균과 고정 끝점 적분에서 같은 물리적 지지와 양쪽 경계 trace를 연결해야 전역 교체를 승인할 수 있습니다.
