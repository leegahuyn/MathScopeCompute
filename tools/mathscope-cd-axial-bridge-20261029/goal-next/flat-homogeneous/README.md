graph and registry archive. The Python script streams every graph node.
Run with assertions enabled.

```text
python bind_homogeneous_cutoffs.py --repo MATHSCOPE_GIT_CHECKOUT --graph ORIGINAL_SOURCE_NODES.jsonl.gz --registry ORIGINAL_SOURCE_FUNCTIONS.json --projection ../cycle/group-postfive-residual.json --forced ../flat/forced-principal-cutoffs.json --out homogeneous-principal-cutoffs.json --controls-out controls.json
```

rejected. No private source seal, complete F[1] decomposition or numerical
