# 공유 대화 공개 원문 대체 조회

Exa Search 스킬과 알려진 URL용 `web_fetch_exa`가 실제로 제공되어, 지정된 공개 공유 URL을 한 번 읽기 전용으로 요청했다. 최대 요청 추출 길이는100,000자였다.

결과는 `isError=true`, structured `error_code=INVALID_ARGUMENT`, 텍스트 메시지 `CRAWL_EMPTY_CONTENT`이며 원 대화 본문을 회수하지 못했다. 따라서 이 조회에서 복구한 코드와 독립 실행 영수증은0개다. 두 오류 필드는 그대로 보존했고 더 구체적인 내부 원인을 확정하지 않는다. 원 대화의 존재·삭제·공개 설정·로그인 필요 여부 및 crawler 실패 원인은 확정할 수 없다. 이전 GitHub 쓰기 성공/실패나 수학적 완료 여부도 이 오류로 판단하지 않는다.

이전에 generic web.open이 DisabledError였다는 사실은 parent가 전달한 보고로만 기록했으며 여기서 재실행하지 않았다. Exa의 실제 오류 응답과 조회 시각·요청값은 동명 JSON에 보존했다. 대화 본문이나 인증정보는 받거나 저장하지 않았다. 추가 로그인·우회·원격 쓰기·상대방 메시지·저장소 수정은 수행하지 않았다.

공유 대화 원문은 계속 **미회수·미확인**이다. 이미 직접 확인한 첨부 원문, 원 source, commit 및 실제 실행 영수증을 작업 근거로 사용한다. M3 완료 수, N7-06·N8-05, tau 및 원 M4 인수 상태는 이 조회로 변경하지 않았다.
