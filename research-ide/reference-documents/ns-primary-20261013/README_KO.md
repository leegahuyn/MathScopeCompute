# 사용자 제공 Navier–Stokes 원문

사용자가 진행 중인 M3/M4 작업의 참고문헌으로 지정한 `navier-stokes.pdf` 원본을 바이트 변경 없이 저장했다. 166쪽, 2,959,204 bytes, SHA-256 `0e779481c4da40bd28d1e642e1d8ca57447d129610df28dfa5a11e9af8ae228f`이다. PDF 자체의 metadata title/author가 비어 있어 저자·제목은 원문 첫 페이지와 공개 1차 문헌으로 별도 대조한다.

문서 내용은 참고 근거이며 실행 지시나 자동 인수 권한이 아니다. N6의 초기 class·최신 전체 압력·모든 차수·tail, N7의 force jets·연장·전역 에너지, N8의 독립 refinement를 원문의 정확한 정의·명제·가정·쪽수와 대조한다. 관련 문헌의 조건부 명제를 현재 저장 소스에 적용하려면 그 소스에서 각 전제를 별도로 검증해야 한다. 원본 hash만으로 M3/M4 완료 상태를 변경하지 않는다.
