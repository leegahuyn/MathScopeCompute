# 실제 양의 차수 전역 응력 소거

## 완료 범위

`actual-positive-global-stress.mjs`는 원래 계수 생성기가 만든 모든 요청된 양의 차수에 대하여, 압력의 방사방향 식과 두 접선방향 운동량 계수의 소거를 결속한다. 각운동량·축운동량의 원래 잔차식은 실제 그래프 노드로 그대로 보존한다. 잔차를 0으로 정의하거나, 별도 외력을 추가하거나, 전체 적분의 값을 입력으로 받지 않는다.

이번 실행에서는 같은 생성 과정에서 나온 실제 `n=1,2`를 검사했다. 일반 차수의 대수는 `nu`를 부정원으로 남기는 별도 커널과 원래 Picard 계수 생성기의 임의 유한 차수 재귀에 연결한다. 1·2차의 유한 실행만으로 무한히 많은 차수를 시험했다고 주장하지 않는다.

0차 선도 응력 식, 공통 무한 cutoff 선택, 물리 잔차의 모든 차수 평탄성은 각각 별도 결속이다. 이 모듈 단독의 `wholeGN4Complete`, `m3MayStart`는 `false`이다. 새 Lean 커널 증명을 생성했다는 주장도 하지 않는다.

## 보존형 식과 다섯 실제 모멘트

원래 원통좌표의 `X=R²/2`를 사용한다. `theta_n`은 소스의 `r_theta,n/R`, `z_n`은 축방향 원래 잔차이다. 각 차수에서 검증된 전역 모멘트의 밀도는 다음과 같다.

| 모멘트 | 완전한 전역 밀도 |
|---|---|
| `m_n1` | `U_n` |
| `m_n2` | `2 X F_n` |
| `m_n3` | `Pi_n,X` |
| `m_n4` | `2 X sum_(i+j=n) U_i F_j` |
| `m_n5` | `sum_(i+j=n) U_i U_j - X Pi_n,X` |

모든 합에는 원래 순서 있는 쌍 `i+j=n`을 빠짐없이 넣는다. `actual-global-conservative-moments.mjs`의 비공개 seal을 검사한 뒤 그 모듈이 증명한 실제 전체 적분과 실제 연속 모멘트 방정식만 사용한다. 전역 선도 유동 `M0`의 누적 적분, 양의 차수 `M_n/X` 평균, 압력의 원래 primitive가 함께 유지된다.

커널은 `nu`를 부정원으로 두고 `mu=nu-2h`를 정의한다. `Tbar_a f=(-a f+D eta f_eta)/L`, `Zbar_a f=(2a eta f+d f_eta)/L`이면 실제 경계항과 연속방정식의 결함을 별도로 남긴 보존형 항등식에서 다음 전체 모멘트 식을 얻는다.

```text
Integral 2X theta_n
 = Tbar_(1-h+nu) m_n2
 + Zbar_(1/2-2h+nu) m_n4
 - Zbar_(1/2-2h+nu) Zbar_(1-h+mu) m_(n-1)2

Integral z_n
 = Tbar_(D+nu) m_n1
 + Zbar_mu m_n5
 - Zbar_mu Zbar_(D+mu) m_(n-1)1.
```

`nu=2nh`를 대입하면 모든 양의 정수 차수에 적용된다. `h`는 원래 양의 정확한 식 그대로이다. 커널에는 압력 부분적분에서 생기는 `X Pi_n` 경계항, 방사방향 점성의 경계항, 낮은 차수 축방향 점성의 두 번 미분 및 경계항이 모두 들어 있다. 연속방정식 결함도 일반 항등식에서 자동으로 버리지 않으며, 같은 소스의 전역 질량 primitive가 이를 0으로 만드는 근거를 제공한다.

원래 선도 질량 모멘트는 `M0_X=U0`, 정칙한 축에서의 `M0(0)=0`, 실제 닫힌 외부에서의 `M0(Xv)=0`으로 얻는다. 이 단계에서 `M0/X`를 축에 대입하지 않는다.

### 1차 각운동량의 필수 조건

`n=1`에서 낮은 차수 각운동량 적분은 발산할 수 있는 고립된 `Integral 2X F0`가 아니다. 원문의 (5.19)에 있는 **완전하고 수렴하는 물리적 뺄셈 모멘트**를 사용한다. 고정 순수 멱 함수의 물리적 `z` 미분은 0이며, 실제 terminal collar 바깥에서는 완전한 열 프로파일도 물리적 `z`와 무관하다. 따라서 해당 뺄셈 모멘트의 두 번 `z` 미분이 원래 각방향 점성 전체 적분을 준다.

`actualLeadingSubtractedAngularProof`의 원래 A.2 angular reset, A.13 terminal wait, B8/I1 수정, I2 및 완전한 열 보상을 모두 포함한다. 열 변화와 I2 변화의 합이 0이라는 사실만으로 원래 적분상수까지 소거했다고 간주하지 않는다. 소스 그래프가 달라지지 않도록 공통 원래 prefix 위의 새 대수 노드만 이름 공간을 구별하여 복사한다. 기존 opaque 함수는 재구성하지 않는다.

## 원래 응력 적분의 양 끝 결속

각방향 원래 forward 응력은 `-Integral_left^X (2t theta_n) dt/(2X)`, 축방향은 `-Integral_left^X z_n dt/sqrt(2X)`이다. backward 식은 같은 밀도를 `X`부터 원래 오른쪽 끝까지 적분한 양의 부호의 식이다.

`actualPositiveStressFTC`로 원래 forward 식 자체를 미분한다. 새 모듈은 backward 식의 원래 적분 밀도·두 끝점·분모·부호를 독립적으로 비교한다. 일반 split 항등식은 `backward-forward=whole/denominator`이며, 전체 적분을 먼저 0으로 증명해야 두 식을 동일시할 수 있다.

안쪽에서는 `Xminus<Xkeep`와 원래 Picard 방정식, 같은 압력 및 질량 primitive를 사용하여 잔차가 열린 축 근방부터 `Xminus`까지 0임을 결속한다. 바깥쪽에서는 실제 전체 적분이 0이고 원래 밀도가 끝난다는 사실로 backward 식과 모든 고정 차수 미분의 0 연장을 얻는다. 활성 구간의 왼쪽 끝은 양수이므로 축에서 응력 분모를 평가하지 않는다.

`n=1`의 각응력은 선도 열 프로파일의 축방향 점성 때문에 `Xb`까지 간다. 1차 축응력과 `n>=2`의 두 응력은 `Xplus`에서 끝난다. 이 구별은 실제 소스의 끝점을 읽어 확인한다. 압력 소거는 원래 전역 압력의 미분과 독립적으로 조립한 완전한 원심/Omega 밀도의 일치로 결속한다.

## 실행과 검증

`tests/run-positive-global-stress-validation.py`는 실행마다 소스·테스트·runner snapshot을 남기고, 전체 로컬 import 그래프의 실행 전후 SHA-256을 비교한다. 종료 코드를 실제로 관찰하며, timeout을 통과로 기록하지 않는다.

| 실행 | 결과 | 시간 | 자식 프로세스 최대 RSS |
|---|---:|---:|---:|
| 일반 커널 attempt 1 | 5/5, exit 0 | 4.398초 | 213,667,840 bytes |
| 실제 소스 attempt 1, `n=1,2` | 8/8, exit 0 | 33.317초 | 2,131,140,608 bytes |

두 실행 모두 원래 의존 파일 60개가 변경되지 않았다. 실제 소스 검사는 실제 raw 운동량 계수, 선도 질량·뺄셈 각운동량, 다섯 모멘트, signed FTC, 1차 열 collar, 압력 결함, 비공개 seal, 이후 append에도 안정적인 certificate를 포함한다.

일반 커널의 음성 대조는 압력 경계항 누락, 압력 모멘트 부호 반전, 각방향 `2X` 가중치 누락, 직전 차수 점성 누락, 증명하지 않은 전체 적분을 0으로 취급하는 경우를 각각 거부한다. 별도의 비상수 다항식 적분 예는 전체 적분이 실제로 0이 아닐 때 forward/backward가 같아지지 않는다는 점도 검사한다.

완전한 실행 근거와 해시는 `research/evidence/positive-global-stress-20261011/validation.json` 및 해당 attempt 파일에 있다. 원문 기준은 제공된 PDF의 (5.19)–(5.22), 실제 계수 재귀 및 전역 압력·모멘트의 원래 소스이다.
