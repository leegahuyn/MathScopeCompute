# 공분산의 전체 구간 합산: 정확한 제곱분할과 (7.30)

이 모듈은 실제 H의 인증과 분리된 **조건부 대수 보조정리**이다. 모든 실제 파동의 H, 양의 역원, 공통 q*, 보조 토러스 지지집합 분리는 실제 소스 생성기가 별도로 결속해야 한다. 이 파일만으로 N5-06을 PASS로 바꾸지 않는다.

## 하나의 매끄러운 분할을 모든 정수에 적용

기존 실제 대표점 계산에서 사용한 동일한 함수 b를 사용한다. |t|≤1/4에서는 1, 1/4<|t|<3/4에서는 원래 source step σ(3/2−2|t|), |t|≥3/4에서는 0이다. 각 정수 j에 대해 χ_j(t)=b(t−j)/sqrt(Σ_k b(t−k)²)로 정의한다. 원래 source step의 양 끝점은 모든 도함수가 0이며, 절댓값의 중심은 상수 1 구간 안에 있다.

어떤 실제 t에서도 가장 가까운 정수를 고르면 offset∈[−1/2,1/2]이다. 이 정수에 대한 상대 인덱스 −1,0,1을 전부 계산한다. |j|≥2인 항은 거리≥3/2>3/4이므로 정확히 0이다. 중심 항의 b≥1/2이므로 공통 분모는 ≥1/4이다. 따라서 세 분자의 합과 공통 분모가 같아서 제곱합은 정확히 1이다. offset=±1/2에서 중심 정수를 바꾸는 것은 같은 절대정수 항들을 다시 이름 붙이는 일이며, 버려지는 끝 항은 이미 정확히 0이다.

band 좌표는 −log(q)/log(2), 각 band의 mesh 좌표는 ell^6·(C_ell−고정 원점)이다. 각 band의 chart가 달라지므로 세 mesh 좌표도 band마다 따로 둔다. 세 band 후보 × 각 band의 3³ mesh 후보를 전개하여 총 81개를 보존한다. 구조적으로 0인 항도 포함한 후보 수이며, 실제로 양수인 항은 최대 16개다. 이 전개는 무한합을 유한 개로 자른 근사가 아니다. 빠진 모든 정수 항이 정확히 0이라는 지지집합 증명을 함께 보존한다.

활성 shell의 한 점에서 cutoff가 0이 아니면 그 점은 해당 mesh box의 지지집합에 있다. 그 점 자체가 B_(ell,a)∩A_ell의 증인이므로 선택된 I_ell로 제한해도 분할 항은 빠지지 않는다. ell0 아래의 band가 실제 q* 영역에서 비활성인지 확인하는 일은 실제 소스 인증기에 남겨 둔다.

## 물리 스케일의 소거

A=1/2+h, ε_beta=Q_beta^h, T0,star_beta=(Q_beta/q)^(A+1/2)T0를 대입하면 Q_beta의 총 지수는 −2A+h+A+1/2=0이다. q의 지수는 −A−1/2=−1−h이다. 이 계산은 h에 대한 유리수 계수의 일차 다항식으로 실행하므로 초소형의 실제 h를 0으로 바꾸지 않는다.

실제 소스가 모든 box에 대해 C(W_beta)=ε_beta T0,star_beta를 제공하면 물리 스케일을 곱한 각 항은 η_beta² q^(−A−1/2)T0이다. 위의 정확한 제곱분할을 한 번 적용하면 전체 합은 q^(−A−1/2)T0이다. β=(ell,a)는 한 box이며, ±는 그 box 내부 H의 두 열이다. ±를 전체 분할 인덱스에 다시 넣으면 합이 정확히 두 배가 된다.

이 항등식은 각도와 Haar 평균을 취한 운동량 공분산에 대한 것이다. 서로 다른 파동의 교차항이 사라지는 조건은 실제 보조 지지집합 분리로 증명해야 하며, 위상별 순간 속도 곱과 평균 공분산을 동일시하지 않는다.

## 경계와 검증 범위

양의 y는 열린 응력 구간 Xa<X<Xb에서 요구한다. 실제 T0=0인 경계에서는 가역 H에 대해 y=0이므로 공분산도 0이다. sqrt(y)의 매끄러운 0 확장은 실제 flat stress의 모든 고정 차수 도함수 상계가 필요하다. 이 대수 모듈은 그 도함수 정리를 대신하지 않는다.

Node 검사 8개는 실제 bump의 중심·연결점·중첩, band마다 다른 mesh, 분할 인덱스 누락·복제, h 지수와 ε 누락 음성 대조, 두 성분의 물리 스케일을 검사한다. 독립적인 BigInt 유리수 정규화 계산도 포함한다. 이는 별도 Python 검사 수나 실제 H 수치적분 검사 수에 합산하지 않는다. Blueprint 검토자가 원문 6.2 및 7.30을 대조하고 별도 프로세스에서 8개 검사를 다시 실행했다.

생성된 분할과 그래프에는 private binding을 사용한다. 행 누락, ± 중복, 전달 과정에서 복제된 객체 또는 원본 그래프 변경은 인증 통과로 취급하지 않는다. 입력 offset 구간, 실제 전체 H와 q*, 모든 box의 label 분리는 최종 실제 소스 생성기가 결속한다.
