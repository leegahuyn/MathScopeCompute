# 원래 양의 profile의 수치 중첩 지수 구간

## 1. 무엇을 실제로 평가했는가

`actual-positive-profile-log-enclosure.mjs`는 고정된 `same-profile-2026-10-10.3`의 원래 매개변수 정의 24개를 literal하게 확인한 다음, 15개의 매우 크거나 작은 양수에 대해 **숫자 유리수와 exp/neg 연산만으로 이루어진 절대 구간 끝점**을 계산한다. 끝점에 원래 expression root, parameter ref, 적분 또는 미평가 원래 함수를 남기지 않는다.

원래 값의 relative tolerance를 보장하는 방식은 아니다. 오차 기준은 명시된 반복 로그 좌표에서의 구간 폭이다. 예를 들어 원래

\[
T=e^{1048576}+10,\qquad h=e^{-8002T}>0
\]

에 대해 \(x=\log(-\log h)\)의 유리수 구간 \([a,b]\)를 계산한 후

\[
\boxed{e^{-e^b}\le h\le e^{-e^a}}
\]

를 반환한다. 두 끝점은 실제 양수이며, 거대한 소수 전개를 생성하지 않아도 정확한 실수 구간이다. \(h=0\) 또는 외부에서 제공한 기호 상수를 대입하지 않는다. \(b-a\le10^{-12}\)라고 해서 \(h\) 자체의 상대 오차가 \(10^{-12}\)라고 말하지 않는다.

실제 정밀도는 192bit directed dyadic arithmetic이다. `logRational`은 \([1,2]\)로 정확히 range reduction한 뒤 atanh 급수와 양의 명시 잔여항을 사용한다. binary64 값은 표시용이며 판정에 쓰지 않는다. \(10^6\) 크기 로그의 binary64 표시 폭은 유리수 계산 폭보다 넓으므로 정식 끝점과 오차 판정은 `lower`, `upper`, `logCoordinateWidth` 문자열이다.

## 2. 원래 큰 상수의 정확한 환원

\(M=1048576\), \(t=e^M\), \(T=t+10\)이라 놓는다. 원래 profile은

\[
P_*=e^{2T},\quad h=e^{-8002T},\quad
Q_{\rm prof}=2^{260}\,2000^2\,e^{64020T}
\]

를 준다. 여기의 \(Q_{\rm prof}\)는 pulse band의 \(Q=2^{-\ell}\)와 다르다. \(a=260\log2+2\log2000\)이면 \(0<a<276\)이고

\[
L=\log Q_{\rm prof}=64020T+a.
\]

원래 선택한 \(C\)는

\[
\log C=Q_{\rm prof}^{200}+10\log(1+Q_{\rm prof}^{300})
=e^{Y}+10\log(1+e^{3Y/2}),\qquad Y=200L.
\]

큰 항만 대입하는 대신 양의 추가항의 비율을 남긴다. \(Y>16\)에서

\[
0<10\log(1+e^{3Y/2})e^{-Y}<(15Y+10)e^{-Y}<1.
\]

마지막 부등식에는 \(e^Y\ge Y^3/6\)와 \(Y^3>6(15Y+10)\)를 쓴다. 따라서 어떤 \(0<\xi<1\)에 대해

\[
\log\log C=Y+\xi=12804000T+200a+\xi.
\]

그러므로

\[
0<\log^3C-(M+\log12804000)<11e^{-M}.
\]

원래 \(C_{\rm axis}\)도 전체 \(+1\)을 유지하면

\[
\log C_{\rm axis}=c_{\rm axis}e^{4161296T}+1,
\quad c_{\rm axis}=64(2^{260}2000^2)^{64}2000^2,
\]

이며 \(\log c_{\rm axis}<64\cdot276+6+16\)이다. 같은 계산이 \(\log^3C_{\rm axis}\)를 \(M+\log4161296\) 근처의 엄밀한 수치 구간에 넣는다.

\[
R_{\rm env}=\exp(C^{25600000})
\]

이므로

\[
\log^4R_{\rm env}=\log(\log25600000+\log\log C).
\]

따라서 \(C\)는 높이 3의 지수 구간, \(R_{\rm env}\)는 높이 4의 지수 구간이다. 작은 \(h,\lambda,t_1,\kappa\)는 마지막 exp의 지수에 음수를 붙이고 씨앗 구간의 양 끝 순서를 반대로 쓴다.

## 3. 유한 오차 예산과 추가 인자

\(\log100000<12\), \(\log25600000<18\), \(\log120<5\) 같은 상계는 \(e>8/3\)와 명시적 정수 거듭제곱 비교로 확인한다. 원래 \(+10\), \(+1\), \(\log(1+Q^{300})\), \(u=2R_{\rm env}^{10}\), \(1+\lceil R_{\rm env}^{50}\rceil\)의 양의 추가항을 보존한다.

\(x=\log\log C=Y+\xi\)라 놓으면 이들 C/Renv 변환의 최종 좌표는 \(\log(x+d)\), \(0\le d<19\)의 형태로 제어된다. \(200\cdot276+1+19<12804000\)이므로 공통의 충분한 여유

\[
0<\text{최종 좌표 보정}<32e^{-M}<2^{-4096}
\]

를 사용할 수 있다. 이 유리수 \(2^{-4096}\)는 실제 양의 잔여항 상한이며 0으로 바꾸지 않는다. directed arithmetic이 이를 한 ulp로 바깥쪽 반올림할 수는 있지만 원래 작은 값 자체를 0으로 바꾸는 것은 아니다.

원래

\[
X_R=110 C^{10}P_*^{10}
\]

도 \(\log X_R=10\log C+20T+\log110\) 전체를 쓴다. 마지막 두 항의 상대 기여를 양의 \(\log(1+\cdot)\) 잔여항으로 제한한 뒤 같은 최종 반복 로그 여유에 넣는다.

## 4. 실제 출력

| 원래 또는 명시적 파생 값 | 구간을 계산한 좌표 | 씨앗의 비교 중심 |
|---|---|---|
| \(T\) | \(\log T\) | \(1048576\) |
| \(h\) | \(\log(-\log h)\) | \(1048576+\log8002\) |
| \(\lambda\) | \(\log(-\log\lambda)\) | \(1048576+\log1000\) |
| \(P_*\) | \(\log^2P_*\) | \(1048576+\log2\) |
| \(Q_{\rm prof}\) | \(\log^2Q_{\rm prof}\) | \(1048576+\log64020\) |
| \(C, C_{\rm axis}\) | \(\log^3\) | 위의 각각 \(12804000,4161296\) 계수 |
| \(C^{100000}\), \(X_R\) | \(\log^3\) | \(1048576+\log12804000\) |
| \(R_{\rm env},2R_{\rm env}^{10},R_{\rm env}^{4096},1+\lceil R_{\rm env}^{50}\rceil\) | \(\log^4\) | 같은 비교 중심 |
| \(t_1=C^{-120}\) | \(\log^2(-\log t_1)\) | 같은 비교 중심 |
| \(\kappa=R_{\rm env}^{-10}\) | \(\log^3(-\log\kappa)\) | 같은 비교 중심 |

각 행은 유리수 좌표 끝점, 그 정확한 폭, 요청 폭 통과 여부, 실제 절대값 끝점의 `exp/neg/rational` 트리를 가진다. 별도 regular 표의 \(\sqrt2,4\pm\sqrt2,4-2\sqrt2,2^{-34}\) 등은 유리수 구간으로 계산한다. 이 regular 상수가 어떤 band의 원래 기하 인자와 같다는 결속은 해당 band adapter가 따로 해야 한다.

## 5. 실행과 제한

정식 기록은 `evidence/positive-profile-log-20261011/`에 있다. parameter source 실행은 실제 고정 정의 24개와 숫자 구간 15개를 확인했고 Node 종료 코드 0을 관측했다. source JSON SHA256은 `67a16a5d4025a54e0c1106320152ad89f3638149895c3a84892d92d00f057b9e`이다. 이 실행은 31.51ms, peak RSS 49,676,288 bytes이며 전체 배경장이나 pulse constructor를 실행하지 않았다. 별도 kernel은 7/7 PASS와 외부 관측 종료 코드 0을 기록했다.

음성대조는 원래 \(h\) 대신 caller가 준 0이나 다른 profile의 주입, parameter/ref가 남은 끝점, 뒤집힌 구간, 복사 객체의 인증, 끝점을 0으로 바꾼 변조와 정밀도보다 좁은 오차 요구를 거부한다. 첫 비정식 smoke에서 비동기 SHA 함수를 await하지 않아 metadata가 JSON이 되지 않는 구현 문제가 있었고, 수학 식을 바꾸지 않고 async 경계를 바로잡은 후 정식 기록을 생성했다.

아직 다음을 평가한 결과로 표시하지 않는다: 공통 selector에 쓰는 실제 FTC norm, 실제 \(\ell\), palette fractional part, \(c_i,L_s,\epsilon,J\), 실제 target \(\tau\). 이를 닫으려면 같은 source norm의 명시적 수치 상계와 실제 band/target 결속이 필요하다. 이 모듈만으로 전체 G-NUM 또는 M2/M3 관문을 완료하지 않는다.
