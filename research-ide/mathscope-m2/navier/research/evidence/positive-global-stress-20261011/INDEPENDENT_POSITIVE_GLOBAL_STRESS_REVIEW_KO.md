# 실제 양의 차수 전역 응력의 독립 검토

검토자는 `/root`이다. 새 생성기와 부호·지수 대수, 실제 다섯 모멘트의 결속, 최종 source 실행 기록을 읽었다. 이 검토는 source 실행을 추가로 수행했다는 뜻이 아니다.

## 확인한 수학

`actual-positive-global-stress.mjs`는 실제 전역 압력의 미분, 다섯 보존 밀도, 원래 양의 차수 재귀를 같은 준비된 소스에 연결한다. 소거할 원래 residual 표현을 보존한 다음, 연속 모멘트 방정식과 내부 미분방정식을 이용한다. 입력으로 주어진 영 잔차나 모멘트 값은 받지 않는다.

각 양의 차수에서 각운동량 적분은 시간 지수 `1-h+nu`, 축 방향 지수 `1/2-2h+nu`를 사용한다. 이전 차수 점성항은 `mu=nu-2h`를 사용한다. 축 방향 운동량에는 `D+nu`와 `mu`가 사용된다. 이 지수들은 `nu`를 독립 변수로 유지한 대수에서도 확인된다. 특정 `n=1,2`의 대입만으로 임의 차수 결론을 주장하지 않는다.

첫 양의 차수의 각운동량에서 필요한 것은 원래 (5.19)의 **완전한 수렴하는 차감 모멘트**이다. 원래 preheat 항, 전체 heat/I2 보정 및 관련 복원항을 유지한다. 발산할 수 있는 개별 leading 경계항을 각각 0으로 놓아 적분하지 않는다. 전체 leading U0 질량과 실제 M0의 축·바깥 경계도 함께 사용한다.

응력의 왼쪽 표현은 음의 forward primitive, 오른쪽 표현은 양의 backward primitive이다. 같은 실제 전체 잔차 적분이 0이므로 두 표현이 같다. 실제 내부 잔차가 0인 영역과 실제 바깥 밀도의 0 영역에서 모든 고정 차수 미분이 붙는다. n=1의 각 방향 바깥 경계 `Xb`와 더 높은 차수의 `Xplus`를 혼동하지 않는다.

압력, 시간항, 수송항, 방사 및 축 점성항을 모두 유지했다. lower-order 모든 ordered pair도 유지한다. 생성된 n1/n2의 결과와 임의 정수 차수의 동일 재귀에 의한 증명 범위를 구분한다.

## 관측된 실행과 범위

최종 source 실행은 **8/8, 관측 exit0**, 33.31702334000147초, peak RSS 2,131,140,608 bytes이다. 독립 유한 대수 검사는 **5/5, 관측 exit0**이다. source 전후 60개 import의 바이트가 같았다는 기록과 현재 바이트를 따로 대조한다.

원본 모듈 SHA-256은 `77227cd74000f5b6d4bec0361106af21d8020b2eee1eb979c1adc9ec3aae97d1`, 대수 모듈은 `c666add7eba6063a9a701c5633f33a81a37b1ed0a4650af19a2142f76b6efb8f`이다. 실제 program graph SHA-256은 `85d3c0daccc7a296208bf8501fb861d4c9a2265ec4d15947671904a79d927c3c`이다.

이 결과는 실제 양의 차수 전역 계수 소거와 응력 접합을 검증한다. 공통 무한 cutoff 수열의 물리 잔차 합, 새로운 analytic Lean 인스턴스, 전체 M2 완료 또는 M3 시작을 이 검토만으로 선언하지 않는다. 원문 64개 기준의 뜻도 바꾸지 않는다.
