# M2 최종 G-NUM 요구 대조 — ns_proof_audit

## 판정과 검토 범위

교정된 실제 source attempt4의 수치 결과를 재개 시점의 G-NUM 요구와 대조했다. **명시된 수치 영역과 표현 계약 안에서는 추가로 빠진 수학적 요구를 발견하지 못했다.** 이 판단은 원래 값의 균일 절대·상대오차를 새로 증명했다는 뜻이 아니다. 아래 정밀도와 좌표의 구분을 최종 관문과 화면에 유지해야 한다.

이 문서 작성 시점에는 교정된 common physical source6의 최종 관측과 공개 화면 검증이 아직 별도의 집계 조건이다. 이 검토가 `wholeM2Complete`를 변경하거나 M3를 시작하지 않는다. 구 지도 attempt3와 이전 원문 64개 PASS는 그대로 역사적 범위에 남는다.

[기계 판독 검토 기록](M2_FINAL_GNUM_REQUIREMENTS_NS_AUDIT.json)에 원문 요구 문서, source4, 수치·물리식 인증, 설치·module·Worker 기록 등 **17개 파일의 해시**와 15개 직접 대조를 저장했다. 무거운 원본 생성자나 Worker를 새로 실행하지 않았다. 정확한 유리수 산술과 SHA 계산만 수행했다. 검토자는 앞선 일부 수학 모듈의 작성자이므로, 이 기록은 요구·범위·출처의 교차 감사이며 모든 모듈에 대한 새 독립 증명으로 세지 않는다.

## 1. 원래 요구와 현재 출력의 대응

기준은 재개 시점의 `m2-continuation-20261011/at-resume-M2_COMPLETION_GATE_KO.md` §3 G-NUM이다. 그 문서는 선언한 원본 입력·영역·정밀도에서 `w`, `w_i`, `w_ij`, `t_i`, `t_ij`, `H_i` 및 필요한 weight/curl 미분의 외향 구간과 전체 오차 예산을 요구했다. 유한 차수 표본을 모든 label의 수치 계산으로 승격하라는 요구는 아니었다.

| 원래 요구 | 교정된 실제 source4 또는 그 인증에 결속된 수치 경로 |
|---|---|
| 두 원래 결합계의 값 `w` | 같은 대표점에서 각 부호 가족의 `wPlus`, `wMinus`를 따로 제공하는 네 VALUE 행 |
| `w_i`, `w_ij` | `a` 18행과 `wMinus` 18행. `a`는 각 결합계의 양의 첫 성분이다 |
| 실제 pulse의 `t_i`, `t_ij` | unweighted `pulse` 54행: 두 부호 × 세 성분 × 아홉 slow 미분 |
| covariance와 weight 미분 | `H` 36행과 `y` 18행. 실제 전체 H·target·역행렬·양의 제곱근의 미분 결속을 유지 |
| 가중 pulse와 fast·mixed 미분 | `weightedPulse` 84행: slow 54행과 `v,vv,Rv,Zv,Tv` 30행 |
| 필요한 실제 전체 curl 미분 | `physicalCurl` 42행: 세 성분의 네 방향 1차와 대칭 2차. 각도 벡터 및 방향 기저의 연결항 포함 |

270개는 위 도함수 행의 합이며 VALUE 네 행은 별도다. 원래 source의 25개 값 계수에는 pulse 여섯 성분, 가중 pulse, H, 역가중치, 중심 진폭, 질량과 행렬식 등이 포함된다. 원래 양의 배율을 적용한 값 구간과 물리 curl 값도 별도로 연결한다.

`wMinus`의 VALUE를 누락하거나 정확한 0으로 바꾸지 않는다. 같은 실제 source의 `B>=2^128`, `S>=B^1024`, `|wMinus/wPlus|<=B^260/S` 및 `0<wPlus<1/2`에서

\[
|wMinus|<2^{-97793}
\]

를 얻고, 192-bit 요청에서는 이를 밖으로 반올림한 `[-2^-192,2^-192]`를 표시한다. 새 계산과 원래 네 성분 ID의 결속은 설치된 source 증거가 담당한다. module·Worker 기록에서 네 VALUE 행과 이 정확한 0 대체 금지를 확인했다.

## 2. 반드시 유지할 좌표·정밀도 계약

**Slow R 표기.** R이 r번 등장한 slow 행은 원래 미분을 먼저 계산한 뒤 `Rsharp^r`를 곱한 양이다. `Rsharp`는 대표점을 평가한 후 고정한다. 이를 배율 없는 일반 `partial_R^r` 값이라고 바꾸어 표시하면 안 된다. 실제 원본 편미분 root, 정규화한 root 및 양의 배율 root가 각각 보존된다. 물리 curl의 42행은 별도의 원래 물리 좌표 인자까지 적용한 공변 미분·Hessian 값이다.

**정밀도.** source4의 최종 도함수 요청은 192 bits, 계수 구간 폭 `1/10^12`이다. 270개 행마다 정확한 유리수 상·하한의 차를 다시 계산하여 저장된 폭과 일치하고 요청 이하임을 확인했다. 모든 해석학적 remainder 반경은 엄밀히 양수다. 양의 배율에는 별도로 384-bit 산술과 명시된 `log^n(value)` 등의 좌표 폭 `1/10^12`를 적용한다. 270개 배율의 좌표 폭도 정확한 유리수로 대조했다.

작은 반복 로그 좌표 폭은 원래 값의 작은 상대폭과 같지 않다. 최종 배율 곱은 원래 표현 대상을 포함하는 닫힌 수치 구간을 제공하지만, 원래 값 자체의 동일한 절대·상대오차 보장은 `false`다. 최종 완료 문구를 “모든 원래 도함수를 원값 기준 12자리 상대정밀도로 계산”이라고 쓰면 원래 실행의 범위를 넘어선다. “명시된 배율 표현의 계수·로그 좌표 오차를 검증하고, 원래 표현 대상의 외향 구간을 제공”한다는 계약을 유지해야 한다.

**개별 양의 보조 인자.** T와 slow partition `eta_beta`의 구간은 거친 양의 경계다. 개별 `precisionMet`는 `false`이며, 이를 요청 정밀도를 달성한 독립 수치값으로 세지 않는다. 이 경계를 실제 식에 곱한 거대한 최종 배율은 자신의 로그 좌표 폭을 별도로 검사한다. h·epsilon·원래 rounding은 0이나 다른 값으로 바뀌지 않는다.

**두 부호 가족과 물리점.** 두 원래 결합계는 같은 slow 좌표와 고정 대표점의 각자 보조 중심 `v=Ls/2`에서 계산한다. 선택한 실제 torus 점에서는 양의 가족 rectangle이 활성화되고 음의 가족 rectangle은 제외된다. 음의 가족의 합성 fast 좌표까지 같은 중심이라는 주장은 하지 않는다. 실제 전체 curl의 값·미분은 이 support 구분을 유지한다.

## 3. 오차 항목과 원본의 실제 연결

source4는 교정된 원문 (6.2)

\[
d_r=2((1+h)\rho_g-h\kappa_s)
\]

와 원래 양의 h 정의를 typed AST로 대조한 기록을 포함한다. 새 역지도에서 대표점, 두 결합계, 전체 H·target·가중치와 270개 원본 도함수를 다시 생성했다. 옛 물리점의 실제 해나 도함수를 새 물리점으로 복사하지 않는다.

완전한 시간 구간의 Gaussian/Riccati·초기층 및 변분 안정성은 source-bound 비교 경계로 처리한다. 이는 `terms:0` 또는 `terms:1`을 실제 무한해로 선언하는 계산이 아니다. 유한 Volterra 근사값을 쓰지 않는 부분은 실제 연속 방정식의 포함 경계가 그 역할을 담당한다. 전체 heat·target 적분의 tail, 수치 quadrature 및 외향 산술은 별도 양의 오차 항목을 유지한다. inverse·sqrt는 실제 H의 조건수 및 양의 weight 하한에 결속된다. phase를 0으로 평가하기 **전에** 실제 전체 curl을 미분하므로 sine remainder의 필요한 미분을 삭제하지 않는다.

선택식 안의 모든 원래 FTC 적분값을 개별 소수로 평가했다고 주장하지 않는다. 원래 첫 selector의 상수는 같은 source의 별도 n1/m5 상계로 제어하며, 원래 역사적·작은 band 항과 A.13 적분을 유지한 선택식 자체를 닫힌 수치 구간으로 둘러싼다. 최종 도함수의 원래 배율은 기호 root만 남긴 상태를 벗어나 숫자 상수와 exp/neg로 이루어진 닫힌 끝점을 가진다.

## 4. 직접 관측한 검증과 남은 집계 조건

교정된 source4는 **8/8, 관측 exit 0, timeout 없음, 1600.967초, peak 5,449,146,368 bytes**다. 시작 119개와 late 131개 import의 현재 SHA가 기록과 모두 일치한다. 원문 torus 식 기록과 source가 참조한 다섯 인증 파일의 SHA도 직접 대조했다.

270개의 양의 배율 root와 원본 표현 대상이 행별로 일치한다. pulse 228행의 대상은 선언된 정규화 slow/fast 미분이고, 물리 42행의 대상은 `physicalValue`다. 두 범주의 서로 다른 의미를 하나의 root 필드로 잘못 비교하지 않았다.

설치 attempt1은 corrected source4의 SHA를 사용했다. module 9개와 Worker 11개 검사가 통과한 기록에서 같은 numerical certificate SHA, 같은 mathematical hash 및 같은 결과 certificate SHA를 확인했다. 네 원래 결합계 VALUE, 270개의 새 외향 곱, 열한 표와 source path가 있는 4210개 값 셀의 결속을 기록한다. 항목명 label 셀이나 모든 UI 상태를 이 수에 포함하지 않는다.

최종 집계에는 다음이 여전히 필요하다.

1. 교정된 common physical source6의 완료와 원문 지도에 대한 G-CURL/G-N5 연결. 수치 source4 한 건으로 전역 물리·flat-error 정리를 대신하지 않는다.
2. 현재 설치된 계산과 같은 공개 bundle·Worker·브라우저·replay의 관측. 이 문서는 직접 공개 화면을 사용하지 않았다.
3. 위 결과를 현재 gate의 명시된 수치 영역·정밀도와 함께 반영하고, 기존 실패·구 지도 성공·원문 64개 범위를 보존하는 최종 집계.

## 5. M3의 원래 순서와 전제

현재 기계 관문의 `P7 → P8`, `Y5 → Y6 → Y7`, `N6 → N7 → N8` 순서와 “사용자가 요청한 M2를 먼저 완료” 조건은 유지돼 있다. P7의 원래 선행 P1·P4, P8의 원래 선행 P1–P4 등 수학적 의존성과 이번 작업 순서를 혼동하지 않는다.

기존 새 Lean algebra kernel 선언의 검증 범위를 실제 해석학 전체의 Lean 증명으로 확대하지 않으며, 반대로 이미 합의된 범위에 새 전면 형식화 목표를 추가하지도 않는다. 실제 전체 미보정 NS 잔차와 N6 correction, N7의 최종 global force는 M3로 유지한다. 모든 label의 소수 수치표나 전역 잔차의 수치 적분을 이 감사에서 새 M2 요구로 추가하지 않는다.

이 검토로 M3 파일·의존성·관문을 변경하지 않았다. FLINT/python-flint의 P7 준비 문서는 읽기 전용 사전 조사이며 설치·구현·실제 영점 증거를 완료한 것으로 세지 않는다.
