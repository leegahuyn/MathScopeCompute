# 실제 펄스의 R/Z/T 2차 jet과 FTC 경계

## 이번 추가 구현의 정확한 범위

`actual-pulse-jet-source.mjs`는 원래 두 부호 펄스의 동일한 계수 행렬과 초기조건에서 출발하여 R, Z, T의 1차 미분과 RR, RZ, RT, ZZ, ZT, TT의 대칭 2차 미분을 구성한다. 현재 실제 원문 실행 범위는 `ellExact: "1"`, `terms: 0` 또는 `terms: 1`이다. 기본값 `terms: 1`은 실제 계수의 첫 번째 순서 적분을 표시한다. 유한 합과 별도로 수렴하는 무한급수의 정의 및 잔여항 경계를 제공한다.

표시 결과는 정확한 함수식과 적분식이다. 실제 원문의 거대한 매개변수를 소수점으로 계산한 도함수나 수치 적분 enclosure는 아니다. 기존 1차 미분 구현과 원문 source 파일은 수정하지 않는다.

## 1. 원래 ODE와 모든 변분 항

두 성분의 원래 해를 \(w\), 시간변수를 \(v\), 선택한 slow 좌표를 \(a_i\)라 하면

\[
\partial_vw=Mw,
\qquad
\partial_vs_i=Ms_i+M_iw,
\]

\[
\partial_vs_{ij}=Ms_{ij}+M_is_j+M_js_i+M_{ij}w.
\]

같은 방향의 2차 미분에서는 \(2M_i s_i\)를 포함한다. R/Z/T의 경우 값 1개, 1차 jet 3개, 대칭 2차 jet 6개에 각각 두 성분이 있으므로 전체 행렬은 20×20이다. 일반 호출자가 미분 행렬을 제공하지 않는다. 구현이 실제 \(M\)의 본문에서 직접 \(M_i,M_{ij},M_v\)를 만든다.

정규화된 원래 초기값은 \(w(0)=e_1\)이므로 원문 source의 \(w_i(0),w_{ij}(0)\)는 0이다. 실제 진폭 \(t=PBw\)의 초기값에는 \(B\)의 R 의존성이 남는다. 이를 공통 0 초기값으로 치환하지 않는다.

일반 kernel은 움직이는 초기점도 지원한다. \(w(\ell(a),a)=g(a)\)이면

\[
s_i(\ell)=g_i-M(\ell)g\,\ell_i,
\]

\[
\begin{aligned}
s_{ij}(\ell)={}&g_{ij}-(M_i g+Ms_i)\ell_j
 -(M_jg+Ms_j)\ell_i\\
&-(M_v+M^2)g\,\ell_i\ell_j-Mg\,\ell_{ij}.
\end{aligned}
\]

평가점 \(b(a)\)에서의 총미분에도 두 mixed 시간 항, \(w_{vv}b_ib_j\), \(w_vb_{ij}\)를 모두 보존한다. 실제 원문의 고정 라벨에서는 양 끝점의 R/Z/T 미분이 0이라는 사실을 본문에서 계산한다.

## 2. 원문 계수에서 직접 만든 FTC 경계

실수 C1 계수 \(f(v,a)\)에 대해 다음 정확한 함수식을 만든다.

\[
U_f(a)=\sqrt{1+f(0,a)^2}
 +\int_0^{L_s}\sqrt{1+(\partial_vf(v,a))^2}\,dv.
\]

미적분학의 기본정리로 \(0\le v\le L_s\)에서

\[
|f(v,a)|\le |f(0,a)|+\int_0^v|\partial_vf|
\le U_f(a).
\]

\(\sqrt{1+x^2}\)를 사용하므로 \(x=0\)에서 평활 majorant 자체의 분모가 0이 되지 않는다. 일반 FTC 함수는 C1 및 실수 조건을 명시한 계산 규칙이다. 원문 인증은 별도 adapter가 원래 본문과 연결하여 수행한다.

이 공식을 \(M,M_i,M_{ij},M_v,B,B_i,B_{ij}\)의 각 원래 성분에 적용한다. 따라서 \(M_{ij}\)를 감싼 표기만 제공하는 것이 아니라, 경계 적분 안에 실제 \(\partial_vM_{ij}\)도 생성한다. 각 행의 성분 경계를 더하고 행들 사이의 최댓값을 취해 유도 infinity 행렬 노름을 얻는다. 부호 하나당 21개 행렬 그룹, 104개 성분 경계가 기록된다.

이 경계는 slow 매개변수에 의존하며 펄스 시간에 대해 균일하다. 원래 유한 활성 source의 매끄러운 본문과 비영 분모를 유지한다. 특히 원래 annulus에서 \(R>0\)이고, 0이 아닌 고정 정수 carrier가 접선 법선의 비영성을 보존한다. 계수 및 시간 미분의 공동 연속성으로 내부 slow 좌표의 작은 compact 근방에서 이 경계들이 유계이다. 이 단계가 미분된 순서 적분 급수의 국소 균일 수렴과 미분 교환을 정당화한다. chart 경계는 연속적인 한쪽 미분의 확장으로 해석한다.

고정한 대표점이나 반올림된 carrier를 바꾸는 경계를 가로질러 미분 가능하다고 주장하지 않는다. 모든 점과 모든 band를 동시에 제어하는 공통 global C3 상수도 이 계산에서 도출하지 않는다.

## 3. 실제 20성분 행렬의 수렴 경계

\(K,K_i,K_{ij}\)를 위에서 얻은 계수 행렬 경계라 하면 augmented 행렬의 유도 infinity 노름은

\[
K_{\mathrm{aug}}
=\max\{K,\ K+K_i,\ K+K_i+K_j+K_{ij}\}
\]

로 제어된다. 초기 augmented 노름 경계를 \(I_{\mathrm{aug}}\)라 하면 \(N\)번째 유한 순서 적분 합의 오차는

\[
E_N=I_{\mathrm{aug}}e^{K_{\mathrm{aug}}L_s}
\frac{(K_{\mathrm{aug}}L_s)^{N+1}}{(N+1)!}
\longrightarrow0.
\]

실제 source의 정규화된 상수 초기값에서는 \(I_{\mathrm{aug}}=1\)이다. 경계는 근삿값의 모든 성분에 적용되며, `terms: 1` 결과를 무한급수의 극한과 동일시하지 않는다. 시간에 따라 비가환인 행렬의 곱 순서는 유지한다.

## 4. 실제 진폭의 1차·혼합 2차 미분

대표점과 carrier를 고정한 R/Z/T 미분에서 원래 envelope는 \(P_i=0\)이다. 따라서

\[
t_i=P(B_iw+Bw_i),
\]

\[
t_{ij}=P(B_{ij}w+B_iw_j+B_jw_i+Bw_{ij}).
\]

진폭 도함수의 유한 합 오차는 각각

\[
P(v)(\|B_i\|+\|B\|)E_N,
\]

\[
P(v)(\|B_{ij}\|+\|B_i\|+\|B_j\|+\|B\|)E_N
\]

으로 제어한다. 반복 방향에서는 동일한 \(\|B_i\|\)가 두 번 들어간다. 양 부호, 9개 미분 방향, 3개 진폭 성분에 대해 54개의 도함수 행을 제공하며, 왼쪽·중간·오른쪽 평가점의 도함수도 별도로 기록한다.

## 5. 인증과 남아 있는 범위

인증서는 원래 source operator, 변경되지 않은 본문 prefix, 함수 정의, jet 시스템, alias, 출력 roots와 scope를 묶는다. 복사한 영수증이나 호출자가 지정한 미분 행렬·경계·완료 플래그는 인증 입력이 아니다. 후속 adapter가 그래프에 노드를 덧붙여도 pulse-jet 자체의 compiler hash는 원래 prefix에 대해 유지된다.

작은 독립 검증에서는 비가환 다항식의 순서 적분, 해석적 nilpotent 및 지수해, 움직이는 두 끝점, \(M_v\)·\(M^2\)·반복 계수 2의 누락 반례, factorial tail과 변조 거부를 확인한다. 원문 검증에서는 동일한 양 부호 계수, 104개씩의 FTC 성분 경계, 실제 첫 번째 적분과 모든 진폭 미분을 확인한다.

이 추가 기능은 실제 고정 band의 국소 1차·2차 도함수 계산을 제공한다. 다음 사항은 각각 별도의 주장과 검증을 필요로 한다.

- 실제 소수점 도함수 및 전체 적분의 수치 enclosure.
- 실행한 `ell=1`의 공분산 가역성이나 양의 weight 인증.
- 실제 전체 curl을 물리 잔차 및 global flat-error 경계와 연결하는 단계.
- 모든 band와 slow 점에 공통인 C3/Gaussian 경계.
- 새 Lean kernel 증명.

기존 원문 64개 M2 항목의 PASS를 이 별도 범위들의 완료로 확대하지 않는다.
