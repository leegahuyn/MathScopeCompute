# 원본 heat 성분의 전역 실수 혼합 미분 노름과 무한 꼬리

기존 증명은 `H_h^(m)(Z)`의 각 고정 차수 실수 상계를 제공했다. 새 계산은 원본 입력 `Z=2(1-eta²)/X`를 그대로 합성하고, 임의의 두 차수 `p,q`에 대한 `D_X^p D_eta^q`의 정확한 정수계수 재귀와 명시적인 유리수 노름을 만든다. 클라우드에서는 총 차수 24까지의 325개 혼합 미분을 전부 계산한다. 임의 차수의 근거는 보간이나 유한 표가 아니라 아래 두 product/chain rule의 귀납법이다.

`X^-a eta^b H^(m)(Z)`의 X 미분은 `-a X^(-a-1) eta^b H^(m) -2 X^(-a-2) eta^b H^(m+1) +2 X^(-a-2) eta^(b+2) H^(m+1)`이고, eta 미분은 `b X^-a eta^(b-1) H^(m) -4 X^(-a-1) eta^(b+1) H^(m+1)`이다. 원본 h의 정확한 source 표현에서 `0<h<1/100`을 재검증한다. 따라서 `X>=4, |eta|<=1`에서 각 항의 노름은 `|c|4^-a(1/100)_m(101/100)_m` 이하이다. 합계를 정확한 유리수로 계산한다.

원본 node71948은 **H가 아니라 normalized heat loss `1-H`**이다. 결과에는 0차 상수 `1`과 모든 H 미분의 부호 `-1`을 따로 보존하고 독립 검증한다. 0차 loss의 노름은 양수 적분에서 `0<=1-H<=1`로 얻는다. 양의 차수는 위 혼합 미분의 부호를 바꾼다.

원본 compactified 적분의 치환 `t=u/(1-u)`와 Jacobian을 포함한 nodes71925–71948,71505–71518을 이전 source checkpoint 또는 SHA-256을 검증한 원본 SQLite prefix에서 직접 확인한다. 새 적분이나 유한 quadrature로 바꾸지 않는다.

새 무한 꼬리 증명은 모든 차수에서 계산 가능한 cutoff를 제공한다. `Gamma(1+h)>e^-2>1/9`이고, `t>=L>=1`에서 `t^(h+m)<=t^(m+1)`이다. 따라서 정규화된 m차 미분의 꼬리는 `9(h)_m e^-L (m+1)! sum_(j=0)^(m+1) L^j/j!` 이하이다. `e>2`로 정확한 유리수 상계를 얻는다. 임의 차수와 목표 bits에 대해 `L=64(m+bits+1)^2`이면 이 꼬리는 `2^-bits` 이하임을 양의 정수계수 다항식 항등식으로 증명한다. 혼합 미분은 모든 chain coefficient의 절대합을 위한 추가 bits를 유지한다. 적분 꼬리를 0으로 버리지 않는다.

독립 검증기는 재귀를 다시 확인하고, 총 차수 8 이하에서는 별도의 이변수 Taylor 계수 공식으로 재귀와 일치하는지 검사한다. 꼬리는 별도의 integration-by-parts 정수 재귀로 다시 계산한다. 계수·노름·꼬리·Gaussian 양수율·미분 행 누락의 다섯 변이를 거절한다.

Gaussian 쪽에서는 `a>0, aN>=1, aN²>=p`일 때 `sum_(ell>=N) ell^p exp(-a ell²)<=2N^p exp(-aN²)`라는 임의 차수 꼬리 상계를 증명하고 유리수 입력 대조 65개를 계산한다. 원본 envelope `a=Renv^-31 Lmin/(64u)`의 모든 label에 대한 실제 진폭·안정 propagator·배경 derivative norm 결합은 여전히 필요하다. 이 조건부 대조를 실제 W/M/S 노름으로 승격하지 않는다.

이는 정확한 heat 성분의 전역 실수 정의역에 적용되는 새 정량 상계다. 전체 PDE의 입력이 이 정의역에 속한다는 source image 증명, 모든 비선형/flat join/압력 성분의 W/M/S 노름, 진짜 공통 복소 Picard strip과 계수 sup norm, 전체 Haar 모멘트 및 Cartesian PDE는 남는다. 따라서 N6-01 OPEN·N6-02 PARTIAL과 56/64는 유지한다.
