# 변경 및 검증 이력

원본 ZIP, PDF, 영수증과 기존 v5 추출본은 변경하지 않았다. 수정과 새 증거는 `work/`의 별도 사본에 기록했다. 이 문서의 검사 수는 M3 항목 수가 아니다.

1. 9개 전송 조각에서 291,568,669바이트 원문 ZIP을 복원했다. 전체 SHA-256과 내부 원문 33개 및 인덱스를 대조했다. 이미 확보했던 핵심 21개의 기존 검증 결과를 승계했다. 미확보 후보 18개는 별도로 회수하고 실제 관측 해시를 기록했다. 후속 첨부 10개는 기존 원문과 동일한 바이트의 별칭이었다.
2. 원본 Windows 영수증은 Python 3.12.10, EXIT_CODE 0, overall_passed=true, 파일 94개 해시 일치와 CLI 두 개·테스트 25개/6개의 네 단계로 인수했다. 이 실행을 반복하지 않았다. 역사 자료의 68/32 테스트는 이 Windows 실행에 합산하지 않았다.
3. 누락 producer 네 개를 원래 핀과 일치하는 바이트로 복구했다. 별도 Step1 사본의 회귀 기준을 7개 존재/4개 누락에서 11개 존재/0개 누락으로 바꾸었다. 원래 TARGET 부재와 부모의 유한 projection은 구분했다. 변경 사본은 CLI 및 28개 검사를 통과했다.
4. `time_amp=s^3(3-2s)`의 미분을 `(9s^2-8s^3)/(t_end-t_quiet)`로 수정했다. 이전 수식에 새 회귀 검사를 적용한 실패를 보존했다. 기존 모델 energy defect의 연속극한은 9/700이며, 수정 후 시간 세분화 오차가 감소한다. 이는 모델의 결과다.
5. Gaussian 계산은 유리수 로그 구간으로 검증했다. 지정 모델에서 최소 정수 문턱은 173이고 E(180)은 약 -590.7103188883375이다. 부동소수 상계는 바깥쪽으로 반올림한다. N6-07의 126개 저장 기록은 원래 63개 (stage,order) 쌍에 대한 K와 ell-prime 차이로 대조했다. 문서에 없는 offset 공식을 추가하지 않았다.
6. N6-08의 모델 유한 cutoff 목록, N7의 표본 norm 및 hardcoded b_j, N8의 모델 tau를 실제 전역장 인증값과 분리했다. 실제 값이 없으면 null 또는 미검증으로 기록한다. 통합 수정본의 17개 검사가 통과했다. 최초 통합의 낡은 b_j 기대값 검사 실패도 보존했다.
7. 기존 same-source 전차수 정리, 실제 두 좌표변환, 세 성분 잔차의 정확한 함수 동일성, Gaussian flatness를 연결한 새 적용 증거를 작성했다. 최신 N6-01 결론과 나머지 항목의 상태는 `FINAL_ID_LEDGER.json`을 따른다. 기존 파일의 역사적인 BLOCKED/conditional 플래그는 삭제하지 않았다.
8. 실제 sealed source 객체를 소비하는 signed 전체 압력 모듈을 새 사본에 구현했다. 실제 pre-temporal signed 단계의 직접 PDE와 별도 분해를 비교해 세 성분의 정확한 분자 0을 확인했다. 최초 2560 MiB V8 heap 시도의 OOM과 4096 MiB 재시도의 성공을 모두 보존했다. post-forced 실제 상태를 소비하는 필수 연쇄는 미구현이므로 N6-02는 OPEN이다.
9. 원래 초기 tuple, inverse, selector, potential gauge를 고정한 실제 재귀 함수족에 정리들을 적용했다. 공통 상계, 실제 potential cutoff 합, wholeK terminal jets 및 force extension의 존재·전차수 접합을 두 독립 검토와 대조하여 N6-07, N6-08, N7-04, N7-05를 CLOSED로 판정했다. 최소 상수·정수 및 supremum의 정확한 수학적 정의는 수치 평가 알고리즘과 구분했다.
10. M3 최종 판정은 61/64이다. N7-06의 실제 전역장 공간·시간 수치 세분화 및 N8-05의 실제 네 축 2배 비교는 미완료다. 분석적 에너지 동일성, 모델 오차 수정 또는 symbolic 선택 정의로 이를 대신 완료 처리하지 않았다.
11. 후속 지시 이후 N6-02의 post-forced 실제 입력 연쇄를 새 사본에서 구현·실행했다. forced→signed→temporal→fresh-five가 EXIT0/1700.657초로 완료되었고 네 poststep의12개 exact comparison과9개 항 누락·압력 대조를 통과했다. 원본135개는 변경하지 않았다. 두 독립 검토 후 N6-02를 CLOSED로 갱신하여 현재 M3는62/64이다. 위61/64는 이전 시점 기록이다.
12. 실제 angular 에너지 식, 같은 source-header의 scalar packet 결합, actual core7개 수치 평가와 독립2배 표, 원래 backend/직접합산의 자원 경계를 추가했다. 모델이나 부분core 표를 global N7-06/N8-05로 승격하지 않았다. 새25쪽 개념 설계도와 기존99쪽 확장설계도를 구분하고 M4 원래16항목 및 지정사이트 기존원문을 읽기전용 대조했다. M3 선행조건과 브라우저 접근장애로 M4/3D게시 완료를 주장하지 않는다.

`REPRO_CHANGED_WORK.py`와 `reproPS.ps1`은 이 변경 작업의 검사만 실행한다. 최초 1260개 의무나 원래 Windows 전체 런처를 다시 실행하는 스크립트가 아니다. 패키지 재배치 검사는 경로 독립성을 확인하기 위한 별도 검사로 기록한다.
