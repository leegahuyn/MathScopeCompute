# 원본 Picard 계수의 실제 호출 범위와 정의역

이 문서는 원본 `picard:0`의 계수 그래프를 대상으로 한다. 계수 함수의
정의역을 검증한 결과와, 접합의 전 차수 일치가 추가로 필요한 부분을
구분한다. 원본 Guard/Jet/PDE 소거 수는 이 문서만으로 변경하지 않는다.

## 1. 원본 결속

고정 정의의 SHA-256은
`c8041bf166aa318a5dab4a0ccb53d1503609feadbaec4361fe4587bb5945bc1b`,
원본 Picard 정의의 SHA-256은
`c3ee2bdec0b3f1bdd63a679bc1d6fbaeff72fc961e68b24b8a39efd4d6229b60`이다.
검증기는 원본에서 인증된 전체 진단 파일의 해시 또는 세 개의 인증된
투영 파일 해시를 먼저 확인한다. 원본 gzip/header 결속과 전체 3,892,594개
노드 인증은 상위 클라우드 검증 단계가 수행한다. 작은 테스트 자료는
원본 그래프 인증을 대신하지 않는다.

원본 `A0`, `A1`, forcing의 보수적 계수 그래프는 정확히 3,679개 노드이고,
그 안의 잠재적인 자연급수 호출은 157개이다. 적분 변수의 범위를
바깥쪽에서 안쪽으로 전달하며, lazy 분기는 **닫힌 구간을 포함한 상계**가
공집합임이 증명될 때에만 제거한다. DAG 방문 기록에는 노드 ID와 전체
변수 환경이 함께 들어간다. 같은 노드가 다른 적분 범위에서 다시
호출되는 경우를 전역 방문 표시 하나로 누락하지 않는다.

## 2. 실제 반경 범위

원본 공통 반경은 `0<=xi<=a`,
`a²=Xa exp(t1/16)`, `Xa=4/Lambda`이다. 원본 매개변수 식으로부터
`Q>2^260`, `Lambda=Q^64>0`, `0<t1<2^-120`가 따른다. 따라서

```
4 exp(2t1) <= 4/(1-2t1) < 41/10.
```

곱·로그·지수의 정확한 대수식, 양수 인자에 의한 순서 보존, 단조성만
사용하여 분기 선택자와 적분 구간을 전달한다. 알려지지 않은 연산,
부호, 비교, 또는 결속되지 않은 좌표는 실패로 남긴다.

157개 호출 중 73개 ID가 207개 유지된 환경에서 실제로 도달하며,
각 환경에서 `0<=Y<41/10`, `eta` 인자가 원본 좌표 2임이 확인된다.
나머지 84개 ID는 284개 증명된 공집합 분기 뒤에만 있다. 이 84개를
실행되었다고 세지 않는다. 모든 잠재 ID는 도달 증명 또는 공집합 분기
증명에 의해 덮인다.

## 3. 원시 연산의 정의역

별도의 두 번째 순회는 자연급수 인자 자체의 원시 연산도 방문한다.
`exp(log X)`를 `X`로 정규화한 뒤 원래 `log X`의 정의역 검사를
생략하지 않는다. 유지된 각 piecewise 선택자·양쪽 끝점, 각 적분의
양쪽 끝점과 본문을 검사한다. 원래 계수 그래프에 대해 8,384개 환경
상태를 검사하였으며 미해결 원시 정의역은 0개이다.

자연급수와 고정 core 함수는 독립 Banach 정리와 원본 커널 재결속
`ACTUAL_NATURAL_KERNEL_BINDING.json`에 연결된다. 사용한 파일 해시는
`c422952afe5886b5c2b873550a40fa756696f8502f11c27f2629687a4a7d943d`,
majorant 결과의 해시는
`4b94c652630c250f883622601d1d9d4998c412927fe3bc4352ba5e8c70e2fe3d`이다.
이 정리의 실제 결론인 `Phi>1/4` 및 공통 복소 eta 관에서
`|Phi|>63/256`을 사용하여 원본 Phi 역수를 정당화한다.

나머지 eta 극점은 직접 확인할 수 있다. `|Im eta|<1/16`에서
`Re(1+eta²)>255/256>0`이고 그 역수도 실수부가 양수이다. 따라서 원본
역수와 principal logarithm은 같은 관에서 정칙이다. 또한 실제

```
Hstar=(1/2-h)eta+(1-eta²)(j0+4eta)
```

에 대해 `|eta|<2`에서 `|Hstar'|<64`이다. 실제 core 관의 반경이
`sigma²/2048`이므로 실수 기준점에서 Hstar의 변화는 `sigma/32`보다
작다. 따라서 `Hstar +/- i sigma`의 절댓값은 `31sigma/32`보다 크다.
`Hstar²+sigma²`는 영이 아니다. `L=1-2h eta²`도 `h<1/16`으로 영이
아니다. 원본 Picard의 `delta=rho/(1024Q)` 관은 이 core 관 안에 있다.

이로써 각 고정된 실수 xi에서 실제 계수의 eta 정칙성을 얻는다.
단계 함수의 인자 31개는 eta와 무관하므로 이 단계에서 eta 선택
경계가 생기지 않는다.

## 4. 반경 접합에 남는 정확한 문제

원시 정의역이 모두 적법하다는 사실만으로 piecewise 함수의 반경
미분 가능성을 결론 내릴 수 없다. 77개 보수적 piecewise 노드에 대해
실제 공통 반경과 만나는 접합은 36개이다. 그중 18개 오른쪽 접합
`xi²=a²`는 안쪽·바깥쪽 본문 ID가 문자 그대로 같다. 나머지 18개는
모두 `xi²=Xa`에서 자연해와 B.26 값을 이어 붙이는 왼쪽 접합이다.
B.22 내부 접합은 이 공통 반경에서 도달하지 않는다.

따라서 필요한 추가 정리는 자연해와 B.26의 `X=Xa` 전 차수 일치이며,
그 적용 대상이 되는 18개 본문 쌍을 원본 F0/U0/v0의 실제 형식 미분과
결속하는 검사는 `picard_interface_lineage.py`가 별도로 수행한다.
그 검사는 18개 본문 쌍 모두에 대해 성공하였다. 원본 생성자의 base
F0/U0/v0 결속과 이 계보, 별도의 전 차수 보존·평탄성 정리를 조합하는
내용은 `ACTUAL_PICARD_REGULARITY_KO.md`에 있다. 이 정의역 검사의
이전 출력에 있는 미조합 상태 플래그를 뒤늦게 덮어쓰지는 않는다.

독립 수학 증명은 `ACTUAL_NATURAL_B26_JOIN_KO.md`에 있다. 실제 자연
방정식의 적분형으로부터 `p1=-2X F_X/F`, `Ns/L=-2U_X`를 유도한다.
`y=log(X/Xa)`에서 `kappa-1`이 0에 평탄하므로 B.26와 자연해의
차이는 모든 혼합 미분에서 0에 평탄하다. 이 수학적 사실과 실제 18개
본문의 미분 계보가 모두 결속되어야 계수의 반경 C-infinity 및 원본
Picard 수렴 정리로 진행할 수 있다.

## 5. 검증의 실질적 한계

이 결과는 원본 `picard:0` 입력의 정의역 정리이다. 전체 g의 다른
376개 자연급수 호출, 모든 native 정의, 전체 압력 적분 구간 J,
원본 230개 jet 및 1,020개 PDE 항을 자동으로 닫지 않는다.
전체 원본 의무의 새 소거 수는 0이다.
