# 유일한 미부착 natural 경로의 원본 의미 검사

실행 38720796745는 같은 원본 533개 natural 호출의 2,464개 외부 범위 계약을 증명했고, `3910 → 99417 → 100000` 경로 하나를 미증명으로 보존했다. 단순히 실행되지 않은 것처럼 보인다는 이유로 이 경로를 삭제하지 않는다.

원래 보수적 추출기는 native 등록부와 native 인수의 모든 정수까지 후보 노드 ID로 보존한다. 실제 정수 상수와 실제 노드 ID를 구별하지 않는 이 과포획은 처음부터 명시되어 있다. 고정 정의를 조사하면 정수 100000이 다음 두 곳에서만 발견된다.

```
fixed.source.parametersExactExpressions.sourceEnvelopeS.power[1]
fixed.outer.parametersExactExpressions.sourceEnvelopeS.power[1]
```

두 값은 정확히 원래 `S=CSelected^100000`의 지수다. 이 필드는 source expression의 `power` 생성자에서 정수 지수를 뜻한다. 값이 우연히 노드 ID 100000의 범위 안에 있다고 해서 그 노드를 평가하라는 의미는 아니다.

이 사실만으로 나머지 등록부의 실제 사용이 없다고 추정하지 않는다. `natural_metadata_origin.py`는 같은 실행에서 인증된 전체 source cache와 header에 다시 결합하고, 136,186개 보수적 노드, 84개 등록부 및 533개 호출의 고정 해시를 대조한다. 모든 등록부와 실제 native tuple의 정수 출처를 전부 열거한다. 정확히 위 두 경로만 100000의 최초 포함 원인이어야 하며, 다음 어느 하나라도 있으면 분류를 거부한다.

- 원본 ordinary 또는 native의 실제 operand가 노드 100000을 읽는 경우.
- 검토된 실제 정의 몸체의 root가 100000인 경우.
- 원래 요청한 g21 root가 100000인 경우.
- 다른 미분류 정수 출처가 추가되는 경우.

다섯 음성 대조군은 실제 operand 또는 body 사용을 수치 메타데이터로 처리하는 잘못된 분류 등을 거부한다. 기존 533개 호출 장부와 원래 미부착 경로는 삭제하지 않고 분류 증거와 함께 유지한다.

성공한 검사는 이 한 경로가 수치 메타데이터로 인한 과포획임을 증명한다. 따라서 외부 **형식적 범위 계약**의 유일한 미분류 경로를 해결한다. 실제 호출의 양수 반경·η 치환, 나머지 primitive 정의역, 전체 g/J 정칙성까지 증명했다는 뜻은 아니다. 이 조건들은 계속 OPEN이며 원본 Guard/Jet/PDE 신규 소거 수는 0이다.
