# 원본 Volterra 이동 좌표의 동적 분모

대상은 원본 `covariance:0,1`의 두 2×2 Volterra 시스템이다. 새 검증기는
같은 workflow에서 전체 원본을 인증한 fresh cache를 읽고, 원본 행렬의
실제 primitive 조상을 찾아 아래 식에 연결한다. 원본 행렬이나 상수를
다시 만들거나, 불명인 ODE 해를 임의의 값으로 정하지 않는다.

원본 carrier는 실수 a에 대해 먼저 `rounded=floor(a+1/2)`를 만든다.
이 정수가 0인 경우에만 실제 fallback의 −1 또는 +1로 바꾼다.
나머지 정수는 그대로 둔다. 따라서 실제 정수 m은 항상 0이 아니다.
fallback 경계의 어느 부호가 선택되는지는 이 결론에 영향을 주지 않는다.

원본 `epsilon=exp(유한한 실수 식)>0`이고
`k=ceil(1/sqrt(epsilon))`이므로 k는 1 이상의 정수이다. 원본의 실제
`p=m/k`는 0이 아니다. 검증기는 실제 p의 분모가 이 k인지, 실제
fallback과 반정수 경계가 위 식인지 확인한다.

원본 이동 normal은

```
n_R = x0-v*H_R,
n_theta = p/R,
n_z = pz-epsilon*v*H_Z,
nt² = n_theta²+n_z²,
|n|² = n_R²+n_theta²+n_z².
```

원래 양의 반경 영역 R>0에서 실제 계수들이 유한한 실수이면

```
nt² >= p²/R² > 0,
|n|² >= nt² > 0.
```

따라서 두 실제 시스템 모두 전체 pulse 구간에서 nt와 |n|² 때문에
분모가 0이 되지 않는다. 작은 v 표본이나 수치 tolerance, 임의의 normal
성분 값은 사용하지 않는다. 검증기는 행렬에서 이 실제 두 제곱합과
`n_theta=p/R` 연결을 찾아 검증하므로 별개의 일반 행렬 예제로 대체하지
않는다. 원본 fallback을 0으로 바꾸거나, angular 제곱항을 누락하거나,
carrier k를 0으로 바꾼 음성 대조는 거부되어야 한다.

이 결과는 동적 분모에 관한 것이다. 원본 대표점에서 고정되는 gabs,
c0, lambda0, Bs의 정의역과 전체 background profile 및 그 도함수의
유한한 실수 정칙성은 별도의 원본 조건이다. 이를 이 정리로 해결했다고
간주하지 않는다. Ls=2*r0/c_i의 양성은 앞선 실제 c_i 결합에서 얻는다.

그 정적 조건과 원본 행렬 계수 M의 Ck 정칙성이 확보되면, 각 compact
매개변수 영역에서 실제 M과 필요한 유한 개 도함수는 유계다. 같은 실제
ordered-integral 급수는 factorial 꼬리로 국소 균등 수렴하며, 하향 폐쇄
변분 시스템의 실제 행렬을 쓰면 필요한 고정 차수 도함수도 얻어진다.
모든 미분 차수에 공통인 단일 수치 K를 미리 가정할 필요는 없다.
다만 원본이 표시한 특정 normUpper를 사용하는 수치 꼬리 인증은 그
특정 상계의 실제 적용 증명이 별도로 필요하다.

고차 변분식은 원본 그대로
`w_alpha' = sum_(beta<=alpha) binomial(alpha,beta) D^(alpha-beta)M*w_beta`
이다. 원본 초기값은 매개변수에 무관한 (1,0)이므로 양의 차수 초기
도함수가 0이라는 결론도 이 실제 초기조건에서 나온다. 미지의 도함수를
편의상 0으로 두는 처리가 아니다.

현재 원본 Guard/Jet/PDE 신규 소거 수는 0이다.
