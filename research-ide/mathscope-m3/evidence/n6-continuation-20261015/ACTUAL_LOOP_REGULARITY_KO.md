# 실제 C.1 역함수와 C.12 유한 주파수 변조의 정칙성

대상은 변경하지 않은 `actual-continuation-exact-loop.mjs`의 실제 `ActualC1VarianceRoot`와 `ActualC1CircleInverseLift`이다. g21 원본 등록부에서는 각각 `monotone:0`의 몸체 7450, 변수 7394, 매개변수 [4756,2] 및 `monotone:1`의 몸체 7539, 변수 7472, 매개변수 [4756,2,7471]이다. 식은 원본 파일 29–50행에 있다. 다른 loop나 원형 좌표를 대입하지 않는다.

이 문서는 먼저 실제 분산 식 자체의 전역 매끄러운 역함수를 무조건적으로 증명한다. 이어서 명시한 실제 배경 조건 아래 원본의 S¹² 구간, 원본 m/M 반복, 원형 역함수 및 C.12 출력의 정칙성을 증명한다. 원본 배경이 그 조건을 만족하는지는 별도의 열린 적용 의무이다.

## 1. 실제 분산 식의 0에서의 제거 가능성과 전역 역함수

정규화된 원 평균을 ⟨·⟩로 쓰고, 실제 원본과 같은 함수를 놓는다.

```
M(z)=⟨exp(z sinθ)⟩,
R(z)=M(2z)/M(z)²,
Q(z)=∫_0^1(1−s)R″(sz)ds,
W(μ,p)=d0 μ sqrt(Q(μp)),       d0>0.
```

모든 실수 z에 대해 M(z)>0이다. 유한 원적분을 임의의 유한 차수로 미분할 수 있으므로 M,R는 실수 해석함수이다. 대칭성과 원 평균으로

```
M(z)=Σ_(n≥0) z^(2n)/[4^n(n!)²],
R(0)=1, R′(0)=0, R″(0)=1.
```

Taylor 적분 나머지를 정확히 적용하면

```
R(z)−1=z²Q(z),       Q(0)=1/2.
```

원본은 p나 μp로 나누지 않고 바로 이 적분형 Q를 사용한다. 검증기의 독립 형식급수 계산은 `Q(z)=1/2−3z²/32+11z⁴/576−…`를 확인한다. 이 유한 전개는 무한 수렴의 근거가 아니라 제거 가능한 값의 독립 점검이다.

`ell=log M`이면 지수 기울임 확률밀도 `f_z(θ)=exp(z sinθ)/M(z)`에 대해

```
ell″(z)=Var_z(sinθ)>0.
```

밀도는 항상 양수이며 sinθ는 상수가 아니므로 부등식은 엄격하다. z>0에서

```
(log R)′(z)=2[ell′(2z)−ell′(z)]>0.
```

R는 짝함수이므로 R(z)>1(z≠0), 따라서 Q(z)>0가 모든 실수에서 성립한다. Q의 양의 제곱근은 실수 해석함수이고 W는 (μ,p)에 대해 매끄러우며 μ에 관해 홀함수이다. p=0일 때 실제 값은

```
W(μ,0)=d0 μ/sqrt(2).
```

p≠0, μ>0일 때 `W²=d0²[R(μp)−1]/p²`를 미분하면 Wμ>0이다. μ<0도 홀대칭으로 같다. μ=0에서는 `Wμ=d0/sqrt(2)>0`이다. 반면 V=W²에 대해서는 Vμ(0)=0이다. 거짓인 `Vμ(0)>0`을 암묵함수 정리에 사용하지 않는다.

W가 모든 실수 값을 취함도 증명할 수 있다. z→+∞에서 확률밀도 f_z는 sinθ=1 근처에 집중한다. 임의의 ε>0에 대해 `Aε={sinθ>1−ε}`라 하면, 더 작은 A_(ε/2)를 이용한 지수 비교로 기울임 확률 `∫_Aε f_z→1`이다. Cauchy–Schwarz에 의해

```
R(z)=⟨f_z²⟩ ≥ (∫_Aε f_z)² / measure(Aε).
```

ε→0일 때 measure(Aε)→0이므로 R(z)→∞이다. 따라서 p≠0에서 W(μ,p)→∞(μ→∞)이고, p=0에서도 같다. 홀대칭으로 음의 방향도 성립한다.

결과적으로 모든 실수 r,p 및 d0>0에 대해 `W(μ,p)=r`의 실수 해 μ는 정확히 하나이다. Wμ>0이므로 암묵함수 정리를 모든 점에 적용할 수 있고, 유일성으로 국소 해들이 일치한다. 실제 W의 전역 역함수 `μ=F(r,p,d0)`는 C∞이다. 특히 r=p=0에서도 동일한 매끄러운 가지이다. 이 결론에는 원본 배경의 cone이나 수치 enclosure가 필요 없다.

## 2. 원본 유한 구간 S¹²가 실제로 충분한 최소 조건

이제 실제 배경에서 다음을 가정한다. p는 원본 p_s,2이고 아래 a,b_s,t_s,v_s도 원본 29행의 식이다.

```
S≥2^20, d0=1/(8S), delta=exp(−S^16),
a>0, a⁻¹≤S, v_s≤S, |p|≤S,
t_s=−b_s/a, v_s=a+b_s²/a=a(1+t_s²).
```

따라서 a≤v_s≤S, |t_s|≤S이다. 원본의 cutoff는

```
v*=2+delta/2,
ζ(v_s)=1−sigma_step((v_s−(2+delta/8))/(delta/8)),
r=ζ sqrt((v*−v_s)/a),
v=v_s+ζ²(v*−v_s).
```

r의 제곱근은 실제 lazy 분기에서만 평가한다. ζ가 0이 아닌 곳에서는 `v_s<2+delta/4`이므로 `v*−v_s>delta/4`; 분모 a도 양수이다. cutoff의 평평함 때문에 오른쪽의 0 확장은 C∞이다. 또한 0≤r²<3/a≤3S이고 v≥v_s>0이다.

원본 분산의 필요한 전역 하계를 직접 얻을 수 있다.

```
R(z)−1 ≥ z²/4                  (|z|≤1),
R(z)−1 ≥ sqrt(|z|)/64           (|z|≥1).                    (1)
```

작은 z에서는 대칭 지수급수로 `⟨sinθ exp(zsinθ)⟩≥z/2`이다. 분산과 Cauchy–Schwarz로 `Var(exp(zsinθ))≥z²/2`이다. 또한 양의 M(1) 급수의 기하급수 꼬리에서

```
M(1)≤5/4+(1/64)/(1−1/36)<4/3,    M(1)²<2
```

를 얻고, 이를 나누면 첫 부등식이 나온다.

큰 z≥1에서는 `cosθ≤1−2θ²/pi²`와 Gaussian 적분으로 `M(z)²<exp(2z)/(2z)`이다. `0≤θ≤1/sqrt(z)`에서 `cosθ≥1−θ²/2`이므로 `M(2z)>exp(2z)/(12sqrt(z))`이다. 따라서 `R(z)>sqrt(z)/6`이다. z≥144에서는 `R−1≥sqrt(z)/12`이다. 1≤z≤144에서는 앞서 증명한 R의 단조성과 R(1)−1≥1/4를 써서 `R−1≥sqrt(z)/48`이다. 짝대칭으로 (1)이 완성된다.

V=W²에 적용하면

```
V(μ,p)≥d0²μ²/4                         (|μp|≤1),
V(μ,p)≥d0²sqrt(μ)/(64|p|^(3/2))        (|μp|≥1).
```

다음 명시적 수보다 큰 μ는 |p|≤P에서 V>4/a_-를 만족한다.

```
B=1+4/[d0 sqrt(a_-)]+2^16(1+P)³/[a_-²d0⁴].
```

여기에 a_-=1/S, P=S, d0=1/(8S)를 넣으면

```
B≤1+32S²+2^31S⁹<S¹².
```

마지막 부등식은 S≥2²⁰에서 `1+32+2^31<2^60≤S³`로 확인한다. 따라서 원본 μMax=S¹²에서 `V>4S>r²`, 즉 W>r이다. μ=0에서는 W−r≤0이다. 실제 원본의 유일한 비음수 해는 [0,S¹²] 안에 있고, r>0이면 내부에 있다. 원본의 S나 μMax를 바꾸지 않았다.

## 3. 원본 m/M 반복도 같은 해로 수렴

Z=S¹³이라 하자. |μp|≤Z에서 `f_z≥exp(−2|z|)`이므로

```
ell″(z)=min_c ⟨f_z(sinθ−c)²⟩ ≥ exp(−2|z|)/2.
```

두 번 적분하면 `Q(z)≥(1/2)exp(−4Z)`이다. 또한 정규화 기울임의 도함수는

```
|∂z f_z|=|f_z(sinθ−ell′(z))|≤2exp(2Z)
```

이다. 실제 divided difference에서 `W≤2d0 μ exp(2Z)`이고, 앞의 분산 미분식에서 `Vμ≥d0²μexp(−4Z)`이다. 따라서 μ>0에서

```
Wμ≥(d0/4)exp(−6Z)>exp(−S¹⁴).
```

μ=0에서도 Wμ=d0/sqrt(2)이므로 같은 하계이다. 마지막 비교는 `log(32S)+6S¹³<S¹⁴`에서 따른다.

상계도 실제 적분에서 얻는다. k≤3에 대해

```
|M^(k)(z)|≤exp(Z),
|(M⁻¹)^(k)(z)|≤k!2^k exp((2k+1)Z).
```

두 번째 식은 `M(M⁻¹)=1`의 미분 점화식과 `Σ_(j≥1)1/(2^j j!)<1`로 귀납한다. R=M(2z)(M⁻¹)²에 Leibniz 공식을 적용하면 k≤3에서

```
|R^(k)|≤2^10exp(10Z),
|Q|,|Q′|≤2^10exp(10Z).
```

따라서

```
Wμ≤2^11(1+Z)exp(12Z)<exp(S¹⁴)<exp(S²²).
```

예를 들어 로그를 취한 상계는 `11+13Z<S¹⁴`보다 작다. 원본이 기록한 `m=exp(−S¹⁴)`, `M=exp(S²²)`가 실제로 유효하다.

원본 반복 `T(μ)=μ−(W(μ,p)−r)/M`은 [0,S¹²]를 자기 자신으로 보내며 `0≤T′≤1−m/M<1`이다. 유한 반복을 해라고 선언하지 않아도 원본 꼬리 `S¹²(1−m/M)^n`가 0으로 가므로 그 극한은 1절의 같은 유일한 해이다. μ의 모든 느린 변수 도함수는 정확한 암묵방정식에서 얻는다. 유한 반복의 도함수 수렴을 근거 없이 가정할 필요가 없다.

## 4. 실제 원형 밀도의 정규화와 전역 lifted inverse

원본 41–43행의 실제 함수는

```
t(θ)=t_s+d0 μ ∫_0^1 [∂z f_z(θ)]_(z=sμp) ds,
density(θ)=a(1+t(θ)²)/(2pi v),
phi(θ)=∫_0^θ density(w)dw.
```

p≠0에서 `t−t_s=(d0/p)(f_(μp)−1)`이다. p=0에서는 같은 적분형이 `d0 μsinθ`를 준다. 그러므로 분모 p로 나누지 않고 모든 경우에

```
⟨t⟩=t_s,
⟨t²⟩=t_s²+W²=t_s²+r².
```

정확한 원본 등식 `v_s=a(1+t_s²)`, `ar²=ζ²(v*−v_s)`, `v=v_s+ar²`로부터

```
∫_0^(2pi) density(θ)dθ = a(1+t_s²+r²)/v = 1.              (2)
```

밀도는 엄격히 양수이고 C∞이다. 따라서

```
phi(0)=0, phi(θ+2pi)=phi(θ)+1
```

이며 phi는 실수 전체를 실수 전체로 보내는 엄격한 증가 C∞ 함수이다. 각 phase q에서 유일한 역함수 Θ(q)가 있고

```
Θ(q+1)=Θ(q)+2pi.
```

q=n+t, n∈Z, 0≤t<1이라 쓰면 원본 구간 `[2pi(q−1),2pi(q+1)]`의 왼쪽 phi 값은 q 이하, 오른쪽 값은 q 이상이다. 따라서 원본의 위상 의존 구간이 모든 실수 phase에 대해 유효하다. floor나 modulo를 미분하지 않는다.

또한 v≤max(v_s,v*)≤2S, a≥1/S 및 2pi<8에서

```
density≥1/(16S²).
```

위에서 v≥v_s≥a이므로 a/v≤1이다. `|t|≤S+2d0S¹²exp(2Z)≤2S¹²exp(2Z)`에서 밀도의 상계는 `5S²⁴exp(4Z)<exp(S¹⁴)<exp(S³⁸)`이다. 따라서 원본 원형 역함수의 m/M도 그대로 유효하고, 원본의 길이 4pi인 bracket에서 반복은 같은 유일한 역함수로 수렴한다. 밀도 도함수의 비영성 때문에 Θ는 모든 느린 변수와 q에 대해 공동 C∞이다.

## 5. 실제 평균 제거 primitive와 유한 N 변조

원본에서 평균을 빼기 전의 함수는

```
A0(q)=(a/2)(q−Θ(q)/(2pi)),
B0(q)=(Ea/2)[t_s q−(1/(2pi))∫_0^Θ(q)t(w)dw].
```

Θ의 shift 등식과 ⟨t⟩=t_s에서 두 함수는 q에 대해 주기 1이다. 원본 meanA,meanB는 Θ 치환 전에 density로 적분한다. (2)에 의한 정확한 변수변환으로 이 값은 각각 A0,B0의 q∈[0,1] 평균이다. 따라서 `A=A0−meanA`, `B=B0−meanB`는 실제로 평균 0인 주기 1 C∞ 함수이다. 평균항이나 비선형 교차항을 버리지 않았다.

ζ=0이면 r=0, μ=0, t=t_s, v=v_s이다. 이때 phi(θ)=θ/(2pi), Θ(q)=2piq이므로 A0=B0=meanA=meanB=0이다. 즉 실제 A,B가 정확히 0이다. 끝점 collar에서 `v_s−2≥S⁻¹`이면 `S⁻¹>delta/4`이므로 ζ=0인 열린 collar가 있다. 원본의 X∈[Ileft,Iright] 밖 0 확장 Acut,Bcut는 따라서 C∞이다.

마지막으로 실제 원본 N은 양의 유한 정수이다. 원본 그대로 `q=NlogX`를 대입하면 양의 X의 모든 고정 compact 구간 J=[L,U]에서

```
U_new=U+B(X,eta,NlogX)/N,
E_new=E·exp(A(X,eta,NlogX)/N)
```

는 C∞이고 E_new>0이다. 모든 빠른 반경 도함수의 N 인자를 보존한다. 주기 1의 q 때문에 임의의 이동 phase와 Haar 적분도 동일한 compact torus에서 다룰 수 있다. 고정된 느린 compact 집합과 유한 차수의 모든 도함수는 그 공통 compact 집합에서 유계이다. 전 band에 공통인 하나의 수치상수를 요구하지 않고 각 고정 band에 대해 성립한다.

## 6. 완료한 native 정리와 남는 실제 적용 의무

무조건적으로 완료한 부분은 원본 scalar 분산 W의 전역 C∞ 역함수이며, 0분산·p=0도 포함한다. 실제 loop 배경에 관한 다음 조건이 증명되면 위 모든 원본 μ/Θ 정의, 원본 반복 극한, 평균 제거, collar 확장 및 유한 N C.12 출력에 대한 정리가 그대로 적용된다.

1. 실제 pre-C12 E,U 및 다섯 cumulative moments가 전체 loop rectangle의 열린 근방에서 C∞이다.
2. 그 전체 rectangle에서 E>0, a>0이며 `a⁻¹≤S`, `v_s≤S`, `|p_s,2|≤S`이다.
3. 실제 두 끝점 collar에서 `v_s−2≥S⁻¹`이다.

원문의 추가 c_s,j_s cone 부등식과 3차 jet 수치상계는 이 정칙성 정리의 가정으로 필요하지 않다. 그 부등식이 다른 물리적 의무에 필요하다면 별도로 유지해야 한다. 위 세 조건이 원본 생산자의 설명 문자열에 적혀 있다는 이유만으로 성립한다고 간주하지 않는다. 원본 natural 증명이나 Picard 증명만으로 B.8 복구를 통과한 E의 a 양성과 source S 전체 경계가 자동으로 나오지도 않는다.

정확한 소스 결합은 `actual_loop_native_probe.mjs`가 변경하지 않은 원본 생산자를 실행해 확인한다. 검사 내용은 g21의 두 실제 monotone 등록부 동일성, 실제 M/R/Q의 μ 몸체, 정규화 기울임과 circle 몸체, 실제 lifted bracket, 원본 파일 무변경이다. 작은 scalar variance AST만 내보내며 전체 배경 자료를 노트북에 저장하지 않는다. `actual_loop_regularity.py --binding …`은 그 원시 AST를 독립적으로 읽어 정규화된 M과 R″의 정확한 식까지 비교한다. 소스 실행을 아직 하지 않은 로컬 결과에는 `originalProducerBindingExecuted:false`가 기록된다.

검증기의 음성 대조는 거짓 Vμ(0)>0, 잘못된 Q(0), vTarget을 v_s로 잘못 바꾼 정규화를 거부한다. 격자 표본이나 유한 부분합을 전체 영역 증명으로 승격하지 않는다. 이 보고서의 새 원본 Guard/Jet/PDE 소거 수는 0이며, 새 Lean 실행도 주장하지 않는다.
