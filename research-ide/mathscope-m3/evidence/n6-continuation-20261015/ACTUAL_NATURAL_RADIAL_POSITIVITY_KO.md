# 실제 natural 해의 반경 단조성과 양의 a

이 문서는 이미 독립적으로 증명된 실제 natural Banach 극한의 정량 경계를 한 단계 강화한다. 같은 원본 해에 대해 실수 eta∈I=[−33/32,33/32], 0≤Y≤41/10에서

```
Phi_Y ≤ −chi/32−1/(16Lambda)<0                            (P)
```

를 증명한다. 특히 4≤Y≤4.1에서 실제 natural 배경의 `a=−2Y Phi_Y/Phi`는 양수이고 `a⁻¹≤4Lambda<S`이다. 원본 B.26 전체나 B.34/B.8 이후의 배경으로 이 결론을 자동 연장하지 않는다.

## 1. 같은 실제 해의 두 항 전개와 오차

앞선 실제 natural 증명의 표기를 사용한다. t=Lambda⁻¹=Q⁻⁶⁴이고, x=(Phi,u), x0=(Schi 1,−J1(L⁻¹Zstar)/2)이다. 원본의 동일한 고정점 식은

```
x=x0+(t/2)B_t(x),
B_t=(Schi J2 R1^t, J1 R2^t).
```

여기서 Schi=(1+chi J2/2)⁻¹이다. 기존 24개 항의 양의 상계는 노름 Q 공에서 `||B_t||≤Q⁸`, `Lip B_t≤Q⁸`를 증명했다. R1/R2에서 명시적 t를 가진 항들의 부분합에도 같은 양의 상계를 적용할 수 있다. 고정 입력 g,Zstar,Q 등은 원래의 실제 값으로 고정해 둔다. B0는 그 다항식에서 명시적 t만 0으로 놓은 대수적 분해이다. 원본 g의 Lambda를 바꾸거나 다른 함수를 대입하는 정의가 아니다.

따라서

```
||B_t(x0)−B0(x0)||≤tQ⁸,
||x−x0||≤tQ⁸/2.
```

`x1=B0(x0)/2`라 놓으면 정확한 같은 해에 대해

```
||x−x0−t x1||
 ≤(t/2)[Q⁸||x−x0||+tQ⁸]≤t²Q¹⁶.                         (1)
```

계수노름에서 |Y|≤4.1의 첫 반경 미분 평가노름은

```
Σ_(n≥1) nY^(n−1)/[20^n(n+1)²]
 ≤1/[20(1−41/200)²]<1.
```

따라서 (1)의 Phi 성분을 Y로 미분한 오차도 t²Q¹⁶ 이하이다.

## 2. 선형 기준해의 모든 실수 경계

`Phi0=Schi 1=f0(chi Y)`이고

```
f0(x)=Σ_(n≥0)(−x)^n/[2^n n!(n+1)!].
```

실수 eta에서 0≤chi≤1이다. 0≤x≤4.1에서 미분급수는 첫 항부터 절댓값이 감소하는 교대급수이다. 따라서

```
−1/4 ≤ f0′(x) ≤ −1/4+x/24 ≤ −19/240 < −1/16.             (2)
```

원래 급수의 1차 이후 꼬리에도 교대급수 경계를 적용하면 `|f0−1|≤x/4`, f0≤1이다. 기존 실제 양성 증명에서 f0>1/4+1/128도 이미 얻었다.

원본 고정 함수에 대해 다음 정확한 단순화가 중요하다.

```
Bneg=Wstar+h(1−2eta Ustar)=−3+h−j eta,
c=Bneg/L≤−2, |c|≤4.                                      (3)
```

이는 D+h=1/2, Ustar=4eta+j를 그대로 전개한 등식이다. 기존 실제 매개변수 h,j<1/1000와 I의 유한 길이에서 (3)의 수치 경계가 따른다.

또한 실제 chi를 미분하면

```
Hstar chi_eta=2Hstar_eta chi(1−chi),
|Hstar chi_eta|≤40chi,                                   (4)
```

이다. 기존 증명의 |Hstar_eta|<20을 사용한다. 이 가중 미분은 sigma⁻¹ 비용 없이 제어된다. Hstar로 나누지 않으므로 Hstar=0도 포함한다.

실수에서 |d|≤1, 0<L≤1, L⁻¹≤2이며

```
|zeta|=(L/sigma)sqrt(chi)sqrt(1−chi)≤Q sqrt(chi).
```

기준해 u0의 노름은 Q/16 이하이므로 0≤Y≤4.1에서 |u0|≤Q이다.

## 3. x1의 첫 반경 미분은 엄격한 음의 기준항을 가진다

명시적 t를 0으로 놓은 실제 R1은 기준해에서

```
R1^0(x0)=L⁻¹[(Bneg+d u0 zeta)Phi0
                    +Wstar Y(Phi0)_Y+Hstar(Phi0)_eta]
         =c+Err.
```

(2)–(4), |Wstar|<23를 적용한다. ordinary 세 항에 대해

```
|Bneg(Phi0−1)|<8chi,
|Wstar Y(Phi0)_Y|<46chi,
|Hstar(Phi0)_eta|<80chi.
```

그리고 `|d u0 zeta Phi0|≤Q²sqrt(chi)`이다. 따라서 L⁻¹≤2를 포함해

```
||Err||_(C0[0,4.1])≤268chi+2Q²sqrt(chi)
                  ≤3Q²sqrt(chi)≤Q³sqrt(chi).              (5)
```

Q≥2²⁶⁰이므로 마지막 두 비교는 엄격히 충분하다.

J2는 실수 Y에서 양의 적분연산자이고

```
J2 f(Y)=Y⁻¹∫_0^Y(Y−s)f(s)ds,
|(J2^(k+1)f)_Y|≤||f||∞ Y^k/[k!(k+2)!].
```

두 번째 식은 J2와 그 Y 미분의 적분커널이 모두 양수임을 이용해 상수함수 1에 적용하면 얻는다. Y=0에서는 연속 극한이다. 따라서 정상수렴하는 resolvent 급수에서

```
|(Schi J2 f)_Y|
 ≤(||f||∞/2)exp(chi Y/2)<14||f||∞.
```

χY/2<3 및 e<3을 사용한 넉넉한 상계이다. x1의 1/2까지 포함하면 (5)의 기여는 `7Q³sqrt(chi)<Q⁴sqrt(chi)`이다.

상수 c의 항은 더 정확히 계산한다. 모든 chi≥0에 대해 급수를 직접 미분하면

```
(Schi J2 1)_Y=−2f0′(chi Y).
```

chi=0에서 나누지 않고도 성립하는 급수 항등식이다. 그러므로

```
(x1.Phi)_Y
 =−c f0′(chi Y)+(1/2)(Schi J2 Err)_Y
 ≤−19/120+Q⁴sqrt(chi)
 ≤−1/8+Q⁴sqrt(chi).                                     (6)
```

## 4. 실제 Phi_Y의 부호와 a 경계

(1),(2),(6)을 같은 실제 해에 적용하면

```
Phi_Y≤−chi/16−t/8+tQ⁴sqrt(chi)+t²Q¹⁶.
```

모든 chi≥0에 대한 완전제곱 부등식

```
tQ⁴sqrt(chi)≤chi/32+8t²Q⁸
```

을 사용한다. `8Q⁸≤Q¹⁶`, `2tQ¹⁶=2Q⁻⁴⁸<1/16`이므로

```
Phi_Y≤−chi/32−t/8+2t²Q¹⁶≤−chi/32−t/16<0.
```

이것이 (P)이다. 실제 Phi는 기존 증명으로 Phi>1/4이고, Phi0≤1 및 실제 오차에서 Phi<2이다. 따라서

```
a=−2Y Phi_Y/Phi≥Y/(16Lambda).
```

4≤Y≤4.1에서는 `a≥1/(4Lambda)>0`이다. (6)의 절댓값 경계에도 |c|≤4를 적용하면 `|Phi_Y|<1/2`이고 따라서 a<32이다.

## 5. natural collar에서 실제 source S 경계

이 절의 범위는 4≤Y≤4.1인 **같은 natural 함수**이다. X=Y/Lambda이다. 기존 실제 입력 경계에서 |Lambda psi|≤64Lambda/sigma²≤log CSelected이므로

```
g=exp(Lambda psi)/CSelected≥CSelected⁻².
```

이하 C=CSelected라 쓴다. 실제 매개변수 `log C≥Q²⁰⁰`에서 C>Q⁶⁵이며 Q≥2²⁶⁰이다. 따라서

```
E=sqrt(2X)gPhi>0, E⁻¹≤C³,
a⁻¹≤4Lambda<C.
```

계수노름과 첫 반경 미분 평가에서 |U_X|=|u_Y|≤Q이다. 따라서

```
|b_s|=|2XU_X/E|≤10QC³≤C⁵,
v_s=a+b_s²/a≤32+C¹¹<C¹²<S=C¹⁰⁰⁰⁰⁰.
```

`ACTUAL_NATURAL_B26_JOIN_KO.md`에서 증명한 실제 source.ns=−2U_X를 결합하면 `p_s,2=X ns/E=−b_s`이다. 따라서 |p_s,2|<S도 성립한다. 이 결론들은 실제 natural collar에서의 조건을 독립적으로 공급한다.

B.26 몸체는 y≥0의 넓은 영역에서 natural 함수와 같지 않다. 이 절의 a/v_s/p2 경계를 B.26 전체, B.34 이동구간, B.8 복구구간이나 C.1 전체 rectangle으로 단순 복사하지 않는다. 해당 실제 소스별 정의와 경계를 별도로 결합해야 하며, 그 전에는 전체 C.1 적용은 OPEN이다.

증명은 실제 natural Banach 정리와 원본 24개 항 상계만 강화하였다. 원본 상수나 생산자, 선택된 해는 바꾸지 않았다. 원본 Guard/Jet/PDE의 수는 이 파일에서 변경하지 않는다.
