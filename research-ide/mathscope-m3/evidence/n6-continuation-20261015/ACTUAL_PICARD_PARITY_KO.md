# 원본 Picard 계수의 정확한 반사 대칭과 even profile

대상은 실제 `picard:0`, SHA-256 `c3ee2bdec0b3f1bdd63a679bc1d6fbaeff72fc961e68b24b8a39efd4d6229b60`의 3,679개 계수 조상 식이다. ξ를 −ξ로 바꾸고 η는 고정한다. 검증기는 각 원시 식이 짝함수, 홀함수 또는 항등적으로 0인지 구조적 귀납법으로 증명한다. 알려지지 않은 연산이나 판정되지 않은 부호를 임의로 짝함수로 처리하지 않는다.

곱과 정수 거듭제곱은 반사 부호를 곱하고, 같은 부호끼리의 합은 그 부호를 유지한다. 제곱근·로그·exponential·실제 smooth step에는 반사 전후 인수가 같다는 조건을 먼저 요구한다. 이 등식은 해당 식의 정의역에서의 등식이다. 원시 식의 실제 정의역과 접합 정칙성은 별도 관문에서 공급한다.

적분 끝점이 모두 짝함수이면 적분변수는 반사하지 않고 integrand의 ξ 부호를 그대로 사용한다. 두 끝점이 홀함수이면 적분변수도 반사하고 방향 반전 부호를 한 번 더 곱한다. 0인 끝점은 어느 규칙에도 사용할 수 있다. 적분변수가 다른 바깥 적분의 반사 변수와 겹치면 안쪽 binder의 범위를 다시 적용한다. 반사하는 원래 ξ를 적분변수가 가리는 경우에는 별도 범위 증명이 필요하므로 거부한다. 자연급수의 실제 두 인수가 반사 전후 같을 때만 같은 natural 함수를 호출한다.

실제 결과는 forcing의 앞 세 성분이 0, 네 번째가 홀함수, 마지막 두 성분이 짝함수다. 실제 A0/A1의 모든 성분은 해의 부호 패턴

```
P = diag(1,1,1,1,-1,-1)
```

에 대해 `A_j(-ξ)=-P A_j(ξ)P`, `f(-ξ)=-P f(ξ)`를 만족한다. 원래 대각행렬 C는 P와 교환한다. 따라서 `w'(ξ)+Cw(ξ)/ξ=A0(ξ)w(ξ)+A1(ξ)w_eta(ξ)+f(ξ)`와 같은 zero-axis 적분식은 `w(ξ)→P w(-ξ)` 아래 불변이다. 0에서의 식은 원래 rescaled integral 표현으로 읽는다.

실제 계수의 공통 영역 정칙성과 Picard 급수의 국소 정상수렴·유일성을 별도로 확보하면, 같은 실제 zero-axis 해에 대해 `w(-ξ)=P w(ξ)`다. 즉 앞 네 성분은 짝함수이고 마지막 두 성분은 홀함수다. 유한 부분합이나 수치 표본의 대칭성으로 무한 해의 대칭성을 추정하지 않는다.

짝함수 C∞ 함수 f에 대해 원본이 사용하는 X profile은 `f(sqrt(X),η)`다. 임의의 고정 k≥1에 대해 반복 미적분학의 기본정리에서

```
partial_X^k f(sqrt(X),η)
 = 2^(-k) integral_[0,1]^k
       [product_j t_j^(2(k-1-j))]
       partial_xi^(2k) f(sqrt(X)*product_j t_j,η) dt
```

를 얻는다. 오른쪽은 X=0까지 연속이며 같은 식을 η에 대해 임의의 고정 차수로 미분할 수 있다. 이는 원래 `materializePicardEvenDerivative`의 인자·가중치·2의 거듭제곱과 같다. 원래 구간 `0≤X≤a²`, `a²=Xa exp(t1/16)`에서만 결론을 사용한다. 임의의 X≥0나 전체 g의 정의역까지 확장하지 않는다.

실행 코드는 `actual_picard_parity.py`다. 전체 원본 진단 파일의 해시와 실제 Picard 정의 해시를 확인하고, 서로 다른 forcing 및 cross-block 계수를 바꾼 대조를 거부한다. 별도 7개 검사는 적분 방향·binder 범위·미지 연산의 거부를 점검한다. 원본 Guard/Jet/PDE 신규 소거 수는 0이다.
