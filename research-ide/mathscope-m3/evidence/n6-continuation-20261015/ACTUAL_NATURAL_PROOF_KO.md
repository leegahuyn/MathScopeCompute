이 문서는 원본 `actual-continuation-exact-core.mjs:prepareActualNaturalCoreProgram`의 계수점화식을 그대로 대상으로 한다. `coefficientNormUpper: Q`라는 메타데이터 선언을 가정으로 쓰지 않는다. 실제 압력과 입력함수의 경계를 먼저 증명하고, 완비공간의 축약사상으로 같은 점화식의 유일한 극한을 구성한다. 유한 차수 계산을 무한급수 증명으로 대체하지 않는다.

## 1. 모든 혼합 차수를 동시에 다루는 완비공간

다음을 고정한다.

```
I=[-33/32,33/32],
b(n,m)=(n+m)!/[n! 20^n (n+1)^2 rho^m (m+1)^2],
||a||=sup_(n,m,eta∈I) |∂eta^m a_n(eta)|/b(n,m).
```

원소는 I 위의 매끄러운 함수들의 계수열이고 위 노름이 유한한 경우이다. 이 공간은 완비이다. 실제로 노름 코시열이면 각각의 고정된 n,m에 대해 도함수가 균등수렴한다. 함수와 그 다음 도함수의 균등극한에 미적분학의 기본정리를 적용하면 극한들이 연속된 도함수임을 알 수 있다. 끝점에서는 한쪽 미분을 사용한다. 각 노름 경계는 극한에서도 유지된다. 미지 함수의 복소 노름을 미리 가정하지 않는다.

곱의 계수에서 i+j=n, r+s=m이라 하면 Leibniz 공식의 팩토리얼 비율은

```
binom(i+r,r) binom(j+s,s) / binom(n+m,m) ≤ 1
```

이다. 분자는 n+m개 중 m개를 고르는 방법 가운데 앞 i+r개에서 정확히 r개를 고르는 방법의 수이다. 또한 모든 n에 대해

```
Σ_(i=0)^n (n+1)^2/[(i+1)^2(n-i+1)^2]
 ≤ Σ_(i=0)^n 2[(i+1)^(-2)+(n-i+1)^(-2)] < 8.
```

이는 n+1<n+2=(i+1)+(n-i+1), (a+b)²≤2(a²+b²), Σ_(l≥1)l⁻²<2로부터 나온다. m에 대해서도 같은 부등식을 적용하여

```
||ab||≤64||a||||b||
```

를 얻는다. n,m의 상한을 정하지 않았으므로 모든 혼합 차수에 대한 결론이다.

원본의 반경 평균 연산자를 `𝒜`라 쓰면 `(𝒜a)_n=a_n/(n+1)`이므로 그 연산자노름은 1 이하이다. 원본의 적분 연산자는 N≥1에 대해

```
(IY a)_N=a_(N-1)/N,
(J1 a)_N=a_(N-1)/N²,
(J2 a)_N=a_(N-1)/[N(N+1)]
```

이고 상수항은 0이다. b의 직접적인 비를 계산하면 세 노름 모두 80 이하이다. 원본의 계수 1/2은 이 연산자 밖에 그대로 둔다.

더 일반적으로 P가 r개 인자의 곱이라고 하자. 인자 전체 중 최대 하나에 η 미분을 한 번 허용하고, 최대 하나에 `Y∂Y`를 허용한다. 두 연산이 같은 인자에 있어도 된다. 평균 연산도 허용한다. e,d∈{0,1}이 각각 η 미분 및 `Y∂Y`의 존재를 나타내면 그 양의 Leibniz 상계는

```
64^(r-1) Π_j||a_j|| · n^d b(n,m+e)
```

이다. η 미분을 허용하는 단계에서는 `multinomial(m;m_j)≤multinomial(m+1;m_j+e_j)`를 쓴다. 반경 미분 인자의 차수는 전체 차수 n보다 크지 않다. N=n+1일 때

```
b(N-1,m+1)/[N²b(N,m)]
 =(20/rho)(N+1)²/N³ · ((m+1)/(m+2))².
```

여기에 `(N-1)^d`를 곱해도 80/rho 이하이다. e=0일 때는 같은 계산으로 80 이하이며 J2의 분모는 J1보다 크다. 따라서

```
||Ji P||≤80·64^(r-1)·rho^(-e)·Π_j||a_j||.                 (A)
```

이것이 실제 점화식에 필요한 연산자 경계이다. η 미분이나 `Y∂Y` 자체가 이 노름에서 유계라고 잘못 가정하지 않는다. 적분과 결합된 실제 연산자만 평가한다.

## 2. 실제 압력과 고정 입력함수의 경계

원본의 정확한 매개변수는 다음과 같다.

```
T=exp(2^20)+10, lambda=exp(-1000T), h=exp(-8002T),
logP=2T, Pstar=exp(logP), K=Pstar²,
j=h⁴, sigma=j/2000, rho=sigma²/65536,
Q=2^260 K/sigma², Lambda=Q^64,
BRefUpper=Q^300,
log CSelected=Q^200+10log(1+BRefUpper), co=1/256, Tf=128.
```

특히 `0<h<lambda<1/1000`, `0<j,sigma<1`, `K>1`, `Q≥2^260`, `rho⁻¹≤Q`이다. 전부 유한한 정확한 실수 식이다. 거대 지수를 부동소수점 0이나 무한대로 바꾸지 않는다.

원본 step 함수는

```
sigma_step(s)=exp(-1/s²)/[exp(-1/s²)+exp(-1/(1-s)²)]   (0<s<1)
```

이며 왼쪽에서 0, 오른쪽에서 1로 평평하게 이어진다. 분모는 양수이다. 내부에서는 odds의 로그 `-s⁻²+(1-s)⁻²`의 도함수가 양수이므로 단조증가한다. `sigma_step(1-s)=1-sigma_step(s)`이므로 그 원시함수 `S(s)=∫_0^s sigma_step(t)dt`는 `S(1)=1/2`이다. 이 기본 성질만 압력 경계에 사용한다. step의 복소 해석성을 가정하지 않는다.

실제 압력은 고정된 양의 측도에 대한 적분으로 쓸 수 있다.

```
P(z)=-∫ (1+z²)^(-2theta) dmu,        0≤theta≤1.             (B0)
```

이는 각 A.21 단계의 실제 적분에서 `logf=-log(1+z²)`를 분리한 식이다. 실제 integrand는 `exp(2(Astart+delta(s)+theta(s)logf))`이다. Python 검증기는 12개 단계 모두에 대해 다음 표와 실제 AST가 정확히 같음을 기호 연산으로 확인한다.

| 단계 | delta(s) | theta(s) |
|---|---|---|
| initial | s/10−(3/5)S(s) | 1 |
| axialDecay | −s/2 | 1 |
| entry | −s/2−lambda S(s) | 1 |
| reservedPower | (−1/2−lambda)s | 1 |
| pulse | (−1/2−lambda)s | 1 |
| interpolation | (−1/2−lambda)s−log(2)sigma_step(s/Tf) | 1−sigma_step(s/Tf) |
| angular | (−1/2−lambda)s | 0 |
| steepen | (−1/2−lambda)s−(1−lambda)S(s) | 0 |
| steepPower | −3s/2 | 0 |
| flatten | −3s/2+(1−h)S(s) | 0 |
| wait | (−1/2−h)s | 0 |
| terminal | (−1/2−h)s+log(fo(s)/(1−co h)) | 0 |

여기서 `fo(s)=1−co h(1−sigma_step((s−1)/2))`이다. 모든 단계의 길이와 시작·끝 log 진폭은 η와 독립이다. 이는 적분변수를 정확히 묶는 free-coordinate 검사로 확인한다.

초기 무한 앞부분의 측도 질량은 `5K/2`이다. 첫 단위구간에서는 delta(s)≤s/10이므로 질량이

```
(K/2)∫_0^1exp(s/5)ds < 5K/8
```

이다. `exp(1/5)<1/(1−1/5)=5/4`를 사용했다. 다음 axialDecay 구간의 질량은 K/2 이하이다.

이후 모든 log 진폭의 기울기는 −1/2 이하이다. flatten에서도 `−3/2+(1−h)sigma_step≤−1/2−h`이다. interpolation의 추가 인자는 비증가하고, 마지막 terminal에서만 `1≤fo/(1−co h)<2`의 인자가 붙는다. 따라서 이후의 모든 유한 단계와 삭제하지 않은 무한 뒷부분을 합친 질량은 `2Kexp(−T)<3K/8` 이하이다. 무한 꼬리를 0으로 치환하지 않는다. 그러므로

```
mu(total)<(5/2+5/8+1/2+3/8)K=4K.                           (B)
```

모든 단계 길이는 양수이다. 비자명한 wait 길이도 양수임을 확인할 수 있다. lambda>h이므로 앞선 scalar Q 해는 양수이다. `−4log h` 길이의 hold가 `(1−h)(−4log h)`를 더하고, flatten의 감소 인자는 exp(−1)보다 크므로 Qb>1이다. 원본 terminal 적분에서는

```
Qp≤exp(3)co h/(1−co h)<27/255999<1
```

이다. 따라서 `log(Qb/Qp)/(1−h)>0`이다. 나머지 길이들의 양성은 원본의 양수 매개변수 식에서 직접 따른다. 이 증명은 실제 natural 입력에 들어간 literal pressure의 증명이다. 다른 angular 수정이 물리적으로 pressure-neutral이라는 별도 주장으로 대체하지 않는다.

`|Im z|≤1/16`에서 `Re(1+z²)≥255/256`이다. 따라서 주가지 로그는 해석적이고, (B0)의 compact 균등 적분상계로 압력의 해석성을 얻는다. 또한

```
|P(z)|≤4K(256/255)²<5K.
```

아래의 훨씬 작은 tube 주변에서 반지름 1/32의 Cauchy 원이 이 strip 안에 있으므로 `|P′|≤160K`이다.

Ω를 I와의 거리가 `sigma²/2048` 미만인 복소 tube라 하자. Ω는 볼록이고 0을 포함하며 `|z|<17/16`이다. 실제 입력 다항식은

```
D=1/2−h, A=1/2+h, d=1−z², L=1−2hz²,
Ustar=4z+j, Hstar=Dz+d Ustar,
Wstar=1−4d−2Dz Ustar,
Zstar=−A(1−2z Ustar)Ustar−4Hstar−dP′+4AzP.
```

삼각부등식으로 Ω 위에서

```
|Hstar|<10, |Hstar′|<20, |Ustar|<5,
|Wstar|<23, |Zstar|<1024K, |L|>99/100
```

을 얻는다. 임의의 z∈Ω에 대해 가장 가까운 실수 x∈I를 택하면

```
|Hstar(z)²−Hstar(x)²|<(400/2048)sigma²<sigma²/4.
```

이에 따라 실제 분모 `Hstar²+sigma²`는 0이 아니다. `w=Hstar(z)²`라 하면 `Re w>−sigma²/4`이고, 따라서 `|w|≤|w+sigma²|`이다. 그러므로

```
|chi|=|Hstar²/(Hstar²+sigma²)|≤1,
|zeta|=|L Hstar/(Hstar²+sigma²)|≤32/sigma².
```

Ω 안의 선분을 따라 정의한 실제 원시함수 ψ는 `|ψ|≤64/sigma²`를 만족한다. `sigma⁻²≤Q/65536` 및 `Q≥2^260`에서

```
log CSelected≥Q^200≥64Q^64/sigma²+1
```

이므로 실제 `g=exp(Lambda ψ)/CSelected`는 Ω 위에서 `|g|≤exp(−1)<1`이다.

I의 각 점 주변 반지름 `r=sigma²/4096`인 원은 Ω 안에 있다. Ω에서 |f|≤M인 반경 상수 해석함수에 Cauchy 경계를 적용하면

```
rho^m(m+1)²|f^(m)|/m! ≤ M(m+1)²/16^m ≤2M.
```

따라서 실제 입력의 계수노름은

```
||chi||≤2, ||L⁻¹||≤4, ||g||≤2,
||Zstar||≤2048K, ||zeta||≤64/sigma².
```

이고 앞의 모든 다항식 입력의 노름은 Q보다 작다. 이 단계까지 미지 계수 Φ,u의 노름은 전혀 가정하지 않았다.

## 3. 선형 chi 항의 역연산자를 실제로 구성

`Tchi=(1/2)J2 M_chi`라 하자. chi는 Y와 독립이므로 M_chi와 J2는 교환한다. k≥1에 대해 직접 계수 비를 계산하면

```
||J2^k||≤20^k(k+1)²/[k!(k+1)!]≤80^k/[k!(k+1)!].
```

M_chi의 노름은 `64·2=128` 이하이다. 따라서

```
||Tchi^k||≤5120^k/[k!(k+1)!].
```

`S=Σ_(k≥0)(−Tchi)^k`는 연산자노름에서 절대수렴한다. 유한합의 망원합 항등식에서 나머지가 0으로 가므로 S는 `1+Tchi`의 양쪽 역연산자이다. 또한

```
||S||≤Σ_(k≥0)6400^k/(k!)²≤exp(160)<3^160<2^256≤Q/16.
```

중간 부등식은 `binom(2k,k)≤4^k`와 exp의 짝수항 급수로 증명한다. `3^160<2^256`은 정확한 정수 비교이다. chi의 노름이 작다는 가정은 필요 없다.

다음을 놓는다.

```
x0=(S1, −(1/2)J1(L⁻¹Zstar)).
```

두 번째 성분의 노름은 `(1/2)·80·64·4·2048K<2^25K<Q/16`이다. 최대값 곱노름을 사용하면 `||x0||≤Q/16`이고, x0 중심의 닫힌 반지름 1 공은 전체 노름 Q 공 안에 있다.

## 4. 실제 비선형 점화식의 24개 항 전체

`t=Lambda⁻¹`라 쓰고 평균 `𝒜`와 상수 A를 구별한다. 원본 계수 루프는 정확히 다음 식의 계수 점화식이다.

```
W=Wstar+t(−2D eta 𝒜u−d ∂eta𝒜u),
U=Ustar+tu, H=Hstar+tdu,
p=g² IY(Φ²), alpha=A(1−4eta Ustar)+4d,
R1=L⁻¹[(W+h(1−2eta U)+du zeta)Φ+W(YΦY)+HΦeta],
R2=L⁻¹[alpha u−2A eta t u²+W(YuY)+Hstar ueta
          +dt u ueta−4A eta p+d peta−2eta(YpY)].
```

특히 `cp=80·64³`라 하면 `||p||≤cp Q⁴`이고, 두 Φ의 압력 차이는 `2cp Q³||Φ−Φ′||` 이하이다.

| −2eta(YpY) | 2·80²·64⁵ | 6 | 2 |

미지 도함수 자체를 따로 유계라고 놓지 않는다. 각각의 η 미분은 (A) 안에서 처리되어 rho⁻¹ 비용만 발생한다. 다중선형 단항식의 차이를 미지 인자를 하나씩 바꾸는 망원합으로 쓰면 각 행의 Lipschitz 경계는 `차수·c·Q^(a−1)`이다.

두 표를 합친 정확한 양의 계수합은 `1779857372938240`, 차수 가중 계수합은 `3559706689208320`이다. 둘 다 `2^56<Q`이다. 값 경계의 최대 Q 지수는 7이고 Lipschitz 경계의 최대 Q 지수는 6이다. 따라서 노름 Q 공 전체에서

```
||(S J2R1,J1R2)||<Q⁸,
Lip[(S J2R1,J1R2)]<Q⁸.                                  (C)
```

검증기는 원본 식의 가환 다항식 전개에서 각각 정확히 12개의 항이 나오고 위 정수계수 상계가 성립함을 검사한다. 원본 압력미분항을 빠뜨린 경우, Lambda 지수를 바꾼 경우, J1의 역 반경차수 하나를 누락한 경우를 각각 거부하는 음성 대조도 포함한다. n,m의 유한 표본을 무한 차수 증명으로 사용하지 않는다.

## 5. 실제 극한 구성 및 원본의 모든 계수와 동일성

원본 점화식은 다음 고정점 식과 동치이다.

```
F(Φ,u)=x0+[1/(2Lambda)](S J2R1,J1R2).
```

(C)와 Lambda=Q⁶⁴에서 F의 변위와 Lipschitz 상수는

```
epsilon=(1/2)Q^(-56)<1/2
```

보다 작다. 따라서 F는 x0 중심 닫힌 반지름 1 공을 자기 자신으로 보내는 축약사상이다. 완비성과 반복 차이의 기하급수 경계로 극한 x가 실제로 존재한다. 유계 적분 연산자의 연속성에서 그 극한의 고정점 식이 성립한다. 이 공 안에서는 유일하며 `||x−x0||≤epsilon`, 특히 `||x||≤Q`이다. 이름만 붙인 존재 가정이나 유한 부분합에 의존하지 않는다.

계수 비교는 정확히 다음을 준다.

```
Φ0=1, u0=0,
Φ_(n+1)=[−chi Φn+t(R1)n]/[2(n+1)(n+2)],
u_(n+1)=[−L⁻¹Zstar·[n=0]+t(R2)n]/[2(n+1)²],
p_(n+1)=g² Σ_(i=0)^n Φi Φ_(n-i)/(n+1).
```

오른쪽에는 이미 결정된 앞선 반경 계수와 그 실제 η 미분만 들어간다. 반경차수에 관한 귀납법으로 원본 생산자의 모든 유한 차수 계수는 방금 구성한 하나의 극한의 계수와 같다. 원본 `actual_natural_series`는 이 동일한 계수열의 극한을 뜻하므로 다른 함수를 바꿔 끼우지 않는다.

고정된 임의의 반경·η 미분 차수와 `|Y|≤Ymax<20`에서 미분급수는 b(n,m)으로 균등수렴한다. 실제 항들의 비의 극한은 Ymax/20<1이다. 따라서 원본 natural 함수 자체의 정상수렴과 국소 C∞ 정칙성이 증명된다. 같은 계수에 대한 원본 꼬리 식도 유효하다.

## 6. 실제 Φ의 양성과 필요한 복소 역수 영역

선형 기준해는

```
S1=f0(chi Y),
f0(x)=Σ_(n≥0)(−x)^n/[2^n n!(n+1)!].
```

실수 η에서는 0≤chi≤1이다. 0≤x≤41/10에서 3차 이후의 교대급수 꼬리는 양수이다. 3차 다항식의 도함수는 `−[(x−8)²+32]/384<0`이므로

```
f0(x)≥1−x/4+x²/48−x³/1152
     ≥305719/1152000>1/4+1/128.
```

`||Φ−f0(chi Y)||≤epsilon`을 평가하면 Y≤41/10에서 오차는

```
epsilon/(1−41/200)<2epsilon<Q^(-56)<1/128
```

이다. 따라서 실제 원본 Φ는 `0≤Y≤41/10, η∈I` 전체에서 `Φ>1/4`이다. 이는 뒤의 Picard 계수 정의역 증명에 필요한 실제 양성을 가정 없이 공급한다.

같은 노름으로 η의 복소 확장도 얻는다. 실수 η∈I, |Y|≤5에서 먼저 반경계수를 합하면

```
|∂eta^m Φ|≤Q rho^(-m) m!/(m+1)² · (4/3)^(m+1).
```

따라서 η Taylor 급수는 반지름 3rho/4 미만에서 정상수렴한다. 거리 rho/4 이하에서는 미분한 Taylor 급수로부터

```
|Φeta|≤(Q/rho)(16/9) Σ_(l≥0)(l+1)/3^l=4Q/rho
```

를 얻는다. 여기서는 `(l+2)²` 분모를 버려 경계를 넓혔다. 이웃 Taylor 원판들은 실수구간에서 같으므로 항등정리에 의해 겹침 전체에서 같은 확장을 준다. I의 끝점에서도 한쪽 실수 Taylor 정리로 같은 결론을 얻는다.

원본이 지정한 `delta=rho/(1024Q)`를 사용하면 실수 0≤Y≤4.1 및 `dist(η,I)≤delta`에서

```
|Φ(Y,η)|≥1/4−(4Q/rho)delta=63/256>1/8.
```

따라서 실제 Φ의 역수는 이 η 복소 tube에서 잘 정의되고 해석적이다. 유한 수치 표본이나 Φ의 별도 수치 enclosure가 필요 없다. 이 결론은 Y를 실수로 유지한 η 복소 확장에 대한 것이며, 필요한 별도 복소 Y 영역이 있다면 그 영역은 추가로 증명해야 한다.

## 7. 원본 의무에 적용하기 전에 남는 정확한 경계

위 증명은 actual natural 계수의 노름과 수렴, Φ 양성 및 정해진 η 복소 tube를 해결한다. 원본 계수 생산자 재실행에 의한 몸체·287개 압력 AST 해시 동일성은 별도 실행 영수증으로 결합해야 한다. 이는 무한 증명의 내용과 원본 정의와의 동일성을 각각 확인하는 절차이다.

이 정리만으로 533개의 구문상 natural 호출 전부가 실행 중 유효하다고 선언하지 않는다. 현재 별도 적용 검사는 실제 58개 Y 형태, η=2인 원래 자리표시자, k≤3·m≤5의 표기, lazy guard와 적분변수 경계를 추출한 상태이다. 다음 내용은 각각 실제 native 치환·활성 분기와 결합되어야 한다.

1. 각 활성 호출의 Y가 위 수렴영역 안에 들어가는지, Φ 역수를 쓰는 곳에서는 0≤Y≤4.1인지 확인한다.
2. η의 native 치환 및 적분변수·중첩 호출 치환 후에도 공통 실수 I 및 필요한 복소 tube를 유지하는지 확인한다.
3. 원본 Picard 해, 비선형 역함수, 압력의 전체 반경 적분에 필요한 실제 계수와 분모·적분영역 경계를 결합한다.
4. 도출한 C∞ 정칙성을 실제 indexed derivative, 평평한 지지집합 경계, Jet/PDE 조립에 같은 원본 함수로 적용한다.

따라서 이 보고서 자체의 새 원본 Guard/Jet/PDE 소거 수는 0으로 유지한다. 이는 위 해석학적 정리가 조건부라는 뜻이 아니라, 원본 전체 의무로의 모든 적용 전제가 아직 별도 증거를 필요로 한다는 뜻이다. 실제 호출 문맥과 정의역 결합 없이 단순히 조건 수나 메타데이터 값을 바꾸지 않는다.

재현 파일: `actual_natural_proof.py`, `actual_natural_proof.json`, `actual_natural_proof.kernel-probe.mjs`. 수학적 독립 검토는 `package_proof_audit` 담당자의 별도 영수증을 함께 참조한다. 새 Lean 형식증명을 실행했다는 주장은 하지 않는다.
