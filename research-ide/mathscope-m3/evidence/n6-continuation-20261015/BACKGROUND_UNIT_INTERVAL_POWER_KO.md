# 실제 eta 제곱의 구간 상계를 보존하는 규칙

run38733393420은41개 검사를 모두 통과했지만 실제26개는 계속 OPEN이다.
현재 원본 장애는402510 역수이며, 완전한11-node cone은 그 분모가
1-2*h*eta402372^2임을 보여준다. 부호 검증기가 eta의 구간이0을 가로지를
때 짝수 제곱의 상계를 잃었으므로 보수적 분모 하계가 미정으로 남았다.

수정은 특정 ID나 좌표 이름을 허용하지 않는다. 실제 재귀 계산된 두
유한 끝점이 모두[-1,1] 안에 있고 지수가 양의 짝수 정수인 경우에만
0<=x^n<=1을 보존한다. 입력이0을 포함하면 제곱이 엄격히 양수라고 하지
않는다. 범위를 벗어나거나 끝점이 미정이면 상계1을 가정하지 않는다.
음의 거듭제곱은 여전히 먼저 비소멸을 검사하며0의 역수는 거부한다.

원래 h=exp(-8002*T),T>128이므로0<h<1/16이다. 실제 FTC binder의
eta 범위가[-1,1]임을 원본 재귀 계산으로 얻으면 분모>=7/8>0이고 역수가
유한 양수다. 로컬11-node 재검사는 이 범위 전제 아래의 조건부 결과다.
원본 source generator의 face box가 같은 eta 끝점을 쓰는 사실과 실제
전체 캐시에서의 binder 전송은 구분한다. 다음 fresh 실행이 후자를 검증한다.

상수·함수·영역·순서 미분·14개 전역 요구사항을 수정하지 않았다.
앞서 승인한 실제 leading/order-one native 값도 수치 norm이나 부호를
가정하지 않는다. 최종 본문과 나머지 모든 정의역이 통과하기 전까지
원본26개, Guard10, PDE1020의 상태를 승격하지 않는다.
