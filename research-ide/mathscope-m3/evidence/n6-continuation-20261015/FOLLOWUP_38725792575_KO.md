# Picard0 보존형 의존성 수술: 현재 검증과 다음 적용 경계

원본 Guard10 / Cartesian Jet230 / PDE1020, 합계1260개는 아직 OPEN이다.
원본 ID, 상수, 정의역, 순서 있는 미분, PDE 계수와 인자를 그대로 유지한다.

run38725792575는 36개 범위 검증 중35개가 통과했다. Picard0의 기존
B, C1, common-collar solutionNorm 및 Kcondition AST 검증, 실제 outer
amplitude bracket/복소 tube, eta 호출 인자, PDE 증분 항등식은 실행됐다.
공통 의존구조 도구는 미정인 conditionalTarget 행에서 실패했다. 실제
호출로 registry와 정의 SHA를 재결합하도록 수정하며, 미정 도함수 전제는
삭제하지 않는다. 실행 성공만으로 원본 의무의 증명을 추론하지 않는다.

배경 Jet26 도구는 실행에 성공했으나 실제 정적분239의 정당화가 남아
26개 모두 OPEN을 반환했다. 별도 장부도 신규 소거0/잔여1260을 기록한다.

사용자가 요청한 재사용 경로를 다음처럼 검증한다.

1. B/C1/solutionNorm/K의 실제 AST와 모든 analytic 입력을 독립 대조한다.
2. 실수 eta의 계승형 경계로부터 같은 함수의 공통 복소 tube를 만들고,
   겹치는 Taylor 전개 일치와 균일성을 검증한다. 값 tube와 추가 Cauchy
   미분에 필요한 더 작은 tube를 구분한다.
3. 원래 허용 입력 전체의 매개변수 부등식, K조건과 꼬리 정밀도를 유지한다.
   commonCollar와 naturalExtensionToY5의 적용 범위를 구분한다.
4. 실제 complete_gr와 Picard/적분/역수/Fourier 소비 경로를 원본 AST로
   연결한다. native 본문의 미확인 전제는 단순 의존 빈도로 대체하지 않는다.
5. 실제 모든 전제가 닫힌 원본 Guard/Jet ID만 PASS 후보로 옮긴다.
6. PDE 직접 평가와 조립식의 차이에 동일한 증명을 소비시킨다. 비선형
   제곱, 교차 이류, cutoff 미분, 실제 강제항 및 미증명 잔여를 유지한다.

논문의 정칙성/접합/압력/수정 순서를 실제 원본 구현에 적용한다. 논문의
결론이나 소스 해시 일치만으로 MathScope의 남은 전제를 승인하지 않는다.
독립 PDE 증분 항등식은 증명됐으나 실제 전체 필드로의 합성은 아직 OPEN이다.
