# 원본 indexed 도함수 검증 범위

대상은 `fieldDefinitions:6~9`의 원본 각도 속도 3성분과 압력이다.
이 네 함수가 원본 Jet230 중 67개 요청을 차지한다. 새 검증기는 실제
162개 행의 함수 몸체·인수·가드·정규화 계수를 그대로 사용한다.

미분할 때 원본 band 번호, mesh 정수, palette 차수와 nearest-copy 정수를
먼저 고정한다. 실제 미분 방향은 `R,Z,T,Y0,Y1,theta` 여섯 개다.
검증기는 실제 전체 인수 사상을 직접 미분한 10×6 Jacobian을 원본의
`derivativeMaps`와 비교한다. 다섯 covering 차수의 모든 행에서 빠진 항과
0인 항까지 확인하고, 바깥 계수와 Jacobian이 여섯 방향에 대해 상수인지
확인한다. 값이 없는 계수나 도함수를 0으로 바꾸지 않는다.

원본 67개 요청의 미분 순서를 보존하며, 혼합 미분의 양쪽 순서를 별도로
남긴다. 전체 10,854개 행별 미분 프로그램은 원본 함수 몸체와 전체
인수를 유지한다. 예를 들어 실제 두 항으로 구성된 Y0 사상에서 2차
미분은 `a² f_xixi + 2ab f_xiv + b² f_vv`이다. 가운데 계수 2, 교차 항,
각도 항과 원본 정규화 계수를 생략하지 않는다. 실제 계수 변경, 항 누락,
2차 미분 중복 계수 누락, 필요한 Leibniz 항 누락을 음성 대조로 검사한다.

원본 slow 가드의 활성 반경은 3/4이고, 후보 목록에서 빠지거나 새로
들어오는 정수 label은 거리 3/2 이상이다. 따라서 실제 활성 행을 버리지
않으며, 목록이 바뀌는 경계 근처에서 해당 행은 0이다. nearest-copy 경계도
실제 지지집합과 떨어져 있어 그 근방에서 전체 행이 0이다.

다만 실제 고정 label 함수 몸체가 필요한 C1/C2 정칙성을 가지며 진짜
지지집합 경계에서 평탄하게 0으로 이어진다는 증명은 여전히 필요하다.
위 미분 프로그램은 그 정칙성이 성립할 때의 정확한 연쇄법칙이며,
미지의 실제 도함수 값이나 정칙성을 새로 증명했다고 간주하지 않는다.
따라서 원본 Jet/PDE 신규 소거 수는 계속 0이다.
