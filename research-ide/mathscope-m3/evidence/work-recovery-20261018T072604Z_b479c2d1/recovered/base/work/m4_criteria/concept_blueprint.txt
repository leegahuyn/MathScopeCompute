02 / MATHEMATICAL CONTRACT
그림이 약속하는 것과 증명이 보장하는 것
객체의 수학적 의미, 표현의 의미, 증거의 신뢰 수준을 각각 명시한다.
설계 제안 v0.1  ·  2026.10.06
03
01
세 가지 차원을 함께 표시
내재 차원 dim(M), 주변 공간 차원 N, 표시 차원 3을 분리한다. 복소 차원 d는 매끄러운 복소점 공간에서
 실차원 2d에 대응한다. 스킴의 Krull 차원과 실수점 집합의 차원도 구분한다.
02
표현은 원본의 대체물이 아니다
n>3 다양체의 열린 부분을 연속 단사 방식으로 R³에 담는 일반 해법은 없다. 사영의 겹침, 가려짐, 밀도
는 원본의 교차·특이점·곡률을 자동으로 뜻하지 않는다.
03
관측법의 조건과 정의역을 저장
사영행렬, 단면 방정식, 좌표 차트, 기저·쌍대함수, valuation 및 선택한 계수를 기록한다. 제외점, 유효한
차트 영역, 절단 범위는 화면에도 표시한다.
04
연속 경로와 차원의 변화를 구분
P_t처럼 관측 사상이 연속적으로 변해도 대상의 정수 차원이 연속적으로 변하는 것은 아니다. rank 저하
와 단면의 임계값은 별도 사건으로 남긴다.
05
증거는 범위와 함께 제시
표본 기반 왜곡 추정, 정확 연산, Lean 증명, 전문가 검토를 다른 종류로 저장한다. 유한 표본에서 관찰한
성질을 대상 전체에 대한 정리로 올리지 않는다.

09 / GEOMETRY
S³로 구분하는 projection과 slice
S³ = {x ∈ R⁴ : x₁²+x₂²+x₃²+x₄²=1}. 같은 대상도 관측법에 따라 다른 그림이 나온다.
설계 제안 v0.1  ·  2026.10.06
10
Projection / P(x)=(x₁,x₂,x₃)
상은 닫힌 단위 3-ball B³이다. 내부의 각 점은
x₄=±√(1-||y||²)인 두 원상점을, 경계점은 하나를
가진다. 표면만 그리면 전체 투영을 오해하기 쉽
다.
Slice / x₄=c
|c|<1에서는 반지름 √(1-c²)의 S².
|c|=1에서는 한 점.
|c|>1에서는 공집합.
단면의 차원과 원본의 차원을 구분한다.
정사영: B³
단면: c에 따른 구면의 변화

수치 구현에서 지켜야 할 점
정확한 단면 프리셋은 매개화로 생성한다. 일반 점구름에 |x₄-c|<ε 필터를 적용하면 두께가 있는 slab 표본이
므로 “근사 단면”과 ε를 표시한다. 임계값 근방에서는 부동소수점 오차와 퇴화를 따로 검사한다.
Stereographic projection은 후속 선택 기능
북극 N을 제외한 S³에서 y=(x₁,x₂,x₃)/(1-x₄)로 정의한다. N 부근은 크게 확대되므로 제외점과 화면 절단 반경을 명
시한다. 영상은 R³ 전체이며 유한 화면에는 일부만 담긴다.

Banach: 연속 쌍대의 함수로 관측
실 Banach 공간 B에서 ℓ₁, ℓ₂, ℓ₃ ∈ B*를 선택하고 O(f)=(ℓ₁(f),ℓ₂(f),ℓ₃(f))로 둔다. 이는 유계 선형 유한 rank 관측
이며, 추가 구조가 없으면 B 안으로의 “직교투영”이라고 부르지 않는다. 같은 관측값은 kernel 방향의 차이

Hilbert: 정규직교 성분과 잔차
실 Hilbert 공간에서 O(f)=(〈f,e₁〉,〈f,e₂〉,〈f,e₃〉). Qₖf=Σⱼ₌₁ᵏ〈f,eⱼ〉eⱼ를 사용하면 ||f-Qₖf||²=||f||²-Σⱼ₌₁ᵏ|〈f,eⱼ〉|². 전체 
노름을 알 때 계산하며, 모르면 잔차도 추정 또는 미확인으로 표시한다.
L²([0,1]) 데모의 구현 계약
항목
