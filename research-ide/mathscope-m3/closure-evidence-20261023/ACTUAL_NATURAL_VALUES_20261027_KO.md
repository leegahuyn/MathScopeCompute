# 원본 비선형 natural 해의 실제 구간값

입력은 명시 I′=[−2,2]의 전체 fixed-point 증명 실행 `9606baa9369803217bc620436c2c06f4ad6c4667cc7deb94c93bb6aa32d39f21` 및 실제 A.21/u₁ 실행 `148b63ed06fa43fad880d8c4f5aedaf3a480bdd4a56f21746e3c0acbdc7697f9`다. 두 실행의 canonical hash와 원본 파일 bytes SHA를 모두 확인한다. 전체 복소해석·Banach 정리는 written analytic proof이며 완전한 Lean 형식 증명은 아니다.

## 1. 비교 함수에서 실제 해로 가는 검증된 오차

앞선 증명의 map 변위 상한이 ball 전체에서1/(2Q⁴³)이므로 fixed point 자체에서도

`||Phi−f0(Ychi)||_Brho, ||u−Y u1||_Brho ≤1/(2Q^43)`.

averaging의 norm≤1이므로 `||average(u)−Y u1/2||`에도 같은 상한이 성립한다. 이때 f₀는 단지 실제 해의 중심 함수이고, **위 비선형 오차를 실제 값의 구간에 더해야 한다.** 비교 함수만을 원본 비선형 해라고 부르지 않는다.

정확한 coefficient weight와 generating function의 k차 Y 미분으로, 실제 두 해의 차이 E에 대해

`|∂Y^k ∂η^m E| ≤Q^-43 ρ^-m (m+k)!/[2(m+1)²20^k] (1−Y/20)^(-m-k-1)`.

0≤Y≤5, η∈I′에서 성립한다. 원본523개 call의15개 (k,m) 형태에 대해 m≤5,k≤3이며 마지막 유리수 prefactor는 Y=5에서2²⁰보다 작다. ρ^-1<Q, Q>2^32768이므로 위 절대 오차는

`<2^20 Q^-38<2^-4096`.

이 작은 상한은 무한급수 tail의 Q를 무시해서 얻은 것이 아니다. 이미 증명한 fixed-point의 실제 중심으로부터의 거리 Q^-43을 사용한다. 원본의 거대한 Q를 곱한 일반 tail을 작다고 오해하지 않는다.

원본 양의 h에 대해 Q>h^-8이므로 오차는2²⁰h³⁰⁴<h³⁰⁰보다도 작다. 따라서 h⁵까지의 양의 인자로 나눈 뒤에도 오차<h²⁹⁵<2^-4096이다. 이로써 실제 u의 짝수 η 미분을 h⁴,h⁵로 정규화할 때도 원본 비선형 오차를 안전하게 포함할 수 있다. K>1로 나누는 홀수 미분도 같은 상한으로 포함된다.

## 2. 실제 Phi 양수성

실수 η∈I′에서 chi=H*²/(H*²+σ²)∈[0,1]이다. 0≤Y≤4.1이면 t=Ychi/2≤41/20이다. f₀의 교대급수에서 cubic 뒤의 짝지은 tail은 양수이고, 각 항 크기의 ratio는 이후1보다 작다. 그러므로

`f0(Ychi) ≥1−t/2+t²/12−t³/144 ≥305719/1152000`.

이 cubic은 구간에서 미분이 음수이다(−1/2+t/6−t²/48≤−1/2+(41/20)/6<0). 따라서 최소는 t=41/20이다. 실제 Phi에 비선형 오차를 빼도

`Phi>305719/1152000−2^-4096>53/200>0`.

이는 I′와 Y∈[0,4.1]의 **실제 natural 해**에 대한 양수성이다. 이 사각형이 모든 물리 native 호출을 덮는다는 주장은 별도이다.

## 3. 원본33개 Y 입력과 η=0에서의 평가

원본 graph·registry·producer SHA를 다시 대조하고 다음 정확한 source node를 검사한다.

- Y#474는 literal4이다.
- Y#3628=Lambda·Xa·exp(t1)=4exp(t1)이다. **exp(t1/16)이 아니다.**
- 두 그룹의 eta 인자는#2 `coordinate eta`다.

원본 CSelected>exp(Q²⁰⁰)>2⁴⁰⁹⁶이므로 0<t1<2^-491520이다. exp(t1)−1<2t1이므로 `4<Y#3628<4+2^-4096`이다. 양수 t1을0으로 대체하지 않고 이 구간을 계산에 사용한다.

원본의 이 두 Y 인자를 가진 actual_natural_series 연산은33개다. 각각 Phi/u/average와 η 미분의 실제 source ID를 보존한다. **평가점은 명시적으로 η=0이다.** 원래 모든 물리 호출에서 η가0이라는 주장이 아니며, native caller 전역 지원집합을 인증하는 것도 아니다.

## 4. Phi 축 미분의 유리수 계산

ξ=η/j₀=η/h⁴로 두면 정확히

`H*/j0=1+(9/2−h)ξ−h^8 ξ²−4h^8 ξ³`,
`chi=(H*/j0)²/[(H*/j0)²+1/4000000]`.

양수 j₀ 인자를 대수적으로 소거했으므로0을 포함하는 h 구간을 역수로 취하지 않는다. |ξ|≤1/16에서 |H*/j₀−1|<1/3, |H*/j₀|>2/3이다. 분모의 modulus는4/9−1/4000000>2/5이고 |chi|<2이다. 따라서 **비교 중심**은 이 ξ disk에서 정칙이다. 원본 실제 해가 같은 큰 disk에서 정칙이라고 주장하지 않는다. 실제 해와 중심의 미분 차이는 별도의 Bρ 오차로 처리한다.

비교 중심 f₀(Ychi)의 radial n항은 `(−Ychi/2)^n/[n!(n+1)!]`다. 0≤Y≤5, 위 ξ circle에서 k차 Y 미분의 modulus는

`(n)_k 5^n/[n!(n+1)!]` 이하이다.

η의 정규화된 m차 미분(j₀^m∂η^m=∂ξ^m)의 전체 tail은 Cauchy 부등식으로 m!16^m을 곱한 양의 급수로 감싼다. n>N일 때 연속 term ratio는 `5/[(n+1−k)(n+2)]`이며 감소한다. 실행은 N=32의 첫 미포함 항/(1−ratio)로 모든 tail을 포함한다.

ξ의 formal polynomial을5차까지 interval arithmetic으로 계산하고 chi^n의 해당5차 계수를 convolution한다. 항별 유리수와 바깥쪽 dyadic 반올림을 사용한다. 여기에 전체 comparison tail과 원본 비선형 오차2^-4096을 함께 더한다. 출력은 `h^(4m) ∂Y^k∂η^m Phi(Y,0)`의 실제 구간이며 원래 양의 scale을 별도로 보존한다.

## 5. 실제 u·average와 표시 데이터

이전 실행의 원본 u₁ η 미분 구간에 Y 또는Y/2를 곱하고 실제 비선형 correction을 더한다. 짝수 미분의 h⁴·h⁵, 홀수 미분의 K 정규화를 그대로 보존한다.

표시용 u(Y,η)/K도 원본 u₁/K의65개 구간에 실제 Y를 곱한 뒤 전체 비선형 오차를 더한다. 따라서 새 데이터는 단순 첫 Taylor prefix가 아니라 **명시 구간의 전체 nonlinear natural 해의 포함 구간**이다. 원본 A–D 전역 속도장과는 구분한다.

Phi 표시에는 미세 ξ=η/h⁴ 좌표를 사용한다. coarse sample 외에 ξ≈−2/9 근처를 간격1/9000으로 refine해 H*의 작은 영점 부근을 놓치지 않는다. h를 수치0으로 놓지 않고 원본 양수 h의 factored coordinate를 쓴다. Y0..4.1의17개 층에서 실제 Phi 구간을 생성한다. 첫 층은 원본 axis 조건 Phi(0)=1,u(0)=0을 정확히 사용한다.

표시 구간은40bit dyadic 바깥 반올림이며, 그림은 그 중앙값 사이를 보간하는 시각화다. 보간 면 자체를 모든 중간점의 검증 구간 또는 최종 물리장으로 해석하지 않는다. 정확한33개 축 평가에는 별도의256bit arithmetic과 명시 scale이 사용된다.
