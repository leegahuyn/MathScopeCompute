# 적분 변수와 적분값의 구분 및 실제 native 인자 연결

이 변경은 원본 첫 FiveMap 소스의 잘못 분류된 입력 의무를 교정한다. 최종 A–D 장, 전역 에너지, 67개 최종 제트 또는 M4 인수를 완료했다고 주장하지 않는다.

## 원본에서 확인한 오류

`actual-continuation-exact-order-one.mjs`의 `integrate()`는 `G.fresh(prefix)`로 적분 변수를 만들고, 그 변수로 원래 X를 치환한 뒤 `G.integral(body,t,0,X)`를 만든다. 따라서 다음 이름은 적분값 Ωj가 아니라 **적분 변수 t**를 뜻한다.

| 좌표 노드 | 변수 이름 | 실제 루트 도달 자연급수 호출 |
|---|---|---:|
| 29442 | actual_n1_Omega_prefix0$201 | 26 |
| 30317 | actual_n1_Omega_prefix1$202 | 26 |
| 31193 | actual_n1_Omega_prefix2$203 | 18 |

기존 `audit_original_217_Y_domain_obligations.py`의 “implicit root” 설명을 수정했다. `audit_original_Omega_prefix_sign.py`의 적분값 부호 추정과 `audit_original_Omega_local_Linf_sufficiency.py`의 적분값 L∞ 추정은 별도의 일반 명제이며, 이 70개의 Y 입력 의무에 적용하지 않는다. 후자의 결과 스키마는 이 교정을 표시하는 v2로 바뀌었다. 과거 결과 파일을 새 인증 결과로 소급 변경하지 않는다.

## 적분 구간과 분기를 함께 확인하는 검사

`original_omega_binder_domains.py`는 SHA가 고정된 전체 4,420,257 노드를 재생한다. 독립 native 본문 도달 검사로 523개 급수 ID와 1,745개 native 본문 진입점을 확보하고 정확한 ID 목록의 해시를 다시 확인한다.

- 43개 호출의 Y는 Λt다. 실제 before 분기는 t≤Xa를 요구하므로 0≤t인 적분 구간에서 0≤Y≤4다.
- 27개 호출은 ΛXa·exp(log(t/Xa))다. 내부 before 분기의 직접 인자 상한은 Xa·exp(t1)이다. 바깥쪽 양의 반경 분기가 로그의 양성 조건을 제공한다.
- 원본 N3의 ΛXa=4와 0<t1<2^-120으로 Y<4/(1-2^-120)<4.1을 얻는다.
- 세 변수의 실제 적분 문맥 38개를 확인한다. source body를 담은 진입점 50558과 117047에서 상한·하한·해당 로그 사용의 미해결 경로가 없다.
- 경로를 OR로 합쳐 보호되지 않은 다른 사용 경로를 숨기지 않는다. 적분 끝점은 적분 변수의 결속 범위에 포함하지 않는다. 내부 적분에 가려진 같은 이름의 변수는 바깥쪽 분기나 적분으로 인증하지 않는다.

이 결과는 **해당 native 진입점에 전달되는 반경 X가 실수이고 0 이상이며, 원본 native 치환·미분 의미론이 성립한다는 전제** 아래의 소스 경로 정리다. 이 전제를 실제 물리장 전체에서 인증한 전역 결과로 바꾸지 않는다.

## 실제 도달 인자로 범위 축소

이전 5,545개 인자 집계는 전체 소스 그래프를 대상으로 했다. 원래 11개 물리 루트의 독립 native 본문 도달 집합과 교차하면 직접 114개 급수를 포함하는 expression 호출은 **317개**다.

| 실제 도달 호출의 X 인자 | 호출 수 | 확인한 범위 |
|---|---:|---|
| 정확한 0 | 6 | 비음수 |
| 기존 formal X | 7 | 입력 반경의 비음수 전제 유지 |
| 곱셈으로 표현된 인자 | 252 | 제곱합/양의 배율 또는 양의 bracket 근을 분모로 하는 식의 비음수 |
| 새 적분 변수 | 52 | 실제 적분 끝점 및 변수 결속으로 비음수 확인 |

`original_reachable_X_nonnegative.py`는 317개 실제 호출의 원본 formal/actual 인자와 도함수 차수를 대조하고, 위 비음수 의무를 native 본문 진입점까지 추적한다. 고정된 원본 근 system 2의 [1/2,2] bracket은 **해당 근이 존재하고 실수로 정의되는 경우**에만 사용한다. 이 프로그램이 그 존재를 대신 증명하지 않는다.

다른 nested native 인자군과 실제 외부 호출자의 영상 소속은 별도로 남는다. 이 정리들을 이유로 원본 전역 Y 인증 집계를 33/523에서 자동 증가시키지 않는다.

## 고정 대표점과 현재 물리점의 구분

`original_representative_frozen_coordinates.py`는 원본 #623935와 #622820의 실제 인자 의존성을 별도로 재생한다. N3 상수에 포함된 다섯 개의 적분에서 적분 변수와 자유 변수를 정확히 구분한다. #623935의 자유 좌표는 frozen band ell과 고정 메시 r,z,t 네 개뿐이다. 현재 slow 좌표 R,Z,T에 의존하지 않는다. 원본 native system 2의 정의 본문에도 선언되지 않은 추가 자유 좌표가 없다.

따라서 라벨과 원본 상수가 고정되고 선택된 값이 정의되면, 대표점의 모든 양의 차수 물리 시간·공간 미분은 0이다. 선택 함수를 N3 파라미터나 라벨에 대한 함수로 바꿨을 때의 C0 불연속 예제는 물리 좌표에 대한 불연속 예제가 아니다. 서로 다른 라벨의 대표점 값도 동일할 필요가 있다는 결론을 이 검사에서 내리지 않는다.

이는 활성 메시마다 역근이 실제로 존재한다는 증명이나 전체 합의 평탄 접합 증명이 아니다. 이 두 의무는 별도로 남는다.

`1a4589381ad2cd8b59e95b76113fd75e2bbb28b9b93e885520ab22643f50d5ce`

이 Git blob은 원본 PR #30과 감사 브랜치에서 같다. 주입된 파라미터 사전에서도 같은 검사를 수행하므로, 기존 hash 문자열을 그대로 두고 h 또는 XR 수식을 바꾸는 입력을 거부한다. 양의 로그 인자의 실수 로그는 부호를 임의로 양수로 만들지 않고 UNKNOWN으로 유지한다.
