# 원본 h의 물리 좌표 → slow inverse 계산

`original_physical_slow_chart.py`는 첨부 논문의 좌표 관계와 원본 native system 2의 방정식을 연결해 q와 그 4차 이하 미분을 유리수 구간으로 계산한다. τ=1−t>0이며, τ와 z의 닫힌 입력 구간에서 `τ_upper+max(z²)≤1`인 영역을 다룬다. 이 영역 조건만으로 원본 최종장의 활성 band·mesh에 들어간다는 주장은 하지 않는다.

## 존재·유일성과 구간 계산

원본 지수는 `h=exp(-8002*(exp(1048576)+10))`, `D=1/2-h`, `0<h<H=2^-4096`이다. 전체 N3 표현의 독립 해시를 재계산한다. 실행 파일은 원본 그래프와 native registry의 전체 SHA도 확인하며, D의 원본 노드 #21·#22와 inverse 방정식·호출을 검사한다.

`q-z²q^(2h)=τ`의 좌변이 모든 q>0에서 증가한다고 가정하면 안 된다. 대신

`G(q)=z²q^(-2D)+τ/q`

는 q>0에서 엄격히 감소하고, 양 끝 극한이 ∞와 0이다. 따라서 `G(q)=1`의 양의 해가 정확히 하나 있다. `G(1)≤1`이므로 q≤1이며, 원래 방정식에서 q≥τ>0이다.

`τ_lower≥2^-B`를 보장하는 정수 B를 정확히 계산한다. 그러면 `-B≤log q≤0`이므로

`1-2HB≤q^(2h)≤1`,

`τ_lower+min(z²)(1-2HB) ≤ q ≤ τ_upper+max(z²)`.

단일 점에서는 이 구간의 비율이 2보다 작다. 일반 입력 상자에서는 넓이가 너무 클 수 있으므로 해당 상자를 하나의 차트로 덮지 못하면 오류를 내며, 미검사 셀을 버리지 않고 분할해야 한다.

## 원본 inverse 영상과 미분

q 상한에 가까운 이진 척도를 `Q=2^-ell`로 택하고, 계산된 전체 q 구간이 `[Q/2,2Q]` 안에 있는지 검사한다. 바닥 이진 척도에 대한 q 상한의 비율이 3/2를 넘으면 이웃의 두 배 척도를 사용한다. 또한 `1/8<(q/Q)^4<8`을 정확한 유리수로 검사해 원본 band offset 지지조건 `|log2(q/Q)|<3/4`를 보장한다. 넓은 상자가 이 조건을 만족하지 못하면 분할을 요구한다. 이는 한 band의 offset 지지조건이며, ell≥ell0나 coefficient window 인증은 아니다. 실제 정의는

`s=q/Q`, `Z=z/Q^D`, `T=τ/Q`.

`2D+2h=1`이므로 `s-Z²s^(2h)-T=0`. 또한

`eta²=Z²s^(2h)/s=1-τ/q<1`,

`∂s F=1-2h eta²≥1-2H>1/2`.

따라서 **이 물리 입력에서 함께 만들어진 Z,T 쌍**은 원본 inverse의 영상 안에 있다. 출력 Z 구간과 T 구간의 데카르트 곱 전체에 대해서는 같은 주장을 하지 않는다. 제트 재귀는 각 실제 영상점의 s·s^(2h)·Jacobian을 포함하는 구간을 사용한다.

`Q^D=sqrt(Q)*exp(h*ell*log 2)`를 상대 정밀도로 계산한다. 작은 Q의 제곱근을 절대 오차로 반올림해 하한을 0으로 만드는 일을 피한다. h는 양수이며 0은 구간 끝점으로만 등장한다.

고정 Q 차트에서는 다음 pullback으로 실제 물리 q의 도함수도 계산한다.

`∂z^a ∂τ^b q = Q/(Q^(aD) Q^b) * ∂Z^a ∂T^b s`.

출력 `derivatives`는 native Z,T 미분, `physical_q_derivatives_z_tau`는 물리 z,τ 미분, `physical_q_derivatives_z_t`는 z,t 미분이다. 마지막 것은 `(-1)^b`를 곱한다. 점마다 Q를 선택한 함수 자체를 미분하지 않는다. 인접 차트에서 계산되는 q와 미분은 양의 해의 유일성으로 같은 함수를 나타낸다.

## 검증과 남은 의무

별도의 Decimal Newton 해와 직접 암시적 미분식으로 h=2^-4097의 양수 효과가 보이는 1460자리 대조를 수행한다. 이는 원본 h를 그 시험값으로 대체하는 절차가 아니며, 본 구간 계산은 원본 h 전체 범위를 포함한다. 축 위에서는 독립적인 4차 닫힌식을 τ=2^-8000에서도 비교한다. 기존 독립 Z,T 상자 API는 그 영상 검사를 유지한다.

이 계산은 다음을 완료하지 않는다.

- 원본 coefficient window의 ell≥ell0 및 q<qStar, radial shell과 실제 메시의 지지집합 결속
- #623935의 모든 활성 메시 대표점 역근 존재
- 490개 자연급수의 전역 Y 인증, Φ/u의 공통 복소 정칙성·Bρ 노름·무한 tail
- 최종 A–D 장, 67+13개 물리장 제트, 전체 3D PDE 잔차, 전역 에너지와 네 축 refinement
- 같은 실행으로 생성한 최종 물리장 3D 게시와 M4의 원래 16개 인수 검사

따라서 **M3 62/64, M4 0/16, 최종 제트 0/67, RELEASE HOLD**를 유지한다. 이 실행을 최종 물리장 샘플로 운영 페이지에 게시하지 않는다.
