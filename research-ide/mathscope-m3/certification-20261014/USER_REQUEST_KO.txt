## 2. 무조건부 미분 구현 — 원본 node 539400, 4483, 5029

### A. Source node 539400 — maximum branch

실제 원본:

`539400 = maximum(1, 539399)`

이전 감사에서는 24개 FTC face와 3개 anchor의 구조를 확인했고, 실제 integrand가 요구 조건을 만족한다면 `539399 >= 3`이라는 엄격한 간격을 얻을 수 있었습니다.

이번에는 다음을 수행하십시오.

1. 실제 원본 source graph의 모든 피연산자와 capture, 적분 변수, 정의역을 복원합니다.
2. 세 anchor의 비음성 및 각 적분항의 비음성, 실수성, 적분 가능성과 구간 순서를 증명합니다.
3. 이 조건들이 실제 원본 입력 전체에 적용됨을 확인합니다.
4. 엄격한 branch gap을 사용해 `maximum` 선택이 요청된 영역에서 매끄러운 하나의 표현과 동일함을 증명합니다.
5. 그 동등성에 근거해 임의의 필요한 유한 미분차수에 대한 정당한 미분 규칙을 구현합니다.
6. 함수의 원래 의미와 결과를 보존하고 독립적인 대수 검증을 수행합니다.

조건부로 선택한 분기를 참으로 가정하는 대신, 선택이 정당하다는 수학적 증거를 생성하십시오.

### C. Source node 5029 — quadratic implicit root

실제 원본:

`5029 = actual_quadratic_root(0,4,2)`

논문의 Lemma A.2와 실제 5차원 연속 이차 시스템을 사용하십시오.

- 원래의 B, Q, d와 zero-seeded branch를 보존합니다.
- contraction의 smallness 조건을 실제 원본 상계에서 검증합니다.
- 선택된 고정점의 존재성과 유일성을 확보합니다.

추가로 monotone systems 0·1·2도 동일하게 검토하여 signed variance root, lifted circle inverse, common slow inverse의 존재·유일성·매끄러움 및 미분 조건을 가능한 범위에서 무조건부로 확보하십시오.

**2단계의 완료 조건은 단순한 `CONDITIONAL_DERIVATIVE_CONSTRUCTED`가 아니라 실제 원본 정의역에서 필요한 수학적 가정이 모두 입증되었다는 증거입니다.**

## 4. N6-02 — 전체 3D Cartesian PDE residual 인증

- Status: `RESOURCE_LIMIT`

### 4-A. 계산 병목 해결

무작정 메모리 한도만 늘리지 말고 다음을 수행하십시오.

1. Root 633815의 전체 dependency DAG 구성
2. 실제 중복 노드·중복 미분·중복 적분 탐지
3. 공통 부분식 재사용과 정확한 memoization
4. 원본 binder와 alpha-equivalence 처리의 정당성 검증
5. streaming·checkpoint·bounded continuation 구현
6. 중단·재개 후 결과 동일성 검사
7. 실제 내부 중단 노드와 원인 기록

수학적으로 동등함을 증명하지 않은 표현식은 단순 캐시 최적화 목적으로 합치지 마십시오.

### 4-B. 전체 PDE 계산

실제 업데이트된 원본 \(u,p\)에 대해

\[
R(u,p)=\partial_tu+(u\cdot\nabla)u-\Delta u+\nabla p
\]

를 직접 계산하십시오.

별도로 다음 분해식을 독립 계산하십시오.

\[
\begin{aligned}
R(u+w,p+\pi)
={}&R(u,p)+\partial_tw-\Delta w+\nabla\pi\\
&+(u\cdot\nabla)w+(w\cdot\nabla)u\\
&+(w\cdot\nabla)w.
\end{aligned}
\]

두 계산 경로에는 다음이 모두 포함되어야 합니다.

- 원본 radial·azimuthal·axial 3성분
- 현재 전체 pressure 및 pressure gradient
- cylindrical frame connection terms
- 선형 교차항과 이차 self-interaction
- 모든 실제 angular harmonics
- wave curl correction
- radial/temporal cutoff derivative
- 이전 flat remainder와 새로운 nonlinear remainder
- Gaussian/Fourier tail 및 실제 physical phase chain rule

두 경로의 수식적 일치, 수치적 차이 및 엄밀한 오차 예산을 서로 별도 결과로 기록하십시오.

독립 감사가 원본과 동일한 코드 경로를 호출하여 자기 자신과 비교하는 형태가 되지 않도록 하십시오.

### 4-C. 인증 조건

전체 mean만 검증하고 전체 Cartesian PDE를 인증했다고 판정해서는 안 됩니다.

N6-02는 직접 3D residual과 독립 decomposition의 원본 동일성, 실제 사용 영역, 생략항 경계, 산술 오차 인증이 모두 통과해야 완료됩니다.
