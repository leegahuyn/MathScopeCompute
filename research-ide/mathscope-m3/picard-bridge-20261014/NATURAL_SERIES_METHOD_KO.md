# Picard 자연급수 함수족과 조건부 복소 수렴

원본 n=1 Picard 계수의 157개 자연급수 호출을 같은 두 입력 노드 `(Y, eta)`별로 분류한다. 성분은 Phi 83개, u 51개, average 23개이며 입력 노드 쌍은 24개다. 각 호출의 미분 차수, 계수 그룹, 원본 수식과 적분 경로를 보존한다. 이 분류와 다음 조건부 정리는 전체 N6 계수 노름의 증명을 대신하지 않는다.

## 실제 입력 범위 검사

`natural_series_audit.py`는 인증된 SQLite가 열린 상태에서 계수 근원부터 모든 호출의 적분 문맥을 추적한다. 적분의 양 끝점은 적분 변수의 새 범위 밖에서 평가한다. 정확 유리수 구간으로 양 끝점과 Y를 평가할 수 있는 경우에만 `|Y|<=5`를 확인한다. 같은 노드가 여러 경로에서 등장하면 모든 경로가 해당 범위를 만족해야 한다. 매개변수나 좌표 범위가 없으면 미해결 상태를 반환한다.

`PROVED_ARGUMENT_RANGE_ONLY`는 실수 Y와 실제 실수 적분 경로의 범위만 뜻한다. eta에 의존하는 Y의 복소 확장, 실제 계수 노름, 공통 복소 영역 안의 모든 입력 위치는 별도 의무다. 실제 결과는 CI의 `natural-series-inventory.json`에 보존한다.

## 호환 계수 미분을 전제로 한 수렴 정리

실수 구간 `I=[-33/32,33/32]`에서 실제 계수 함수가 모든 차수에 대해 호환되는 미분을 갖고, 어떤 양수 Q와 rho에 대해

```text
|a_n^(l)(x)| <= Q * 20^(-n) * rho^(-l) * l! * binom(n+l,l)
                  / ((n+1)^2*(l+1)^2)
```

를 만족한다고 가정한다. 이 가정은 저장된 노름 이름이나 서로 무관한 미분 배열로 대체할 수 없다. Taylor 잔여항의 계수 경계가 0으로 가므로 실제 함수는 수렴하는 Taylor 전개와 일치한다. 겹치는 실수 구간에서 일치하는 전개들을 접합해 복소 함수로 확장한다.

`|eta-x|<=t*rho`, `0<=t<1`에서 Taylor 급수를 양의 항으로 지배하면

```text
|a_n^(m)(eta)| <= Q*rho^(-m)*20^(-n)*(n+m)!/n!
                 / ((n+1)^2*(1-t)^(n+m+1)).
```

`|Y|<=R`, `c=1-t-R/20>0`에서 Y에 대한 k차 미분을 더하고 양의 분모 가중치를 버리면 이항 생성함수 항등식으로

```text
|partial_Y^k partial_eta^m F(Y,eta)|
    <= Q*rho^(-m)*(m+k)!*20^(-k)*c^(-m-k-1)
```

를 얻는다. 내부의 모든 콤팩트 집합에서 정상 수렴하므로 정칙성과 항별 미분이 성립한다. average의 계수는 u의 계수를 `(n+1)`로 나눈 것이므로 같은 경계를 적용할 수 있다.

공통 선택 `t=1/2`, `R=5`는 `c=1/4`이며

```text
|partial_Y^k partial_eta^m F|
    <= Q*rho^(-m)*(m+k)!*4^(m+k+1)/20^k
```

를 준다. 코드가 실제 호출의 미분 차수 쌍마다 이 유리수 상수와 양의 꼬리의 기하급수 경계를 재검산한다. 실제 계수 평가 오차를 포함한 수치 함수 평가기로 승격하지 않는다. **원본 호환 계수의 Q와 rho를 확보하는 가정은 아직 열려 있다.** rho/2 근방을 거리 1/4 근방으로 확대하는 결론도 얻지 않는다.

## 실제 역원에 적용한 개별 경계

다음 경계는 실수 `0<h<1/100`과 `dist(eta,[-1,1])<1/4`를 전제로 한다. 다항식을 정확 산술로 인식한 뒤 원본 역원 노드에 연결한다.

| 원본 역원 노드 | 분모 | 분모 절댓값의 엄격 하한 | 역원 절댓값의 엄격 상한 |
|---|---|---|---|
| 17 | 1+eta^2 | 9/16 | 16/9 |
| 279 | 1-h | 99/100 | 100/99 |
| 1953 | 1-2h*eta^2 | 31/32 | 32/31 |
| 3434 | 1+2h | 1 | 1 |

node 17의 분모를 `(eta-i)(eta+i)`로 인수분해한다. 두 극점과 실수 구간 사이의 거리는 1이므로, 복소 근방 안에서 각 인수 절댓값은 3/4보다 크다. 따라서 곱은 9/16보다 크다. `|eta|<5/4` 원판에는 극점 i와 -i가 들어가므로 이 원판을 전체 계수의 공통 정의역으로 사용할 수 없다.

## 전체 Picard 수렴에 남은 연결

자연급수의 조건부 수렴을 전체 계수 행렬과 forcing의 Picard 수렴으로 연결하려면 다음 원본 의무를 해결해야 한다.

| 의무 | 필요한 원본 근거 |
|---|---|
| PB-COMPLEX-STRIP | 모든 실제 A0, A1, forcing 및 역원·로그·제곱근에 같은 영역과 균일 노름 |
| PB-NATIVE-IDENTITY | 원본 함수·적분·분기와 M2 노름 입력 함수의 동일성 |
| PB-PREVIOUS-ORDERS | n>=2에서 실제 이전 계수·모멘트·cutoff가 forcing에 주는 노름 |
| PB-ALL-BANDS | 모든 band, label, copy의 입력 위치와 W/M/S 및 Cartesian PDE 연결 |

이 단계는 Cartesian Jet 230개, 전역 Guard 38개, PDE 잔여항 1,020개를 공식 소거하지 않는다. 총 1,288개, N6-01 OPEN, N6-02 PARTIAL, M3 56/64를 유지한다. 조건부 정리는 고전적 해석 증명과 정확 산술 재검산이며, 새 Lean 커널 인증 결과로 표시하지 않는다.

## 증거 화면

`render_native_view.py`가 실제 `native-domain-inventory.json`으로 독립 HTML을 생성한다. 화면은 함수족 검색, 실수 Y 범위 확인 여부, 조건부 미분 경계, 개별 역원 증거, 원본 SHA와 고정된 N6 잔여 의무를 표시한다. 전체 노름이나 기준 상태가 승격된 입력을 거부한다.
