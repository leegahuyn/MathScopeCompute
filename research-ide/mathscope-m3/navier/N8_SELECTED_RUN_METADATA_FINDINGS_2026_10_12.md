### Energy that can be derived without a new spatial source constructor

For each recorded point, the three normalized velocity enclosures and
their authentic positive physical scaling roots give a rigorous **pointwise
kinetic density** enclosure. If u_j=S_j v_j and v_j in [a_j,b_j], use

    (1/2) sum_j S_j^2 [min(a_j^2,b_j^2,0 if a_j<=0<=b_j),
                       max(a_j^2,b_j^2)].

The coefficient interval can be computed with exact rational arithmetic;
the original physical scales must retain their own scalar-program hash.
This is not a spatial integral. It must be named `pointwiseKineticDensity`,
and it cannot be labelled E(t), core energy, or whole-K energy. If the
selected run promises an integrated energy, that observable is still
missing. No artificial cell volume or unexecuted mesh may be supplied.

An authentic new finite-window selected run might permit a bounded source
residual/integral calculation, but it needs the actual background's complete
active selector prefix and its physical time/space derivatives. The current
near-terminal tau values must not be assumed to lie in a precomputed
finite-order anchor window.
